## Additional resources

- ### Convert between Paths and Selection Borders

[Paths provide smooth outlines](https://helpx.adobe.com/uk/photoshop/using/converting-paths-selection-borders.html) that you can convert into precise selection borders. You can also convert selection borders into paths, using the "Direct Selection" tool for fine\-tuning.

You can define any closed path as a selection border. A closed path can be added to, subtracted from, or combined with the current selection.
