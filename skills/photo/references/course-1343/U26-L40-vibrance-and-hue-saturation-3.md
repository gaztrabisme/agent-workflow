I’ll use the Magnetic Lasso tool. I’m not a big fan of it, but it can work when an object has fairly sharp, defined edges. It is not a good way to make a pixel-perfect cutout, but it can make a quick selection.

## Add the hubcap and refine the edge

Anchor: 1343 · U26 · L40 · 04:30–06:07

We should also add the hubcap. An Elliptical Marquee selection can help. Choose the second selection mode so it adds to the existing selection. It takes practice to use the Elliptical Marquee. Imagine the ellipse as a square and estimate where its top-left corner would be; that is where to start. The selection will not be perfect, even with practice, but while holding the mouse button we can hold the space bar to move the ellipse. Reposition it, keep dragging, and adjust it until it fits.

Next, open Select and Mask. I’ll add a little feathering and smooth the edge slightly. Do not smooth it so much that the little lumps and bumps on the car disappear.

## Add a sampled color with a Solid Color fill layer

Anchor: 1343 · U26 · L40 · 06:07–08:20

I’ll sample a color from the car before adding a color. When an image already has a color to use, I suggest sampling it. Click the foreground color at the bottom of the toolbox to open the Color Picker, then choose a bright, saturated part of the car. Now add a Solid Color fill layer.

The three options at the top of the black-and-white circle menu are fill layers, not adjustment layers. I like this menu because it puts fill layers and adjustment layers together.

Some people prefer the Layer menu, so I’ll show that route too: Layer contains the fill layers Solid Color, Gradient, and Pattern. One benefit of creating the fill layer from the menu is that its dialog lets us name the layer and set the blend mode before applying it. We’ll use Soft Light, which enhances and saturates colors. The car looks as if it has a new coat of paint. The Color Fill dialog selects the foreground color by default. I prefer to pick the color before opening the dialog, but we can also choose it there.

## Edit the mask to hide color from the glass

Anchor: 1343 · U26 · L40 · 09:19–11:51

Open Select and Mask again, use about five pixels of feathering as before, and smooth the edge a little. To understand the mask, look at the mask itself. Hold Alt or Option and click its thumbnail to show it. White is where the color has been applied; black hides the effect.

![1343 · U26 · L40 · 09:49](frames/U26L40-F0949.00.jpg)

On screen: "Layer Mask" / "Density: 100%" / "Feather: 0.0 px" [rest omitted]  
Shows: The layer mask displayed as white over the car body and black outside it, with the window outlined as a selection.

We need to fill the window area with black. There are several ways. We can use Edit and Fill, or the Brush tool on the mask. Press D for the default colors, raise brush opacity and flow, then press X to set black as the foreground. Even if the brush goes outside the window, it can only paint inside the selection.

![1343 · U26 · L40 · 10:36](frames/U26L40-F1036.00.jpg)

On screen: "Mode: Normal" / "Opacity: 100%" / "Flow: 100%" / "Smoothing: 0%" [rest omitted]  
Shows: The layer mask displayed with the window selected and the brush cursor crossing the selection edge.

My preferred way to fill a selection is a keyboard shortcut. Command or Control with Backspace or Delete fills with the background color. Alt or Option with Backspace or Delete fills with the foreground color. Here the foreground is black, so I’ll use Alt or Option plus Backspace or Delete. Then leave the mask view, deselect with Command or Control-D, and the color is removed from the window.

We have now looked at a few ways to work with color: Hue/Saturation and adding color to an image that has lost it or has faded colors. In the next lesson, I’ll show how to add or remove an object to improve a composition.

### Key points (derived)

- A quick selection can establish the mask, then be refined with add/subtract tools and Select and Mask.
- A sampled Solid Color fill layer in Soft Light can add paint color; the mask keeps it off chrome and glass.
