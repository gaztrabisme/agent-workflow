## Check an image before delivering it

Anchor: 1343 · U54 · L81 · 00:00–01:19

Delivering files to a client can feel daunting the first few times. This lesson covers low- and high-resolution files, JPEGs versus TIFFs (captions: “TIPS”), and RGB versus CMYK: what to use, when, and how.

Before sending files, look back at your notes and check everything. This Snickers advert from a few years ago is funny because it contains errors, and mistakes like these are easy to miss. The last thing you want is an extra hand on a shoulder or half of an item missing from an image. As a fun challenge, find all the arrows in the advert and leave your answers in the comments, or add notes on a separate layer so they can be reviewed.

## Choose a screen-ready low-resolution size

Anchor: 1343 · U54 · L81 · 01:19–04:29

Resolution here does not necessarily mean the PPI number, such as 300 PPI or 72 PPI. When sending files to a client, you may send a low-resolution version for approval, or hold back the full-resolution file until the client has paid. “Low resolution” and “high resolution” are relative terms, and expectations change as camera and screen resolutions increase. The first low-resolution files I delivered were around 500 pixels; today, a 500-pixel-tall image is so small that you can hardly judge it.

A low-resolution file should be good enough to view on a screen, but not necessarily large enough to print. It is also quick and easy to send. To make one, open Image Size with Option-Command-I on a Mac or Alt-Control-I on Windows. Make sure Resample is on. Set the resolution to 72 pixels per inch (PPI); the width and height will change automatically. Do not confuse PPI with DPI, or dots per inch. Images are measured in pixels per inch; printer resolution is measured in dots per inch (DPI; captions read “100%” and “dpio.Sprinch”). Many people call image resolution DPI, a common mistake, but the distinction matters.

Then set the image’s longer side—in this case, the height—to 2,000 pixels. At 100% zoom (Command-1 on a Mac or Control-1 on Windows), the result is still a large image and good enough to judge most things on a screen. If particular details matter, send a high-resolution version of that image. A 2,000-pixel image can be printed, but only at a fairly small size.

## Prepare both versions and send the low-resolution copy first

Anchor: 1343 · U54 · L81 · 04:29–07:57

A high-resolution file is typically the image at its full resolution, with no size change. I always send clients both low- and high-resolution files, even if they have not asked for both. The smaller version loads faster and is easier to judge.

You can make the smaller copies in Bridge by choosing Tools, Photoshop, then Image Processor. In Photoshop, choose File, Scripts, then Image Processor. In Image Processor, choose either open images or a folder, then choose where to save the processed copies. Photoshop creates a subfolder for you. Saving in the same location does not necessarily overwrite files already there, but I prefer to specify the destination folder to avoid mistakes.

The file type will usually be JPEG. Turn on Resize to Fit and choose a quality; it does not have to be 12, since this is a low-resolution copy and does not need optimum quality. Converting the profile to sRGB is useful because the file can then be viewed in a file browser or other applications without issues. Set both dimensions to 2,000 pixels; Photoshop makes the longer side 2,000. You can also run an action while processing. I will cancel this setup for now.

Clients may not know to ask for both versions, but it is useful for them to have both. I typically start by sending the low-resolution files because they transfer quickly (captions: “leave”), even with a poor internet connection, and download quickly for the client. Make clear that these are the low-resolution versions, and clients will be happy and thankful to have them (captions: “follow” before “they will be”). The last thing you want is to end up with an image whose quality has gone out the window. That can happen when pixel dimensions are confused with centimeters, leaving you with very small images—a common mistake to avoid. The last topic here is color.
