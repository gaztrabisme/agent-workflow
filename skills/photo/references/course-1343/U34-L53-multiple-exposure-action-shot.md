## Load the photos into Photoshop layers

Anchor: 1343 · U34 · L53 · 00:47–02:27

For a job like this, I would use an automated feature in Bridge. To open every image in the folder, I can press Command-Ctrl-A, then choose Tools > Photoshop > Load Files into Photoshop Layers. Photoshop puts all the images into one file, with each separate photo as a layer stacked above the others.

If you do not have Bridge or do not use it yet, you can do the same thing in Photoshop: choose File > Scripts > Load Files into Stack. If all the photos are already open, choose Add Open Files. Since mine are not open, I’ll choose Browse, go to the folder, select the photos, and click Open. I would normally tick “Attempt to Automatically Align Source Images.” This asks Photoshop to align the parts that stay in the same place across the photos. I took these handheld, so the camera shifted a little between shots. I do want to align them, but I’ll leave that box unchecked to show how to correct this later if you forgot to check it while loading, or if you need to align something else. I’ll click OK. There is quite a bit to process, but Photoshop does it fairly quickly.

## Align the stacked photos

Anchor: 1343 · U34 · L53 · 02:27–03:54

Photoshop has placed the images on top of each other in the right sequence. You can see that the camera shifted slightly. If we had checked the box during loading, Photoshop would already have tried to align the photos. I’ll do it manually now to show you how to fix the alignment afterward.

Select all the layers by clicking the top layer, then Shift-clicking the bottom layer. Go to Edit > Auto-Align Layers. Photoshop asks how to align them. This time, do not choose Auto: I only want Photoshop to reposition the layers. Choose Reposition and click OK. The process can take a little while. When I toggle the layers off, you can see how Photoshop has aligned the images, which will help with the next step. Some pixels are missing at the top-right and bottom-left corners. I can clone those areas later or crop the image, so I will not worry about them now.

## Isolate the first jump pose

Anchor: 1343 · U34 · L53 · 03:54–05:21

From each layer, I only want the diver in that moment of the jump. We’ll use selections and masks. I’ll select the top layer, choose the Quick Selection tool by pressing W, and zoom in. Hold the space bar to move around the image. Use the right bracket key next to P to make the selection brush larger; it does not have to be perfect because we can edit it later. I’ll make the brush smaller with the left bracket. It is better to select a little too much than too little. I should include the small shadow as well, and I missed a tiny area here.

I can use the command I showed you earlier: Select > Modify > Expand. Instead of contracting the selection, I’ll expand it by a couple of pixels to include the edges. Then I’ll add a mask. Photoshop masks the layer according to my selection. If I Alt-click or Option-click the mask, you can see the selection itself; the layer underneath is visible through it. Toggling the layer shows the next diver underneath. Since he is bending farther down in that photo, I may exclude it. I’ll start from this picture and turn off the next two layers. I will not delete them in case I want to return to them. Now I need to adjust this mask a little.

## Refine the mask and select another pose

Anchor: 1343 · U34 · L53 · 05:21–07:14

I’ll zoom in farther and use the regular Brush tool by pressing B. I want a fairly hard brush so the edges stay defined. I do not need it at 100%; around 70% should be enough. I’ll keep opacity and flow at 100%, make sure the foreground color is black, reduce the brush size, and click the mask thumbnail so I know the mask is selected. Then I’ll paint. I’m holding Shift to keep the strokes straight.

I’ll hide this layer temporarily so I can select the diver in the layer below. Choose Quick Selection again. The selection does not have to be perfect; we can refine it. It is more important to include a little too much than not enough. I missed the fingertips, so I’ll extend the selection slightly, then choose Select > Modify > Expand by a couple of pixels. That looks fine. I can mask the extra area later if needed. I’ll add the mask in the Layers panel, and the next photo will show through. I can include or exclude this layer; here I’ll exclude it and use the next one.

Now I’ll select the diver in this position on the next layer. Expand the selection by three pixels this time. I have missed those fingers, so I’ll make sure they are included before adding the mask. Then I’ll refine the mask with the Brush tool: press B, zoom in, check that black is the foreground color, and paint to hide the contents of this layer. There is a hint of blue around the edge, so I’ll go around it again. I’ll zoom out to check the result and turn the top layer back on.

## Continue masking the later positions

Anchor: 1343 · U34 · L53 · 07:14–09:55

The next step is to select the diver on the next layer. To make that selection easier, I’ll temporarily switch off the layer above, use Quick Selection, and choose Select > Modify > Expand by three pixels. I’ll make sure the selection includes everything, add the mask, and switch the previous layer back on. Then I’ll use the Brush tool with black to hide the parts of this layer I do not want.

To understand what is on each layer, I toggle the next layer on and off. I hide the previous layer, pick up Quick Selection, and repeat the process. Once you have done this a few times, it starts to become logical, though it can be confusing the first time. There are plenty of layers here to practice on.

If you remove too much, press X to switch to white and paint that area back in. Then mask the next photo: turn off the previous layer, make a Quick Selection, expand it by three pixels, and add the mask. Turn the previous layer back on. This layer is easier because the diver is not covering himself. Make sure the selection does not cover the previous layer. There is a little tuft flying up, so I’ll keep it. Use Select > Modify > Expand. This selection is covering the foot, so I’ll need to adjust the mask after adding it. Actually, I think we got it about right. Let’s check the last few layers.

## Blend the splash and trim the canvas

Anchor: 1343 · U34 · L53 · 09:55–11:46

A splash appears in the next layer and grows larger in the one after it, so I’ll include some of it. I’ll hide the previous layer as before and zoom in. Here it may be easier to use the Lasso tool. This layer also adds a small shape in the water, which we can revisit later. I’ll make a rough selection, make sure I have everything, and add the mask. As you can see, this hides a little of the splash in the layer underneath.

I’ll press B for the Brush tool and use a larger, softer brush. I’m painting black to blend the splash into the image. I can Alt-click or Option-click the eye icon to see only this layer and check whether there is anything else I want to include. I may paint down here to bring the diver into the nice shape in the water. Let’s take a look. We have a few more layers we could work on, but I think this looks good as it is.

When an image has a transparent edge, another way to crop it is to trim it to that edge. Choose Image > Trim and select Transparent Pixels. Photoshop will crop the image automatically when I click OK. That is how you can put an action shot into one frame in Photoshop.

To finish, I would add a couple of adjustment layers. I would probably add a Curves layer to darken the image slightly, then another Curves layer to bring out more contrast. Then I’ll add a little more vibrant color with Vibrance.

To organize the layer stack, select the topmost pixel layer, Shift-click the last one, and add a group. I’ll call that “Action shots.” If we want, we can put the adjustments in another group above it and call that “Adjustments.” This is a fun way to show action a little differently from the usual approach. I’d love to see your own examples if you upload them to the website, and I’ll give you feedback.
