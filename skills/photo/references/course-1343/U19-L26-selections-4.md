## Choosing the Pen tool for a product edge

Anchor: 1343 · U19 · L26 · 00:11–02:48

1343 · U19 · L26 · 00:11–02:48

The last kind of selection in this lesson uses the USB cable image. I chose it for two reasons. First, it is white on white, which makes selections difficult for Photoshop’s automated tools. Second, it is a product image. Product cutouts usually need very straight, square edges and smooth curves. That is different from the hair cutout, where the goal was to preserve fine, frizzy detail. With this product, removing a little extra plastic may look better than leaving a small bump in an otherwise perfect cutout. Sometimes it is better to cut away a little of the object.

The best tool for this kind of selection is the Pen tool. It works with vectors rather than pixels. I showed this with text earlier: a path keeps its edge smooth when you scale it up, even though the image pixels themselves can still become pixelated. Press P to choose the Pen tool, or select it from the toolbox. It takes practice, and I am not a master because I rarely make these kinds of selections; I mostly work with portraits, where we do not often use the Pen tool for cutouts. The basic motion is to click, move, and click again to place points and connect them. What you create is a path, not yet a selection.

## Work paths and shaping curves

Anchor: 1343 · U19 · L26 · 02:48–04:51

1343 · U19 · L26 · 02:48–04:51

To turn a path into a selection, use the Paths panel, which is normally beside Channels. If it is not visible, choose Window > Paths. Photoshop creates a Work Path by default; treat it as temporary. For a more complex task, start a new path by clicking the plus icon. If you forget, as I often do, drag the Work Path onto the new-path icon to save it. A saved path stays in the document when you save it as a Photoshop document.

I will make another path to demonstrate a curve. Click to place points for straight sections. For a curve, click and drag while holding the mouse button. This creates two handles that shape the curve. Their direction and length affect the section of curve around the point and how the next section will be shaped.

## Edit anchor points and handles

Anchor: 1343 · U19 · L26 · 04:51–08:05

1343 · U19 · L26 · 04:51–08:05

If you want to move an existing point, a common beginner mistake is to click it with the Pen tool and accidentally add another point. Undo that. To edit points and handles, choose the Direct Selection tool, the white arrow in the toolbox. With it, you can adjust the point and move its handles individually. Then select the Pen tool again to continue the path.

If a point is slightly out of place, use the keyboard arrow keys to nudge it instead of switching tools. To move a point or its handles while using the Pen tool, hold Command on a Mac or Control on Windows to bring up the white arrow temporarily. A handle can bend what should be a straight line into an arch. To make a corner, hold Alt or Option so you can move the two handles independently; pull the handle in the direction needed for the straight edge.

I have made a few mistakes in this demonstration path, so I will delete it and try the actual cable. The main idea is to use the white arrow or the keyboard for small corrections, and to separate the handles when the curve on one side of a point should not control the other side.

## Trace the cable and convert the path to a selection

Anchor: 1343 · U19 · L26 · 08:05–12:13

1343 · U19 · L26 · 08:05–12:13

For the cable cutout, I will ignore the slightly rounded corners and use square corners to work faster. Zoom in to see the edge. Click and drag where the cable curves, then adjust the point if the handle makes the path too thick or points in the wrong direction. At a corner, nudge the point to make the line straight. At the bend near the bottom of the cable, move the bottom handle independently of the top one with Alt or Option. Use single clicks for straight sections, and drag again where a curve is needed. The Command or Control key lets me move a point; Alt or Option lets me separate its handles. The Spacebar is another way to reposition while tracing.

As I trace, I check whether each handle follows the cable’s edge. If a handle bends the path the wrong way, adjust it so the edge tracks the cable. When I make a curve on one side, I make a matching curve on the other side. Some corners have an unusual angle, so I use a similar angle at the corresponding point. The result is not perfect, but it looks fine for this demonstration. With the Direct Selection tool, I can nudge any point that needs to be straighter or adjust an angle.

The button at the bottom of the Paths panel converts the path into a regular selection. I can then use that selection with adjustment layers, for example to change an object’s color or hue.

## Save and reload a selection

Anchor: 1343 · U19 · L26 · 12:13–13:16

1343 · U19 · L26 · 12:13–13:16

Once you have made an accurate selection, you can save it so you can return to it later. The hair cutout and shoe in the previous images are examples of selections you could save this way. Choose Select > Save Selection and give the selection a name. In this image, the USB cable is the only object to select, so I will name it “USB Cable” and click OK. Deselect the object. To use the saved selection later, choose Select > Load Selection. Photoshop lists the available selections; here there is only the one I just saved. Choose it, click OK, and the selection reappears. Then deselect it again.

## Cut out the object with a vector mask

Anchor: 1343 · U19 · L26 · 13:16–14:36

1343 · U19 · L26 · 13:16–14:36

You can also cut an object out using its path. Because a path is vector-based, it gives a smooth edge regardless of how large the image is made. Select the path, go to Layers, and open Layer > Vector Mask. Choose Current Path. Photoshop cuts out the object using that path. The blue line is only a preview; click away from it to see the result. There is a lot to learn about selections, and it takes practice to make them precise. In the next lesson, I will show you an even more important part of Photoshop: working with layer masks.
