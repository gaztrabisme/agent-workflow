## Additional resources

- ### Use the Liquify Filter

The ["Liquify"](https://helpx.adobe.com/uk/photoshop/using/liquify-filter.html) filter lets you push, pull, rotate, reflect, pucker, and bloat any area of an image. The distortions you create can be subtle or drastic, which makes the Liquify command a powerful tool for retouching images as well as creating artistic effects. The Liquify filter can be applied to 8‑bits per\-channel or 16‑bits per\-channel images.
