# Unit 3 · Let's do it

Anchor: 669 · U3

In this unit I want to show you how I manage a session in an interior location, so you can see how we can take advantage of the different elements it offers us.

## Tasks

- ### Locate 
Practice exercise 3\.1

Think of interior spaces where you have been or that you like and consider how to get portraits there. Make a list, move threads and whatever you need.
- ### Search items 
Practice exercise 3\.2

Think about what objects can help you give a different touch to your photos. Play, investigate, try them, you never know what will work best for you.
