# Measurement: source checks, image checks, and review thresholds

**Reader:** an editor measuring a photo export or preparing a rendered comparison for review. Run code checks first. Measures screen for specific defects; they do not establish that a portrait is beautiful, authentic, or suitable for its audience.

## Reporting

For every test report **measured**, **vision-judged**, **not judged**, or **skipped**. Include actual measurements and the source of each threshold. If a domain or delivery brief replaces a default, name it. Never convert an unavailable vision review or a tool's manual-review result into a pass.

## Photo tool limits

grade.py measure reports histograms, channel statistics, clipping shares, a heuristic neutral patch and optional mask-based hue summaries; those neutral/skin readings are estimates. grade.py compare reports CIEDE2000 differences and writes an HTML comparison page, but alignment resampling limits its meaning. roundtrip.py verify checks protected regions against its stated tolerances and requires manual review after resize. None of these checks decides whether a retouch looks natural or matches the brief. See [TOOLS.md](../../TOOLS.md).
