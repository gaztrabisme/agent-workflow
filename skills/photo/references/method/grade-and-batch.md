# Grade and batch: hold a coherent look without flattening the images

**Reader:** the editor matching a portrait set or preparing repeatable social images. **Scope:** create a grade and a safe batch path. Colour facts and palette theory belong with `color-theory`.

**Source lessons:** [669 U4 L10](../course-669/U04-L10-editing-with-lightroom.md), [227 U4 L12](../course-227/U04-L12-photo-editing-with-vsco.md), [1343 U47 L70](../course-1343/U47-L70-working-with-actions.md), [1343 U53 L80](../course-1343/U53-L80-colour-grading-batch-processing.md).

## Set one look, then adapt each photograph

- Decide the overall look by comparing the grade on and off. The Photoshop course demonstrates LUTs, gradient maps, and curves, and recommends testing an action on an image before processing a batch. (1343 · U53 · L80 · 00:11–03:00; 1343 · U53 · L80 · 03:00–05:41; 1343 · U53 · L80 · 05:41–07:20; 1343 · U53 · L80 · 07:20–10:29; 1343 · U53 · L80 · 10:29–13:58)
- Match a group only when images share the same scene conditions. The Instagram course copies edits for a matching set but still reviews each result; the portrait course copies a scene base and adapts each image. (227 · U4 · L12 · 18:15–20:06; 669 · U4 · L10 · 03:49–05:57)
- When recording an action, leave color and contrast curves without points when those adjustments depend on the image (1343 · U47 · L70 · 04:00–05:55). Stop recording and test the action by playing it back (1343 · U47 · L70 · 05:56–07:39). A dialog pause can stop the action at a step so you can change its value (1343 · U47 · L70 · 07:40–09:32). After batch processing, check the first image; in the teacher's example she removes a duplicate curve from it (1343 · U53 · L80 · 10:29–13:58).
- Reuse a curves preset on another image as a starting point, with a few tweaks (1343 · U53 · L80 · 07:20–10:29). The portrait course copies its scene base to other photographs from the same space and adapts each one (669 · U4 · L10 · 03:49–05:57).
- **Derived set check:** compare neighboring images for unintended shifts in brightness, color, contrast, or skin appearance while preserving useful scene differences. This check follows from reusing a curves preset with image-specific tweaks and adapting a copied scene base. (derived from 1343 · U53 · L80 · 07:20–10:29; 669 · U4 · L10 · 03:49–05:57)

**Derived batch rule:** treat automation as a starting adjustment, not an approval. The courses show copied scene edits, copied mobile edits under matching conditions, and a tested action; together they support a sample-first, per-image review. (derived from 669 · U4 · L10 · 03:49–05:57; 227 · U4 · L12 · 18:15–20:06; 1343 · U53 · L80 · 10:29–13:58)

## Check before moving on

T10 passes when every edited frame has been reviewed individually and the set has no unintended grade discontinuity. See [review-checklist.md](review-checklist.md).

**Practice the teacher sets:** record and test a repeatable grading action, then inspect its results on the intended image set. See [Unit 53](../course-1343/U53-unit.md).
