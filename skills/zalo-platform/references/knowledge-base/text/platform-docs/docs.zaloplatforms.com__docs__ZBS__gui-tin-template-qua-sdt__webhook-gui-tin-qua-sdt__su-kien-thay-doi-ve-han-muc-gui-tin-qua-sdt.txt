Sự kiện thay đổi về hạn mức gửi tin qua SĐT
Khi có sự kiện thay đổi về hạn mức gửi tin của OA được phát sinh theo hệ thống đánh giá hoặc theo đề xuất thay đổi từ khách hàng, hệ thống Zalo sẽ gửi đến Webhook Url của ứng dụng một HTTP request như sau.
Lưu ý
Quyền cần có: Nhận sự kiện gửi tin qua SĐT
URL: Webhook Url của ứng dụng
Method: POST
Content Type: application/json
X-ZEvent-Signature: mac = sha256(appId + data + timeStamp + OAsecretKey), với data là chuỗi json trả về dưới đây.
Ví dụ:​
{
"event_name": "change_oa_daily_quota",
"oaId": "2352868362652028400",
"quota": {
"prev_value": 1000,
"new_value": 2000
},
"timestamp": "1602560967477"
}
Mô tả thuộc tính​
Thuộc tính
Mô tả
event_name
String
Tên sự kiện
Giá trị nhận về: change_oa_daily_quota
oa_id
String
ID của OA ủy quyền
quota
Json Object
Ví dụ:
{
"prev_value": 1000,
"new_value": 2000
}
Trong đó:
"prev_value": Hạn mức gửi tin của OA trước khi cập nhật
"new_value": Hạn mức gửi tin của OA sau khi cập nhật
timestamp
String
Thời gian hệ thống gửi thông báo
