Lấy thông tin quota lệnh phản hồi người dùng
Bạn có thể sử dụng API lấy thông tin quota lệnh phản hồi để kiểm tra số lượt phản hồi với người quan tâm đã sử dụng.
Lưu ý
Quyền cần có: Quyền gửi tin và thông báo qua OA
HTTP request​
URL: https://openapi.zalo.me/v2.0/oa/quota/message
Method: POST
Content Type: application/json
Response Type: text/json
Example request​
curl
-X POST
-H 'Content-Type: application/json'
-H 'access_token: <your_access_token>'
-d '{
"message_id": "843dd5bf90e676ba2ff5"
}' 'https://openapi.zalo.me/v2.0/oa/quota/message'
Tham số header​
Tham số
Kiểu dữ liệu
Tính bắt buộc
Mô tả
access_token
string
yes
Token cho phép ứng dụng đại diện OA gọi API. Xem chi tiết cách lấy access token tại đây.
Cấu trúc body của request​
Tham số
Kiểu dữ liệu
Tính bắt buộc
Mô tả
message_id
string
yes
Token cho phép phản hồi tin nhắn đến từ người dùng (nhận được thông qua webhook sự kiện người dùng gửi tin nhắn)
Example respond​
{
"data": {
"type": "reply",
"remain": 3,
"total": 8,
"message_id": "843dd5bf90e676ba2ff5"
},
"error": 0,
"message": "Success"
}
Cấu trúc thuộc tính data​
Thuộc tính
Kiểu dữ liệu
Mô tả
type
string
Giá trị trả về là reply cho biết đây là quota của lệnh phản hồi.
remain
int
Số lượng lệnh còn lại có thể dùng để phản hồi người dùng trong vòng 48 giờ.
total
int
Tổng số lượng lệnh phản hồi có thể gửi tới người dùng khi nhận tin từ người dùng trong vòng 48 giờ
