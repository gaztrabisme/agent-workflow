Lấy thông tin Agent, Branch
Lưu ý
Ứng dụng cần được OA cấp quyền sử dụng chức năng gọi thoại
HTTP request​
URL: https://openapi.zalo.me/v3.0/oa/call/getmccinfo
Method: GET
Content Type: application/json
Response Type: text/json
Example request​
curl --location 'https://openapi.zalo.me/v3.0/oa/call/getmccinfo' \
--header 'access_token: <oa_access_token>' \
--header 'Content-Type: application/json' \

Tham số

Mô tả
access_token
string
yes
Token cho phép ứng dụng đại diện OA gọi API. Xem chi tiết cách lấy access token tại đây.

Cấu trúc thuộc tính data​
Thuộc tính
Kiểu dữ liệu
Mô tả
agents
JSON Array
Danh sách các tổng đài viên, trong đó:
· agent_id: là user_id của tổng đài viên
· agent_name: tên của tổng đài viên
· allocation: danh sách nhánh mà tổng đài viên đang làm việc
branches
JSON Array
Danh sách các nhánh gọi, trong đó:
· branch_id: ID của nhánh gọi
· branch_name: Tên của nhánh gọi
· status: Trạng thái hoạt động của nhánh gọi (on hoặc off)
