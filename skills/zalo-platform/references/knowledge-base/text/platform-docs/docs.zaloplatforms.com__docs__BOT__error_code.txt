Bảng mã lỗi
Bảng mô tả mã lỗi có thể phát sinh khi sử dụng các APIs của hệ thống. Với các trường hợp lỗi, vui lòng tham khảo thông tin trong trường description trong dữ liệu nhận được để biết thêm chi tiết.
Mã lỗi
Ý nghĩa
400
Bad request - sai đường dẫn hoặc API Name không hợp lệ
401
Unauthorized - Token đã hết hạn hoặc không hợp lệ
403
Internal server error
404
Not found - Yêu cầu truy cập không lệ
408
Request timeout - Quá thời gian xử lý cho phép
429
Quota exceeded - Vượt quá giới hạn sử dụng API cho phép
