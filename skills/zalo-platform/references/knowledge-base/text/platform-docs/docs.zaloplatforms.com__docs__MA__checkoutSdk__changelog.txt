2025-04-24​
Release ZMP SDK v2.45.0​
Thêm sự kiện PaymentDone giúp nhận & xử lý kết quả thanh toán trên Mini App tiện lợi hơn. Xem hướng dẫn
Kể từ phiên bản này, khi có lắng nghe sự kiện PaymentDone, Checkout SDK sẽ bỏ qua Redirect Path ở các phương thức có hỗ trợ.
Đối tác có thể lắng nghe sự kiện PaymentDone để nhận kết quả thanh toán và điều hướng người dùng phù hợp cho từng phiên bản ứng dụng.
Kể từ phiên bản này, đối tác cần bắt buộc phải truyền dữ liệu MAC vào API. Checkout SDK sẽ không xử lý những request bị thiếu MAC.
