Khởi tạo và Phát triển ZOA Extension
Zalo OA command-line interface (ZOA-CLI) cho phép nhà phát triển (ED) phát triển và triển khai sản phẩm lên Zalo OA Extension Hub. Hướng dẫn này sẽ giúp bạn bắt đầu với ZOA-CLI và phát triển Extension của mình.
Cài đặt ZOA-CLI​
Bạn có thể cài đặt ZOA-CLI bằng npm hoặc yarn:
# Sử dụng npm
npm i -g zoa-cli
# Hoặc sử dụng yarn
yarn global add zoa-cli
Sau khi cài đặt, kiểm tra phiên bản đã cài đặt:
zoa --version
Khởi tạo Dự án​
Chuyển vào thư mục bạn muốn tạo dự án.
Chạy lệnh sau để khởi tạo project:
zoa init
Nhập Zalo App ID của bạn khi được yêu cầu.
Chọn Login via QR code with Zalo App để xác thực tài khoản và lấy access token.
Chọn Create a new ZOA Extension project và điền thông tin liên quan để tạo project mới.
Phát triển Dự án​
Mở project bằng IDE và tiến hành coding.
Lưu lại thông tin thay đổi.
Chạy lệnh sau để build dự án:
zoa build
Triển khai (Deploy)​
Để triển khai dự án của bạn:
Chạy lệnh sau để sync code lên hệ thống quản lý phiên bản:
zoa deploy
Kiểm tra kết quả tại trang quản lý phiên bản.
Thông tin
Lệnh zoa deploy sẽ đẩy code lên trang quản lý phiên bản. Sau khi deploy thành công, bạn cần truy cập Trang quản lý phiên bản để tiến hành các bước tiếp theo.
Tài liệu tham khảo​
NPM Package ZOA-CLI
Mẫu dự án đơn giản
Lưu ý:
Trong giai đoạn POC, chỉ có Zalo APP_ID được cấp quyền mới có thể truy cập trang quản lý phiên bản của Extension.
