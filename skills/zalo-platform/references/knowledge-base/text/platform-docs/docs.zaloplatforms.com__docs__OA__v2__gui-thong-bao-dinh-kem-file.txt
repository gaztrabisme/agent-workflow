Gửi thông báo đính kèm file
Quyền cần có: Quyền gửi tin và thông báo qua OA
Lưu ý: để gửi thông báo đính kèm file, bạn cần sử dụng API upload file.
HTTP request​
URL: https://openapi.zalo.me/v2.0/oa/message
Method: POST
Content Type: application/json
Response Type: text/json
Example request​
curl
-X POST
-H "Content-Type: application/json"
-H 'access_token: <your_access_token>'
-d '{
"recipient": {
"user_id": "2468458835296117922"
},
"message": {
"attachment": {
"type": "file",
"payload": {
"token": "12i8LV3BcmmDS4iLfyoU3qKxHXNtpu077ZjA7xRHmmi8EXrEjuR50LHjJXJWWvTQ17OJ7R2Oc5q4SHSJjPoPKmDq5X2tyS4MI78oKexCna1CUJnQyiMvUKmfG7UOX8PYVW5FJAckbWbi1tWbj8BnCNOyTGMBr8mrG5XZ4epkfbD4HczzjUs3FM0QL1ZM"
}
}
}
}' "https://openapi.zalo.me/v2.0/oa/message"

string
yes
Token cho phép ứng dụng đại diện OA gọi API. Xem chi tiết cách lấy access token tại đây.
