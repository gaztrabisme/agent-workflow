Thả biểu tượng cảm xúc vào tin nhắn
Quyền cần có: Gửi tin nhắn/Thả biểu tượng cảm xúc vào tin nhắn
HTTP request​
URL: https://openapi.zalo.me/v2.0/oa/message
Method: POST
Content Type: application/json
Response Type: text/json
Example request​
curl --request POST "https://openapi.zalo.me/v2.0/oa/message"
--header 'access_token: <your_access_token>'
--header 'Content-Type: application/json'
--data-raw '{
"recipient": {
"user_id": "186729651760683225"
},
"sender_action": {
"react_icon": "/-strong",
"react_message_id": "789f573aecf8a9a4f0eb"
}
}'

Tham số
Kiểu dữ liệu

Mô tả
access_token
string
yes
Token cho phép ứng dụng đại diện OA gọi API. Xem chi tiết cách lấy access token tại đây.

Tham số
Kiểu dữ liệu

string
yes
ID của người nhận (nhận được thông qua API truy xuất chi tiết người dùng, API truy xuất danh sách người dùng)

Tham số
Loại
Tính bắt buộc
Mô tả
react_icon
string
yes

:>
--b
:-((
/-strong
/-heart
:-h
:o
/-remove (sử dụng khi thu hồi biểu tượng cảm xúc)

string
yes

Lưu ý:​
Một message_id chỉ được thả tối đa 50 biểu tưởng cảm xúc.
API này không bị tính vào quota chủ động hàng tháng.
