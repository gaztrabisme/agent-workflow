IP Whitelist Policy
Cập nhật lần cuối:5/8/2026
Development​
All IP addresses are allowed to access the development API endpoint.
Production​
Only registered IP addresses are allowed to access the production API endpoint. Requests from the IPs which have not been registered for whitelisting will receive responses with code -7 (forbidden).
