Cập nhật thông tin khách hàng quan tâm OA
Lưu ý
API hỗ trợ cập nhật thông tin của người quan tâm mà OA lưu trữ. Thay đổi chỉ áp dụng với thông tin lưu trữ ở phía OA và không làm thay đổi thông tin tài khoản Zalo của người quan tâm.
API này được thay thế bởi API Cập nhật thông tin người dùng và sẽ dừng hỗ trợ OA Doanh nghiệp từ ngày 01/06/2024
HTTP request​
URL: https://openapi.zalo.me/v2.0/oa/updatefollowerinfo
Method: POST
Content Type: application/json
Response Type: text/json
Example request​
curl \
-X POST \
-H 'Content-Type: application/json' \
-H 'access_token: <your_access_token>' \
-d '{ \
"user_id": "2512523625412515",
"name": "Huynh Hong Hien",
"phone": "012345678",
"address":"ho chi minh",
"city_id": city_id,
"district_id": district_id,
}' "https://openapi.zalo.me/v2.0/oa/updatefollowerinfo"

Tham số

Mô tả
access_token
string
yes
Token cho phép ứng dụng đại diện OA gọi API. Xem chi tiết cách lấy access token tại đây.
