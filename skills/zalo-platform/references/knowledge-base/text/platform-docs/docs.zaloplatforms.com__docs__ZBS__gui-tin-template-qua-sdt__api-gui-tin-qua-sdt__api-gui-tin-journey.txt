API Gửi tin Journey
Khi có nhu cầu gửi tin qua SĐT theo hành trình cho hành trình giao vận hoặc vé xe khách, bạn có thể sử dụng chuỗi tin Journey tương ứng với 1 trong 2 hành trình để tối ưu chi phí.
Lưu ý:
Bạn cần liên hệ với bộ phận vận hành dịch vụ gửi tin qua SĐT thông qua Zalo Official Account/kênh email, hoặc đội ngũ chăm sóc khách hàng đang làm việc với doanh nghiệp của bạn để được cấp phép sử dụng loại API này và hướng dẫn các cài đặt template liên quan.
Lưu ý
Quyền cần có: Gửi tin qua số điện thoại
Mô hình gửi tin Journey qua SĐT
Một tin Journey được định nghĩa là một chuỗi các tin gửi qua SĐT gửi đến 1 khách hàng, tính phí theo một mô hình riêng (thay vì theo từng tin).
Tin Journey hiện tại được chia theo 2 industries chính:
Logistics: Hành trình giao vận
Coach bus: Hành trình xe khách
Cần phải có Journey Token để thực hiện chuỗi gửi tin Journey đến khách hàng. Từng khách hàng, cho từng hành trình, sẽ có từng Journey Token khác nhau.
Mỗi loại Journey Token cần được gửi bằng loại Template Journey tương ứng. Vui lòng liên hệ đội ngũ Chăm sóc khách hàng của Zalo Business Solutions qua email: support@zalo.solutions để khởi tạo các mẫu Template này.
Các mẫu tin gửi qua SĐT trong bộ tin Journey cần phải được khai báo trước khi sử dụng.
Khởi tạo Journey Token​
HTTP request​
URL: https://business.openapi.zalo.me/journey/get-token
Method: POST
Content Type: application/json
Response Type: text/json
Example request​
curl --location
--request POST 'https://business.openapi.zalo.me/journey/get-token'
--header 'Content-Type: application/json'
--header 'access_token: your_access_token'
--data-raw '{ "phone":"84987654321", "token_type":"token_logistics_7" }'

Content Type: application/json

--header 'Content-Type: application/json'
--header 'access_token: access_token'
