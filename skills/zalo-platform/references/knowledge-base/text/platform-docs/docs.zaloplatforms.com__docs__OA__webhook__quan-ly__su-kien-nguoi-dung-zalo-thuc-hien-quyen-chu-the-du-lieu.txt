Sự kiện người dùng Zalo thực hiện quyền chủ thể dữ liệu
Khi người dùng Zalo yêu cầu thực hiện quyền chủ thể dữ liệu với Bên Kiểm soát dữ liệu cá nhân (bao gồm rút lại sự đồng ý; xoá dữ liệu; hạn chế xử lý dữ liệu; phản đối xử lý dữ liệu), Nền tảng Zalo thực hiện thông báo các yêu cầu này đến các bên Đối tác để tiến hành xóa dữ liệu tương ứng của chủ thể dữ liệu.
URL: Webhook Url của ứng dụng bên thứ 3
Method: POST
Content Type: application/json
X-ZEvent-Signature: mac = sha256(appId + data + timeStamp + OAsecretKey), với data là chuỗi json trả về dưới đây.
Example​
{
"app_id": "1519815886763164419",
"oa_id": "607812198688816074",
"user_id_by_app": "2836211951173838919",
"user_id": "4558424660619243532",
"event_name": "user_withdraw",
"timestamp": "1727770763679"
}
Mô tả thuộc tính​
Thuộc tính
Kiểu dữ liệu
Mô tả
app_id
String
Id của ứng dụng bên thứ 3
oa_id
String
Official Account Id mà ứng dụng đã liên kết
- Nếu app chưa liên kết với OA, sẽ trả oa_id = “”
user_id_by_app
String
Id của user (với app) thực hiện withdraw
user_id
String
Id của user (với OA) thực hiện withdraw
- Nếu app chưa liên kết với OA, sẽ trả user_id = “”
event_name
String
Thuộc tính xác định loại event
Giá trị là: user_withdraw
timestamp
String
Thời điểm request được gửi, tính bằng milliseconds
Trước
Sự kiện Đồng bộ user_external_id thất bại
