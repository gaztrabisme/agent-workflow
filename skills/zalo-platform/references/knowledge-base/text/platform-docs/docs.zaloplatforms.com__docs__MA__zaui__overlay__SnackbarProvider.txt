SnackbarProvider
Cập nhật lần cuối:5/8/2026
import { SnackbarProvider } from "zmp-ui";
Dùng để tạo thông báo nhanh hiển thị lên trên giao diện ứng dụng, sự dụng thông báo về thông tin thêm, trạng thái thành công hoặc lỗi xảy ra khi sử dụng một hành động, quá trình download, trạng thái kết nối,...

SnackbarContext​
Property
Type
Required
Description
openSnackbar
(options: SnackbarOptions) => void
No
Hàm để tạo mới và mở một Snackbar. Có thể mở Snackbar với các
closeSnackbar
() => void
No
Hàm để đóng một Snackbar, có thể sử dụng để đóng nhanh khi chưa hết thời gian hiển thị.
setDownloadProgress
(completed: number) => void
No
Cập nhật phần trăm tiến trình download (0 - 100) khi sử dụng với `type` là `download`.
