getAppInfo
Cập nhật lần cuối:5/8/2026
import { getAppInfo } from "zmp-sdk";
API truy xuất thông tin Zalo Mini App hiện tại.
Ví dụ​
Lấy tên và phiên bản live hiện tại:
const { name, version } = await getAppInfo({});
Xem hướng dẫn xử lý lỗi và bảng mô tả chi tiết mã lỗi tại đây.
Kết quả trả về​
API trả về Promise chứa các thông tin Zalo Mini App hiện tại.
