Gửi tin nhắn Mention tới nhóm
Lưu ý
Ứng dụng cần được cấp quyền quản lý thông tin nhóm.
HTTP request​
URL: https://openapi.zalo.me/v3.0/oa/group/message
Method: POST
Content Type: application/json
Response Type: text/json
Example request​
curl --location --request POST 'https://openapi.zalo.me/v3.0/oa/group/message' \
--header 'access_token: <your_access_token>' \
--header 'Content-Type: application/json' \
--data '{
"recipient": {
"group_id": "f414c8f76fa586fbdfb4",
},
"message": {
"text": "hello [@186729651760683225] and [@7967320986128691935] from GroupAPI"
}
}
'
