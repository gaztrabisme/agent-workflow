Thông tin cấu hình
Cập nhật lần cuối:5/8/2026
Khi trở thành đối tác giải pháp, bạn sẽ được cung cấp cặp giá trị Partner API Key - Partner Id để tương tác và sử dụng các API này từ Server của bạn.
Sau đây là một số thông tin đi kèm khi bạn đăng ký sử dụng OpenAPI cho đối tác giải pháp:
Danh sách IP Access: Danh sách IP Server hoặc Gateway của bạn bạn đã đăng ký để truy cập những API này.
Webhook Url: URL nhận thông báo và cập nhật dữ liệu từ Zalo Mini App.
Scopes (Phạm vi) API mà bạn có thể tương tác:
apps.create: cho phép tạo Mini App.
apps.getlist: cho phép lấy danh sách các Mini App của bạn.
apps.deploy: cho phép deploy mới phiên bản Mini App lên hệ thống Zalo.
apps.versions: lấy danh sách các phiên bản của Mini App.
apps.request.publish: cho phép gửi yêu cầu xét duyệt Mini App.
apps.publish: cho phép publish Mini App.
apps.request.permission: cho phép gửi yêu cầu xin cấp quyền.
apps.get.stats: Cho phép lấy số liệu thống kê của Mini App.
apps.get.payment.channels: Cho phép lấy danh sách phương thức thanh toán của Mini App.
apps.create.update.payment.channels: Cho phép tạo và cập nhật phương thức thanh toán của Mini App.
Lưu ý, tất cả các API đều có rate limit theo từng Zalo App, bạn có thể xem thông tin chi tiết trong phần Quản lý APIs.
