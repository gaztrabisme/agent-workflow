Cấu hình Open API
Cập nhật lần cuối:5/8/2026
Để tương tác và sử dụng được các Open APIs, bạn cần thiết lập API Key cho ứng dụng Zalo App của mình. Vui lòng làm theo hướng dẫn sau để lấy API Key:
Truy cập trang Quản lý Zalo App, chọn Zalo App bạn muốn thiết lập.
Sau đó chọn Open APIs.
Trong phần Quản lý APIs thiết lập các thông tin sau:
IP Access: bạn bắt buộc phải khai báo danh IP Server hoặc Gateway của bạn để có thể truy cập những API này.
Webhook URL: để nhận thông báo khi có những thay đổi liên quan đến Mini App.
Scopes: Phạm vi bạn muốn API có thể tương tác:
apps.send.notification: cho phép gửi thông báo tới người dùng qua OA chung của Zalo Mini App.
apps.get.stats: Cho phép lấy số liệu thống kê của Mini App.
Sau đó chọn Cập nhật, hệ thống sẽ tạo cho bạn một API Key tương ứng với các thông tin đã thiết lập
