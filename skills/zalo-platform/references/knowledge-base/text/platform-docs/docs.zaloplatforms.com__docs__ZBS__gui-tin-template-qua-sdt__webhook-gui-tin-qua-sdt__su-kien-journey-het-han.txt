Sự kiện journey hết hạn
Khi có sự kiện một journey hết hạn và chưa từng được sử dụng, hệ thống Zalo sẽ gửi đến Webhook Url của ứng dụng một HTTP request như sau.
Lưu ý
Quyền cần có: Nhận sự kiện gửi tin qua SĐT
URL: Webhook Url của ứng dụng
Method: POST
Content Type: application/json
X-ZEvent-Signature: mac = sha256(appId + data + timeStamp + OAsecretKey), với data là chuỗi json trả về dưới đây.
Ví dụ:​
{
"event_name": "event_journey_time_out",
"journey_id": "928185612043968512",
"app_id": "4349311699477619340",
"oa_id": "3886651700907664415",
"timestamp": "1641367274777"
}
