Slider
Cập nhật lần cuối:5/8/2026
Bạn đang xem tài liệu zmp-ui v1.7.0. Bản mới nhất là v1.11.0. Xem bản mới nhất →
Tạo giao diện cho phép người dùng lựa chọn gía trị, hoặc khoảng giá trị trong một giới hạn
