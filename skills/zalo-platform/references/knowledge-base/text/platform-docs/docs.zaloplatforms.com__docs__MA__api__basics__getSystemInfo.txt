Cập nhật lần cuối:5/8/2026
Bắt đầu hỗ trợ ở phiên bản:
SDK2.4.0
import { getSystemInfo } from "zmp-sdk";
API truy xuất thông tin hệ thống, thiết bị đang sử dụng.
Ví dụ​
Lấy các thông tin phiên bản:
const { version, apiVersion, zaloVersion } = getSystemInfo();
Xem hướng dẫn xử lý lỗi và bảng mô tả chi tiết mã lỗi tại đây.
Kết quả trả về​
API trả về Promise chứa các thông tin về phiên bản, ngôn ngữ, theme của hệ thống.
