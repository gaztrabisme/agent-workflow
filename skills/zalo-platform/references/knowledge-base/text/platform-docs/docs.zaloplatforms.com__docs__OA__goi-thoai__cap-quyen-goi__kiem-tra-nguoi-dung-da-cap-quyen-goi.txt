Kiểm tra người dùng đã cấp quyền gọi
Lưu ý
Ứng dụng cần được OA cấp quyền sử dụng chức năng gọi thoại
HTTP request​
URL: https://openapi.zalo.me/v2.0/oa/call/checkconsent
Method: GET
Response Type: text/json
Example request​
curl \
-X POST \
-H 'Content-Type: application/json' \
-H 'access_token: <your_access_token>' \
'https://openapi.zalo.me/v2.0/oa/call/checkconsent?data={"phone":"84773543888"}'
