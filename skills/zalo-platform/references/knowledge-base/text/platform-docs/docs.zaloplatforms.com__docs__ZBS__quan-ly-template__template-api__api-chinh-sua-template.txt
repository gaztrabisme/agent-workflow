API Chỉnh sửa Template
Doanh nghiệp có thể chỉnh sửa các template có trạng thái REJECT (đã bị từ chối) thông qua API chỉnh sửa template. Tương tự như quá trình tạo template, các thay đổi đối với template sau khi gửi qua API sẽ cần được đội ngũ Zalo kiểm duyệt trước khi sử dụng lại.
API chỉnh sửa template đặc biệt hữu ích cho các doanh nghiệp hoặc agency có nhu cầu cập nhật nhiều template sau khi nhận phản hồi từ Zalo hoặc khi cần thay đổi nội dung template bị từ chối (REJECT).
Sau khi gửi yêu cầu chỉnh sửa template thành công, đội ngũ Zalo sẽ kiểm duyệt. Sau khi kiểm duyệt xong, một event webhook thay đổi trạng thái template sẽ được gửi về webhook URL đã được thiết lập trước đó của doanh nghiệp. Trạng thái của template sẽ thay đổi từ PENDING_REVIEW sang REJECT nếu bị Zalo từ chối hoặc ENABLE nếu được duyệt.
THÔNG BÁO
API này đang được đánh giá lại và có thể có điều chỉnh trong thời gian sắp tới.
→ Khuyến nghị: Ưu tiên tạo và chỉnh sửa Template qua giao diện ZBS Account.
Lưu ý
Quyền cần có: Quản lý Message Template
Prequisite​
Mã truy cập (Access Token) được doanh nghiệp (OA) ủy quyền cho App. Lưu ý: Template khởi tạo sẽ thuộc sở hữu của OA.
Quyền cần có để sử dụng API: Quản lý tài sản.
Logo/Hình ảnh đính kèm khi tạo template, doanh nghiệp cần tải lên thông qua API upload ảnh (Chi tiết xem tại đây)
Giới hạn​
Daily quota của API chỉnh sửa template: 100 requests/ngày
Mỗi loại mẫu tin sẽ có các quy định cần phải tuân theo khác nhau về các trường thông tin.
HTTP request​
URL: https://business.openapi.zalo.me/template/edit
Method: POST
Content Type: application/json
Response Type: application/json
