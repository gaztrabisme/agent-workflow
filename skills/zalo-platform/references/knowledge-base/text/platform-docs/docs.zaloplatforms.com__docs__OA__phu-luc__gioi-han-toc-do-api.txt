Giới hạn tốc độ gọi API
Giới hạn tốc độ​
Giới hạn tốc độ xác định giới hạn về số lệnh gọi API có thể thực hiện trong một khoảng thời gian cụ thể. Giới hạn tốc độ được đặt ra cho từng ứng dụng.
Giới hạn tốc độ cấp ứng dụng​
Mọi lệnh gọi API từ ứng dụng khi đã vượt quá giới hạn tốc độ đều không được thực thi và sẽ trả về error code = -32. Các giới hạn này sẽ được tính dựa theo phút. Các giới hạn này sẽ được làm mới ở phút tiếp theo.
Giới hạn​
Giới hạn tốc độ gọi được tính trên ứng dụng theo từng loại API khác nhau:
Official Account API: 4.000 requests/phút
Article API: 4.000 requests/phút
Social API: 4.000 requests/phút và 20 requests/user/phút
Giới hạn tốc độ gọi được tính trên Official Account theo từng loại gói OA khác nhau. Xem thông tin tại đây.
Lưu ý
Giới hạn tốc độ gọi tính trên Official Account không bao gồm API gửi tin ZBS Template Message.
Cách tránh giới hạn tốc độ​
Trải đều truy vấn giữa 2 khoảng thời gian để tránh lưu lượng gọi API tăng vọt trong một thời điểm. Đặc biệt là các thao tác nhập dữ liệu
Có phần xử lý lỗi khi gọi API trả về error code = -32.
Header giới hạn tốc độ​
Tất cả phản hồi cho lệnh gọi với API đều bao gồm Header HTTP X-RateLimit-Limit và X-RateLimit-Remain. Trong đó X-RateLimit-Limit là tổng số lệnh ứng dụng được gọi API tính theo phút, X-RateLimit-Remain là số lệnh gọi còn lại mà ứng dụng được gọi API tính theo phút, khi số này bằng 0 có nghĩa là ứng dụng của bạn đã đạt tới giới hạn gọi API.
