Luồng tạo nhóm​
Giải thích:
(1) Gửi request Lấy hạn mức nhóm của OA
(2) Hệ thống Zalo trả về danh sách các gói kèm asset_id
(3) Gửi request tạo nhóm chat kèm theo asset_id
(3) Hệ thống Zalo trả về thông tin nhóm chat được tạo thành công
HTTP request​
URL: https://openapi.zalo.me/v3.0/oa/group/creategroupwithoa
Method: POST
Content Type: application/json
Response Type: application/json
Example request​
curl --request POST 'https://openapi.zalo.me/v3.0/oa/group/creategroupwithoa' \
--header 'access_token: <your_oa_access_token>' \
--header 'Content-Type: application/json' \
--data '{
"group_name": "Tư vấn nha khoa",
"group_description": "Group tư vấn nha khoa cho các nhân viên",
"asset_id": "326e977e4d3da463fd2c",
"member_user_ids": [
"186729651760683225"
]
}'
Tham số header​
Tham số
Kiểu dữ liệu
Tính bắt buộc
Mô tả
access_token
string
yes
Token cho phép ứng dụng đại diện OA gọi API. Xem chi tiết cách lấy access token tại đây.
Cấu trúc body của request​
Tham số
Kiểu dữ liệu
Tính bắt buộc
Mô tả
group_name
string
yes
Tên nhóm
group_description
string
optional
Mô tả nhóm
asset_id
string
yes
ID gói GMF, sử dụng để làm dịch vụ hoạt động của Nhóm. (Lấy ID bằng cách gọi API Lấy hạn mức tạo nhóm GMF)
member_user_ids
array
yes
Danh sách các user trong nhóm (danh sách này không được để trống và không quá 99 người và có ít nhất 1 người là admin của OA)
