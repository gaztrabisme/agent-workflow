Sự kiện tạo nhóm OA
Khi một nhóm OA được tạo mới, hệ thống Zalo sẽ gửi một request HTTP đến Webhook URL đã đăng ký của ứng dụng.
URL: Webhook Url của ứng dụng
Method: POST
Content Type: application/json
X-ZEvent-Signature: mac = sha256(appId + data + timeStamp + OAsecretKey), với data là chuỗi json trả về dưới đây
Example request​
{
"event_name": "create_group",
"oa_id": "2057086764452860443",
"group_id": "48382b0bb7595e070748",
"app_id": "3570977494304483078",
"timestamp": "1696407729342"
}
