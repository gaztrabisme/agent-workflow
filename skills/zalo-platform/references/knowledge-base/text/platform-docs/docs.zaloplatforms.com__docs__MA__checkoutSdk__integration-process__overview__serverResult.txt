Bước 4 - Xử lý kết quả thanh toán phía Server
Cập nhật lần cuối:5/8/2026
Xử lý callback từ Checkout SDK Server​
Đối với các thanh toán qua ZaloPay, Momo, VNPay, PayMe. Khi hoàn tất quá trình thanh toán, Checkout SDK Server sẽ gửi dữ liệu kết quả cho Merchant Server theo CallbackURL . Merchant dùng PrivateKey để xác thực dữ liệu do Checkout SDK Server POST qua.
CallbackURL và PrivateKey đã cấu hình trong cài đặt chung ở phần khai báo phương thức thanh toán.
Chi tiết: tham khảo API callback
Xử lý notify từ Checkout SDK Server​
Đối với hai phương thức thanh toán sau khi nhận hàng (COD) và chuyển khoản ngân hàng, ứng dụng cần hiện thực API nhận thông báo khi người dùng chọn một trong hai phương thức này.
Chi tiết: tham khảo API: notify
Cập nhật kết quả thanh toán cho Checkout SDK Server​
Đối với các thanh toán qua thanh toán khi nhận hàng (COD), chuyển khoản ngân hàng và thanh toán riêng. Khi hoàn tất quá trình thanh toán, đối tác cần chủ động gửi dữ liệu kết quả cho Checkout SDK qua API updateOrderStatus.
