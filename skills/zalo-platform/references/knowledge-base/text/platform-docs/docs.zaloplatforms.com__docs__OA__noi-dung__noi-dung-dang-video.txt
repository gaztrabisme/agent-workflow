Trên trang này
Nội dung dạng Video
HTTP request​
URL: https://openapi.zalo.me/v2.0/article/create
Method: POST
Content Type: application/json
Reponse Type: text/json
Sample​
curl \
-X POST \
-H "Content-Type: application/json" \
-H "access_token: <ACCESS_TOKEN>" \
-d '{
"title": "News",
"description": "This is news",
"status": "show",
"video_id": "7f8c46bf7bfa94cbeb",
"avatar": "url_image",
"comment": "show"
}' \
'https://openapi.zalo.me/v2.0/article/create'
Tham số header​
Tham số
Kiểu dữ liệu
Tính bắt buộc
Mô tả
access_token
String
Yes
Xem hướng dẫn lấy access_token ở đây.
Cấu trúc body​
Tham số
Kiểu dữ liệu
Tính bắt buộc
Mô tả
title
String
Yes
Tiêu đề bài viết. Tối đa 150 ký tự.
description
String
Yes
Mô tả về bài viết. Tối đa 300 ký tự.
status
String
Yes
Trạng thái của bài viết. Chỉ nhận 1 trong 2 giá trị: “show”, “hide”
video_id
String
Yes
id của video hiển thị trên bài viết.
avatar
String
Yes
Đường dẫn url đến hình ảnh muốn dùng làm thumbnail .
comment
String
Yes
Gồm 2 giá trị: “hide” (không cho phép comment trên bài viết này), “show”(Cho phép comment trên bài viết này). (Không bắt buộc, mặc định là “show”)
