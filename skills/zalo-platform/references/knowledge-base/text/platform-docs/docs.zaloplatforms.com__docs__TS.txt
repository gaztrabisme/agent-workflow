Transfer Service
Giải pháp nhận thanh toán qua chuyển khoản ngân hàng cho Mini App.
REST APIVietQRWebhookHTTPS
Tổng quan​
Transfer Service là giải pháp kết nối giữa Mini App của Merchant với các ngân hàng và tổ chức thanh toán, cung cấp:
Xử lý thanh toán — tiếp nhận thông tin thanh toán từ khách hàng.
Kết nối ngân hàng — giao tiếp với ngân hàng để tạo giao dịch và sinh VietQR.
Thông báo kết quả — gửi thông tin giao dịch về hệ thống của Merchant.
Đặc điểm kỹ thuật: Mọi truy vấn thực hiện qua HTTPS, hỗ trợ GET/POST, dữ liệu JSON. Mỗi request được xác thực bằng chữ ký (signature).
Điểm nổi bật​
Tích hợp nhanh
REST API + JSON, ví dụ rõ ràng cho từng endpoint.
Bảo mật bằng chữ ký
Xác thực signature trên mọi request, bắt buộc HTTPS.
Đối soát realtime
Webhook + API truy vấn giúp đối soát chính xác trạng thái đơn.
Tính năng chính​
Khởi tạo giao dịch và sinh mã VietQR.
Webhook thông báo kết quả thanh toán theo thời gian thực.
Truy vấn trạng thái giao dịch chủ động.
Bảng mã lỗi nghiệp vụ & HTTP đầy đủ để xử lý ngoại lệ.
