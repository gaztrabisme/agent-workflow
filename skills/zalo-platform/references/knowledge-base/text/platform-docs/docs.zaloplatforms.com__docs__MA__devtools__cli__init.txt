Tạo dự án
Cập nhật lần cuối:5/8/2026
zmp init
Để tạo Zalo Mini App, bạn có thể lựa chọn một trong hai cách sau:
Create a new ZMP project (Tạo mới): Zalo Mini App CLI sẽ tạo ra cấu trúc thư mục cho dự án mới và cài đặt các dependencies cần thiết vào thư mục hiện hành đang sử dụng (working directory).
Use ZMP to deploy only (Chuyển đổi ứng dụng Web có sẵn thành Zalo Mini App): Zalo Mini App CLI sẽ bổ sung các file thiết lập cần thiết để bạn có thể đưa dự án có sẵn lên Zalo Mini App. Chi tiết bạn có thể tham khảo bài viết Hướng dẫn chuyển đổi Web App thành Zalo Mini App trong 30 phút

Mô tả
Zalo Mini App ID
✓
✓
ID của Zalo Mini App mà bạn đã đăng ký. Nếu chưa có, bạn có thể tạo ID cho mini app của mình ở mini.zalo.me.
Name
✓
✓
Tên của Zalo Mini App, được dùng để hiển thị trên thanh điều hướng.
Template
✓
CLI sẽ tạo ra các trang mẫu theo template bạn chọn để bắt đầu phát triển Mini App. Nếu bạn không cần các trang mẫu này, bạn có thể chọn "blank".
JavaScript/TypeScript
✓
CLI có thể tự động tích hợp TypeScript vào dự án của bạn nếu bạn chọn tùy chọn này. Nếu bạn cần một mã nguồn đơn giản hơn, bạn có thể chọn JavaScript.
CSS Preprocessor
✓
Bạn có thể chọn giữa CSS (không sử dụng preprocessor) hoặc các preprocessor phổ biến như Less, SASS / SCSS và Stylus.
More Options
✓
Ngoài ra, bạn có thể chọn bổ sung các thư viện/công cụ hỗ trợ phát triển Mini App nhanh hơn như TailwindCSS và Recoil,...
