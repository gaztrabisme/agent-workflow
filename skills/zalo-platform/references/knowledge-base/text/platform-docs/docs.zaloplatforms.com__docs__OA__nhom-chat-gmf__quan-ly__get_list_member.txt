Lấy danh sách thành viên nhóm
Lưu ý
Ứng dụng cần được cấp quyền quản lý thông tin nhóm.
HTTP request​
URL: https://openapi.zalo.me/v3.0/oa/group/listmember
Method: GET
Response Type: text/json
Example request​
curl --request GET 'https://openapi.zalo.me/v3.0/oa/group/listmember?group_id=f414c8f76fa586fbdfb4&offset=0&count=5' \
--header 'access_token: <your_access_token>'

Tham số
Kiểu dữ liệu

string
yes
Token cho phép ứng dụng đại diện OA gọi API. Xem chi tiết cách lấy access token tại đây.
