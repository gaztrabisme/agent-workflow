Tương tác, điều hướng tới Zalo Mini App
Cập nhật lần cuối:5/8/2026
Do hỗ trợ nhiều điểm truy cập khác nhau nên Zalo Mini App cũng hỗ trợ nhiều cơ chế điều hướng giữa các ứng dụng Web và Zalo Mini App.
Mở Zalo Mini App từ ứng dụng bên ngoài Zalo​
Để điều hướng người dùng tới Zalo Mini App từ bên ngoài nền tảng Zalo vui lòng sử dụng 1 trong 2 cách:
Hướng dẫn người dùng quét mã QR của Zalo Mini App.
Xây dựng link điều hướng theo cấu trúc bên dưới, trong đó appId là Zalo Mini App ID bạn muốn điều hướng tới.
https://zalo.me/s/{appId}/?variable=value
Mở Zalo Mini App từ một Zalo Mini App khác​
Để mở 1 Zalo Mini App từ 1 Zalo Mini App, vui lòng sử dụng API như hướng dẫn:
import { openMiniApp } from "zmp-sdk/apis";
openMiniApp({
appId: "Zalo Mini App ID to open",
params: {
key: value
},
success: (res) => {
// xử lý khi gọi api thành công
},
fail: (error) => {
// xử lý khi gọi api thất bại
console.log(error);
}
});
Mở Webview trong Zalo Mini App​
Để mở 1 Website dưới dạng Webview trong Zalo Mini App, vui lòng sử dụng API như hướng dẫn:
import { openWebview } from "zmp-sdk/apis";
openWebview({
url: "Website url to open",
success: () => {},
fail: (error) => {}
});
