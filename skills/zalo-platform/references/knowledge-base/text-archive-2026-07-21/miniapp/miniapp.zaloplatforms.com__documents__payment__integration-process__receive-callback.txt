Cập nhật lần cuối: 8/1/2026

Khi hoàn tất quá trình thanh toán, Checkout SDK Server sẽ gửi dữ liệu kết quả cho Merchant Server theo CallbackURL . Merchant dùng PrivateKey để xác thực dữ liệu do Checkout SDK Server POST qua.

CallbackURL và PrivateKey đã cấu hình trong cài đặt chung ở phần thông tin tích hợp.
