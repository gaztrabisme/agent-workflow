LƯU Ý: NỘI DUNG TẠI TRANG NÀY SẼ KHÔNG CÒN ĐƯỢC CẬP NHẬT.

Từ ngày 01/01/2026, dịch vụ ZNS được hợp nhất vào ZBS Template Message. Vui lòng xem tài liệu mới tại: ZBS Template Message.

Khi có sự kiện một journey hết hạn và chưa từng được sử dụng, hệ thống Zalo sẽ gửi đến Webhook Url của ứng dụng một HTTP request như sau.

LƯU Ý

Quyền cần có: Sử dụng Zalo Notification Service.

URL: Webhook Url của ứng dụng
Method: POST
Content Type: application/json
X-ZEvent-Signature:mac = sha256(appId + data + timeStamp + OAsecretKey), với data là chuỗi json trả về dưới đây.
Ví dụ:​
{
    "event_name": "event_journey_time_out",
    "journey_id": "928185612043968512",
    "app_id": "4349311699477619340",
    "oa_id": "3886651700907664415",
    "timestamp": "1641367274777"
}

Mô tả thuộc tính:​
Thuộc tính	Mô tả
event_name
String	Tên sự kiện
Giá trị nhận về: event_journey_time_out
journey_id
String	ID của journey
app_id
String	ID của ứng dụng
oa_id
String	ID của OA
timestamp
String	Thời gian hệ thống ghi nhận journey timeout
Trước
Sự kiện thay đổi về chất lượng gửi của mẫu tin ZNS
