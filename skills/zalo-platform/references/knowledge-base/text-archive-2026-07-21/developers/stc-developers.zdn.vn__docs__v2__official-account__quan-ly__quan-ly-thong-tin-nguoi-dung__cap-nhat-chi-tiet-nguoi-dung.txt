LƯU Ý

Ứng dụng cần được cấp quyền quản lý thông tin người dùng

HTTP request​
URL: https://openapi.zalo.me/v3.0/oa/user/update
Method: POST
Content Type: application/json
Response Type: text/json
Example request​
curl --location --request POST 'https://openapi.zalo.me/v3.0/oa/user/update' \
--header 'access_token: <your_access_token>' \
--header 'Content-Type: application/json' \
--data '{
    "user_id": "4064634764263601113",
    "shared_info": {
        "name": "Display name",
            "phone": "012345678",
            "address":"ho chi minh",
            "city_id": city_id,
            "district_id": district_id,
            "user_dob" : "31/12/1999"
    },
    "user_alias": "Alias name"
    "user_external_id": "ED123mi09hfh"
}'

Tính bắt buộc

	

Mô tả




user_id

	

string

	

yes

	

ID của người dùng cần thay đổi thông tin.




shared_info

	

string

	

no

	

Thông tin người dùng cần cập nhật




user_alias

	

string

	

no

	

Tên alias của người dùng




user_external_id

	

string

	

no

	

Mã liên kết do OA tùy biến. Mỗi mã chỉ được gắn cho 1 khách hàng.

Kiểu dữ liệu

Mô tả




name

	

string

	

no

	

Tên cập nhật




phone

	

string

	

no

	

Số điện thoại cập nhật




address

	

string

	

no

	

Địa chỉ cập nhật




city_id

	

int

	

no

	

Mã tỉnh, thành phố trực thuộc trung ương. Xem tại đây.




district_id

	

int

	

no

	

Mã quận, huyện, thành phố trực thuộc tỉnh. Xem tại đây.




user_dob

	

string

	

no

	

Ngày sinh theo định dạng định dạng dd/MM/yyyy. Hiện tại chỉ hỗ trợ nhập các giá trị từ 1/1/1970.
