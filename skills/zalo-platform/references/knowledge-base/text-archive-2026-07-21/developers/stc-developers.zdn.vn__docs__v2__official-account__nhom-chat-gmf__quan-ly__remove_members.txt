LƯU Ý

Ứng dụng cần được cấp quyền quản lý thông tin nhóm.

HTTP request​
URL: https://openapi.zalo.me/v3.0/oa/group/removemembers
Method: POST
Content Type: application/json
Response Type: text/json
Example request​
curl --location --request POST 'https://openapi.zalo.me/v3.0/oa/group/removemembers' \
--header 'access_token: <your_access_token>' \
--header 'Content-Type: application/json' \
--data '{
    "group_id": "f414c8f76fa586fbdfb4",
    "member_user_ids" : [
        "8756287263669629130"
    ]
}'

Tham số header​
Tham số	Kiểu dữ liệu	Tính bắt buộc	Mô tả
access_token	string	yes	Token cho phép ứng dụng đại diện OA gọi API. Xem chi tiết cách lấy access token  tại đây.
Cấu trúc body của request​
Tham số	Kiểu dữ liệu	Tính bắt buộc	Mô tả
group_id	string	yes	ID của nhóm
member_user_ids	string	yes	Danh sách các user_id muốn xóa khỏi nhóm
Example respond​
{
    "error": 0,
    "message": "Success"
}
