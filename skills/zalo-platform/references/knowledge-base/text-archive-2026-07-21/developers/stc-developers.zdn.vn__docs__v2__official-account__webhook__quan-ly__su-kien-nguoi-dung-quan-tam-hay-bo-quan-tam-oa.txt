Sự kiện người dùng quan tâm hay bỏ quan tâm OA

Khi người dùng quan tâm hay bỏ quan tâm OA, hệ thống Zalo gửi đến webhook URL đã đăng ký của ứng dụng

URL: Webhook Url của ứng dụng
Method: POST
Content Type: application/json
X-ZEvent-Signature:mac = sha256(appId + data + timeStamp + OAsecretKey), với data là chuỗi json trả về dưới đây.
Example respond​
{
  "oa_id": "388613280879808645",
  "follower": {
    "id": "24684588352919792"
  },
  "user_id_by_app": "552172779717587730",
  "event_name": "follow",
  "source": "oa_profile",
  "app_id": "36084652489903967",
  "timestamp": "154397978274"
}

Mô tả thuộc tính​

Thuộc tính

	

Kiểu dữ liệu

	

Mô tả




oa_id

	

String

	

Official Account Id mà user đã quan tâm/bỏ quan tâm




follower

	

Json Object

	

Ví dụ:

{
    "id": "24684588352919792"
}


Trong đó:

·        “id”: Id của User quan tâm/bỏ quan tâm Official Account




event_name

	

String

	

Xác định loại event, gồm các giá trị sau:

· event _name=”follow”: Người dùng quan tâm Official Account

· event _name=”unfollow”: Người dùng bỏ quan tâm Official Account




source

	

String

	

Xác định cách thức người dùng quan tâm Official Account:

· oa_profile: Người dùng nhấn nút quan tâm trên trang chủ của Official Account

· message_invite: Người dùng nhấn đồng ý trên tin nhắn mời quan tâm

· social_plugin: Người dùng nhấn nút quan tâm của social_plugin (Thảm khảo cách lấy nút quan tâm tại đây)




app_id

	

String

	

Id của ứng dụng bên thứ 3




timestamp

	

String

	

Thời điểm request được gửi, tính bằng milisecond
