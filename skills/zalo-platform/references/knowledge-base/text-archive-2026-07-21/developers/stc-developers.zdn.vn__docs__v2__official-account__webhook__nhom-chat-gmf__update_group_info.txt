Sự kiện cập nhật thông tin nhóm

Khi có nhóm được cập nhật thông tin, hệ thống Zalo sẽ gửi một request HTTP đến Webhook URL đã đăng ký của ứng dụng.

URL: Webhook Url của ứng dụng
Method: POST
Content Type: application/json
X-ZEvent-Signature: mac = sha256(appId + data + timeStamp + OAsecretKey), với data là chuỗi json trả về dưới đây
Example request​
{
    "oa_id": "2057086764452860443",
    "group_id": "48382b0bb7595e070748",
    "event_name": "update_group_info",
    "app_id": "3570977494304483078",
    "timestamp": "1696408709119"
}

Mô tả thuộc tính​
Thuộc tính	Kiểu dữ liệu	Mô tả
event_name	String	Thuộc tính xác định loại event
oa_id	String	Id của Official Account
group_id	String	Id nhóm
timestamp	String	Thời điểm request được gửi, tính bằng millisecond
app_id	String	Id ứng dụng đang nhận event
