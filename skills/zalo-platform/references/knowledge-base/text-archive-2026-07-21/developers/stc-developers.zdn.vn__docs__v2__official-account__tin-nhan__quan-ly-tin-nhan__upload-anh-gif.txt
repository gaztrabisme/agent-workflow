Upload ảnh GIF
MẸO

Bạn có thể sử dụng API upload ảnh GIF (ảnh động) để phục vụ việc gửi thông báo đính kèm ảnh.

LƯU Ý

Ảnh GIF sau khi được upload và gửi đến người dùng sẽ được lưu trên server tối đa 7 ngày. Trường hợp người dùng muốn xem lại GIF sau thời gian trên, người dùng sẽ được thông báo ảnh GIF không còn tồn tại. Quota cho API là không giới hạn.

Quota cho API là:

5000 request/ tháng.

Quyền cần có: Quyền gửi tin và thông báo qua OA

HTTP request​
URL: https://openapi.zalo.me/v2.0/oa/upload/gif
Method: POST
Content Type: multipart/form-data
Response Type: text/json
Example request​
curl \
-H 'access_token: <your_access_token>' \
-F "file=@/home/test.gif" \
https://openapi.zalo.me/v2.0/oa/upload/gif

Tham số header​
Tham số	Kiểu dữ liệu	Tính bắt buộc	Mô tả
access_token	string	yes	Token cho phép ứng dụng đại diện OA gọi API. Xem chi tiết cách lấy access token tại đây.
Cấu trúc body của request​
Tham số	Loại 	Tính bắt buộc	Mô tả
file	binary	yes	Nội dung file nhị phân của file hình GIF. Dung lượng tối đa 5MB.
Example respond​
{
  "data": {
    "attachment_id": "hDtMfuo7iDncIQ1aSOQp9FHOROFisDP7m64BxCKe"
  },
  "error": 0,
  "message": "Success"
}

Cấu trúc thuộc tính data​
Thuộc tính	Kiểu dữ liệu	Mô tả
token	string	ID của ảnh được upload, sử dụng cho API gửi thông báo đính kèm ảnh.
