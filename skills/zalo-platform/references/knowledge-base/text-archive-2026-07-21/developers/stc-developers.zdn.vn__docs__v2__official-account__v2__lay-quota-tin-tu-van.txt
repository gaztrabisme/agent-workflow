Lấy quota tin Tư vấn

Bạn có thể sử dụng API lấy quota tin tư vấn để kiểm tra số lượng tin Tư vấn miễn phí theo gói.

LƯU Ý
API này sẽ chính thức dừng hỗ trợ từ ngày 01/06/2024. Và được thay thế bởi API [Kiểm tra hạn mưc tin nhắn OA].


Nhà phát triển vui lòng thực hiện chuyển đổi trước thời hạn trên để không ảnh hưởng đến trải nghiệm.



Ứng dụng cần được cấp quyền quản lý thông tin OA

HTTP request​
URL: https://openapi.zalo.me/v2.0/oa/quota/message
Method: POST
Content Type: application/json
Response Type: text/json
Example request​
curl
-X POST
-H 'Content-Type: application/json'
-H 'access_token: <your_access_token>'
'https://openapi.zalo.me/v2.0/oa/quota/message'

Tham số header​
Tham số	Kiểu dữ liệu	Tính bắt buộc	Mô tả
access_token	string	yes	Token cho phép ứng dụng đại diện OA gọi API. Xem chi tiết cách lấy access token tại đây.
Example respond​
{
    "data": {
        "type": "active",
        "remain": 450,
        "total": 1000 
    }, 
    "error": 0,
    "message": "Success"
}

Cấu trúc thuộc tính data​
Thuộc tính	Kiểu dữ liệu	Mô tả
type	string	Giá trị trả về là active cho biết đây là tin Tư vấn miễn phí theo gói.
remain	int	Số lượng tin Tư vấn miễn phí theo gói còn lại
total	int	Tổng số lượng tin Tư vấn miễn phí theo gói có thể sử dụng.
