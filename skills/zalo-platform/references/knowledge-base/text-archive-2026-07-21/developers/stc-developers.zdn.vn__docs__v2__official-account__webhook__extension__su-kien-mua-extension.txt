Sự kiện mua Tiện ích

Khi OA thanh toán tiện ích thành công

Cho phép app config bật/tắt event này trong trang thiết lập webhook (https://developers.zalo.me/app/{appid}/webhook)

Sự kiện: Sự kiện OA thanh toán tiện ích thành công
Tên sự kiện: extension_purchased Event này chỉ fire về cho đúng appId được chỉ định (extension_id được mua)

Khi quyền giữa ứng dụng và oa bị hủy, hệ thống Zalo sẽ gửi một request HTTP đến Webhook Url đã đăng ký của ứng dụng

URL: Webhook Url của ứng dụng bên thứ 3
Method: POST
Content Type: application/json
X-ZEvent-Signature:mac = sha256(appId + data + timeStamp + OAsecretKey), với data là chuỗi json trả về dưới đây.
Ví dụ:​
{
    "oa_id": "388613280879808645",
    "event_name": "extension_purchased",
    "extension_id": "36084652489903967",
    "extension_sub_info":
    {
        "valid_start_date": "15/12/2023",
        "valid_through_date": "14/12/2023",
        "duration_month": "1"
    }
    "timestamp": "154397978274"
}

Mô tả thuộc tính​
Thuộc tính	Kiểu dữ liệu	Mô tả
oa_id	String	Id của Official Account
event_name	String	Giá trị là: extension_purchased
extension_id	String	Id của tiện ích
extension_sub_info	Object	Trong đó:
valid_start_date: Ngày bắt đầu hiệu lực của gói tiện ích
valid_through_date: Ngày hiệu lực cuối cùng của gói tiện ích
duration_month: Thời gian hiệu lực của gói tiện ích, tính theo tháng

timestamp	String	Thời điểm event được gửi, tính bằng milisecond
