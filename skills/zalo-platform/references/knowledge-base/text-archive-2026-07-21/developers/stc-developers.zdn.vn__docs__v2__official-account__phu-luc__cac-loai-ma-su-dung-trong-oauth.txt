Các loại mã sử dụng trong OAuth
Authorization code​
Là mã ủy quyền cho phép ứng dụng gọi API để lấy access token và refresh token.
Authorization code sẽ được trả về qua callback URL của ứng dụng.
Authorization code chỉ được sử dụng 1 lần và có hiệu lực trong vòng 10 phút.
Access token​
Token cho phép ứng dụng đại điện OA sử dụng API.
Thời hạn hiệu lực: 25 giờ.
Refresh token​
Mỗi access token được tạo ra sẽ đi có một refresh token đi kèm. Refresh token dùng để tạo lại access token khi access token hết hiệu lực.
Thời hạn hiệu lực: 3 tháng.
