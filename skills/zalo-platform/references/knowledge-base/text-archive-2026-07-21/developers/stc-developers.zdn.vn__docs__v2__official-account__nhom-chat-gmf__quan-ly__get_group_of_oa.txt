LƯU Ý

Ứng dụng cần được cấp quyền quản lý thông tin nhóm.

HTTP request​
URL: https://openapi.zalo.me/v3.0/oa/group/getgroupsofoa
Method: GET
Response Type: text/json
Example request​
curl --location --request GET 'https://openapi.zalo.me/v3.0/oa/group/getgroupsofoa' \
--header 'access_token: <your_access_token>'

Tham số header​
Tham số	Kiểu dữ liệu	Tính bắt buộc	Mô tả
access_token	string	yes	Token cho phép ứng dụng đại diện OA gọi API. Xem chi tiết cách lấy access token  tại đây.
Tham số​
Tham số	Kiểu dữ liệu	Tính bắt buộc	Mô tả
offset	integer	optional	
Offset muốn query.
Mặc định: 0

count	integer	optional	
Số lượng mong muốn query.
Mặc định: 5

Cấu trúc thuộc tính data​
Tham số	Kiểu dữ liệu	Mô tả
offset	integer	offset muốn query
count	integer	Số lượng muốn query
total	integer	Tổng số lượng các nhóm của OA
groups	array	Danh sách các nhóm của OA
member_count	integer	Số lượng các thành viên được trả về
Cấu trúc thuộc tính groups​
Tham số	Kiểu dữ liệu	Mô tả
name	string	Tên nhóm
avatar	string	Hình đại diện của nhóm
group_id	string	ID của nhóm
group_link	string	Link để tham gia nhóm
group_description	string	Mô tả nhóm
total_member	integer	Tổng số lượng thành viên trong nhóm
status	string	Trạng thái nhóm:
enabled: OA có thể quản lý và gửi tin nhắn trong nhóm
disabled: OA không thể quản lý và không thể gửi tin nhắn trong nhóm
