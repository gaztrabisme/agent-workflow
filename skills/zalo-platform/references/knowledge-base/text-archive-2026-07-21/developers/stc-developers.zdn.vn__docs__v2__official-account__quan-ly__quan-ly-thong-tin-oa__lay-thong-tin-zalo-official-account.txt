Lấy thông tin Zalo Official Account.
LƯU Ý

Ứng dụng cần được cấp quyền quản lý thông tin OA

HTTP request​
URL: https://openapi.zalo.me/v2.0/oa/getoa
Method: GET
Response Type: text/json
Example request​
curl \
-X GET \
-H 'access_token: <your_access_token>' \
"https://openapi.zalo.me/v2.0/oa/getoa"

Tham số header​

Tham số

	

Kiểu dữ liệu

	

Tính bắt buộc

	

Mô tả




access_token

	

string

	

yes

	

Token cho phép ứng dụng đại diện OA gọi API. Xem chi tiết cách lấy access token tại đây.

Cấu trúc thuộc tính data​

Thuộc tính

	

Kiểu dữ liệu

	

Mô tả




oa_id

	

long

	

ID của OA được lấy thông tin




name

	

string

	

Tên của OA




description

	

string

	

Mô tả của OA




oa_alias

	

string

	

Tên gợi nhớ dùng cho đường dẫn OA




is_verified

	

boolean

	

Trạng thái xác thực của OA
Các giá trị trả về:
• false: OA chưa được xác thực
• true: OA đã xác thực




oa_type

	

integer

	

Loại OA:
2: OA Doanh nghiệp
4: OA Cơ quan nhà nước




cate_name

	

string

	

Danh mục hoạt động của OA




num_follower

	

integer

	

Tổng số người quan tâm của OA




avatar

	

string

	

Đường dẫn đến ảnh đại diện của OA




cover

	

string

	

Đường dẫn đến ảnh bìa của OA




package_name

	

string

	

Tên gói dịch vụ
Chỉ Loại OA Doanh nghiệp mới trả về thông tin này




package_valid_through_date

	

string

	

Ngày hiệu lực cuối cùng của gói dịch vụ
Chỉ OA đang sử dụng gói dịch vụ OA mới có thông tin này




package_auto_renew_date

	

string

	

Ngày thực hiện gia hạn tự động
Chỉ OA đang sử dụng gói dịch vụ OA và có bật tự động gia hạn mới có thông tin này.




linked_zca

	

string

	

Thông tin ZCA mà OA đang liên kết
Chỉ OA đang liên kết ví ZCA mới có thông tin này.
