Zalo PHP SDK  là một thư viện mã nguồn mở, hỗ trợ các nhà phát triển dễ dàng tích hợp đăng nhập Zalo và sử dụng các API của Zalo. Thông qua Zalo PHP SDK, bạn có thể truy vấn dữ liệu người dùng, dữ liệu bạn bè, đăng tin mới với Social API hay chăm sóc khách hàng tốt hơn với Official Account Open API. Để được hướng dẫn cài đặt và triển khai, truy cập mục Bắt đầu nhanh và xem  một số ví dụ cụ thể, qua đó sẽ giúp bạn dễ dàng hơn trong việc tích hợp.
