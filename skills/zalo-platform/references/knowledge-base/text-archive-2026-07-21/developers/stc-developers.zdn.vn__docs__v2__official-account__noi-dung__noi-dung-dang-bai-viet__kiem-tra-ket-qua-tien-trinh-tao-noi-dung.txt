Kiểm tra kết quả tiến trình tạo nội dung

API lấy Id bài viết sẽ giúp kiểm tra tiến độ, cũng như kết quả của tiến trình tạo bài viết.

HTTP request​
URL: https://openapi.zalo.me/v2.0/article/verify
Method: POST
Content Type: application/json
Reponse Type: text/json
Sample​
curl \
 -X POST \
 -H "Content-Type: application/json" \
 -H "access_token: <ACCESS_TOKEN>" \
 -d '{
        "token" : "agkuioska4sd56as82654654asd+fbkjjsj24uicvi=="
}' \
 'https://openapi.zalo.me/v2.0/article/verify'
