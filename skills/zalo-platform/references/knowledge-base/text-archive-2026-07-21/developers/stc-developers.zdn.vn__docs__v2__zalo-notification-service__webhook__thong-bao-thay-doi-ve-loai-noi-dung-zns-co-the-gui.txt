Sự kiện thay đổi về loại nội dung ZNS có thể gửi
LƯU Ý: NỘI DUNG TẠI TRANG NÀY SẼ KHÔNG CÒN ĐƯỢC CẬP NHẬT.

Từ ngày 01/01/2026, dịch vụ ZNS được hợp nhất vào ZBS Template Message. Vui lòng xem tài liệu mới tại: ZBS Template Message.

· V1 (hiện tại): Từ 0h ngày 16/04/2024, ngưng trả về webhook v1.

· V2 (mới): Từ 0h ngày 16/04/2024, trả về webhook v2

Khi có sự kiện thay đổi về cấp độ nội dung OA có thể gửi được phát sinh theo hệ thống đánh giá hoặc theo đề xuất thay đổi từ khách hàng, hệ thống Zalo sẽ gửi đến Webhook Url của ứng dụng một HTTP request như sau.

LƯU Ý

Quyền cần có: Sử dụng Zalo Notification Service

URL: Webhook Url của ứng dụng
Method: POST
Content Type: application/json
X-ZEvent-Signature:mac = sha256(appId + data + timeStamp + OAsecretKey), với data là chuỗi json trả về dưới đây.
[V1]​
Ví dụ:​
{
  "event_name": "change_oa_template_tags",
  "oa_id": "2352868362652028400",
  "tag_level": {
    "prev_value": 2,
    "new_value": 3
  },
  "timestamp": "1602560967477"
}

Mô tả thuộc tính​
Thuộc tính	Mô tả
event_name
String	Tên sự kiện
Giá trị nhận về: change_oa_template_tags
oa_id
String	ID của OA ủy quyền
tag_level
Json Object	Ví dụ:
{
  "prev_value": 2,
  "new_value": 3
}


Trong đó:

"prev_value": Cấp độ nội dung ZNS được phép gửi của OA trước khi cập nhật.
"new_value": Cấp độ nội dung ZNS được phép gửi của OA sau khi cập nhật. Tham khảo phụ lục (*)

timestamp
String	Thời gian hệ thống gửi thông báo
Phụ lục:
(*) Giá trị trả về biểu thị cấp độ nội dung ZNS được phép gửi của OA:
0: OTP, IN_TRANSACTION, POST_TRANSACTION
1: OTP, IN_TRANSACTION, POST_TRANSACTION, ACCOUNT_UPDATE
2: OTP, IN_TRANSACTION, POST_TRANSACTION, ACCOUNT_UPDATE, GENERAL_UPDATE.
3: OTP, IN_TRANSACTION, POST_TRANSACTION, ACCOUNT_UPDATE, GENERAL_UPDATE, FOLLOW-UP.
[V2]​
Ví dụ:​
{
  "event_name": "change_oa_template_tags_v2",
  "oa_id": "2352868362652028400",
  "tag_level": {
    "prev_value": ["TRANSACTION", "CUSTOMER_CARE"],
    "new_value": ["TRANSACTION", "CUSTOMER_CARE", "PROMOTION"]
  },
  "timestamp": "1602560967477"
}
