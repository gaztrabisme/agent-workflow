Sự kiện người dùng nhận tin nhắn từ Official Account

Khi Official Account gửi tin nhắn cho người dùng và tin nhắn đó đã được nhận, hệ thống Zalo sẽ gửi đến Webhook Url của Official Account một request http như sau Quyền cần có:

Sự kiện tin nhắn đã được nhận

Sự kiện này chỉ được gửi về khi user nhận tin nhắn trên Zalo Mobile

URL: Webhook Url của ứng dụng
Method: POST
Content Type: application/json
X-ZEvent-Signature:mac = sha256(appId + data + timeStamp + OAsecretKey), với data là chuỗi json trả về dưới đây.
Ví dụ:​
{
    "app_id": "360846524840903967",
    "sender": {
        "id": "388613280879808645"
    },
    "recipient": {
        "id": "246845883529697922"
    },
    "event_name": "user_received_message",
    "message": {
        "msg_id": "43b59c025aebfb5e6fa"
    },
    "timestamp": "1540363714911"
}

Mô tả thuộc tính​
Thuộc tính	Kiểu dữ liệu	Mô tả
app_id	String	Id của ứng dụng đang nhận sự kiện.
sender	Json Object	Ví dụ:
{
    "id": "388613280879808645"
}


Trong đó:

"id": Id của Official Account gửi tin nhắn

recipient	Json Object	Ví dụ:
{
    "id": "246845883529697922"
}


Trong đó:

"id": Id của User nhận tin nhắn

event_name	String	Giá trị là "user_received_message".
message	Json Object	Ví dụ:
{
    "msg_id": "43b59c025aebfb5e6fa"
}


Trong đó:

"msg_id": Id của tin nhắn.

timestamp	String	Thời điểm request được gửi, tính bằng milisecond
