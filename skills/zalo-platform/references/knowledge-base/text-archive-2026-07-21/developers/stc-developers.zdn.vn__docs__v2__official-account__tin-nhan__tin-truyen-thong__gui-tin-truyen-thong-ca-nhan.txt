Gửi tin Truyền thông cá nhân
🚩LƯU Ý:

Từ 01/01/2026, giải pháp tin nhắn với mẫu tin (template) được ra mắt gọi là ZBS Template Message. Dịch vụ Tin UID Giao dịch (165 vnd) và UID Truyền thông cá nhân sẽ được dừng cung cấp từ 01/03/2026. Xem chi tiết tại đây.

HTTP request​
URL: https://openapi.zalo.me/v3.0/oa/message/promotion
Method: POST
Content Type: application/json
Response Type: application/json

Tham số header​
Tham số	Kiểu dữ liệu	Tính bắt buộc	Mô tả
access_token	string	yes	Token cho phép ứng dụng đại diện OA gọi API. Xem chi tiết cách lấy access token  tại đây.
Cấu trúc body của request​
Tham số	Kiểu dữ liệu	Tính bắt buộc	Mô tả
recipient	object	yes	Thông tin người nhận
message	object	yes	Nội dung cần gửi
Cấu trúc thuộc tính recipient​
Tham số	Kiểu dữ liệu	Tính bắt buộc	Mô tả
user_id	string	yes	ID của người nhận (nhận được thông qua API truy xuất chi tiết người dùng, API truy xuất danh sách người dùng)
Cấu trúc thuộc tính message​
Tham số	Kiểu dữ liệu	Tính bắt buộc	Mô tả
attachment	object	yes	Attachment cần gửi
Cấu trúc thuộc tính message.attachment​
Tham số	Kiểu dữ liệu	Tính bắt buộc	Mô tả
type	string	yes	Loại attachment.

Giá trị nhận vào bắt buộc:

type = template

payload	object	yes	Chứa payload của attachment muốn gửi
Cấu trúc thuộc tính message.attachment.payload​
Tham số	Kiểu dữ liệu	Tính bắt buộc	Mô tả
template_type	string	yes	Loạitemplate.

Giá trị nhận vào bắt buộc:

template_type = promotion

language	string	no	Ngôn ngữ sử dụng của tin

Giá trị nhận vào:

language  = VI
hoặc
language  = EN
Khi chọn ngôn ngữ các nội dung mặc định của mẫu tin sẽ chuyển sang ngôn ngữ tương ứng
elements	array	yes	Các đối tượng của template.

Xem thêm mục message.attachment.payload.elements bên dưới
buttons	array	no	Các nút nhấn CTA (tùy chọn có hoặc không, tối đa 4 button) Xem thêm mục message.attachment.payload.buttons bên dưới
Cấu trúc tham số message.attachment.payload.elements​
Type	Tham số	Kiểu dữ liệu	Tính bắt buộc	Mô tả
banner	image_url	string	yes
	image_url : Đường dẫn đến ảnh
Các định dạng ảnh hỗ trợ: jpg và png
Dung lượng tối đa: 1MB
Tỉ lệ kích thước ảnh (height :width): từ 1:5 đến 1:1 (ảnh vuông)

Lưu ý: chỉ sử dụng 1 trong 2 biến image_url hoặc attachment_id
attachment_id	string	yes
	attachment_id: ID của ảnh bạn muốn sử dụng (nhận được thông qua API upload ảnh)
Các định dạng ảnh hỗ trợ: jpg và png
Dung lượng tối đa: 1MB
Tỉ lệ kích thước ảnh (height :width): từ 1:5 đến 1:1 (ảnh vuông)

Lưu ý: chỉ sử dụng 1 trong 2 biến image_url hoặc attachment_id
header	content	string	yes	Nội dung của header, tối đa 100 ký tự.
align	string	no	Chấp nhận 3 giá trị
left (hoặc để trống): canh lề bên trái
center: canh lề giữa
right: canh lề bên phải

text
Lưu ý: tối đa được 2 đoạn text

	content	string	yes	Nội dung của text, tối đa 1000 ký tự mỗi đoạn
align	string	no	Chấp nhận 3 giá trị
left (hoặc để trống): canh lề bên trái
center: canh lề giữa
right: canh lề bên phải

table
Lưu ý: tối đa 5 phần tử tùy biến	Content	array	yes	Cấu trúc 1 phần tử trong table bao gồm:
2 field bắt buộc:
key  - maxlenght = 25
value  - maxlenght = 100
VD:
{
  "key": "Voucher",
  "value": "VC09279222"
}

Cấu trúc tham số message.attachment.payload.buttons​
Tham số	Kiểu dữ liệu	Tính bắt buộc	Mô tả
title	string	yes	Tiêu đề của button Lưu ý: Tiêu đề không được vượt quá 35 ký tự
image_icon	string	yes	Có thể tryền:
image url của hình ảnh
attachment_id sau khi sử dụng API upload hình ảnh
để trống hoặc “default”: để sử dụng imaeg icon mặc định của Zalo
Lưu ý: Kích thước hình ảnh tối ưu: 100px * 100px
type, payload	object	yes	Tham khảo các loại action được hỗ trợ tại đây
Example respond​
{
  "data": {
    "message_id": "e6fa968f027",
    "user_id": "4356639876691778517"
  },
  "error": 0,
  "message": "Success"
}

Cấu trúc thuộc tính data​
Thuộc tính	Kiểu dữ liệu	Mô tả
message_id	string	ID của thông báo
user_id	string	ID của người nhận
