Danh sách Components

Các components của template, được sử dụng trong API tạo template và API chỉnh sửa template.

Thứ tự và số lượng các components của mỗi template phụ thuộc vào loại template được chọn khởi tạo hoặc chỉnh sửa

Danh sách components​
1. Tiêu đề (Title)
2. Đoạn văn bản (Paragraph)
3. OTP
4. Bảng (Table)
5. Tệp đính kèm (Attachment)
6. Logo
7. Image
8. Button
9. Payment
10. Voucher
11. Rating
Syntax
{ 
  "TITLE": {"value": "<value>"} 
}

Tham số
Field	Tính bắt buộc	Kiểu dữ liệu	Mô tả
value	yes	string	
Bao gồm text cố định hoặc param. Số lượng param ở component TITLE không được vượt quá 4.
Tối thiểu 9 ký tự và tối đa 65 ký tự.
