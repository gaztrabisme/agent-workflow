Gửi yêu cầu cấp quyền gọi
LƯU Ý

Ứng dụng cần được OA cấp quyền sử dụng chức năng gọi thoại

HTTP request​
URL:  https://openapi.zalo.me/v2.0/oa/call/requestconsent
Method: POST
Content Type: application/json
Response Type: text/json
Example request​
curl \
-X POST \
-H 'Content-Type: application/json' \
-H 'access_token: <your_access_token>' \
-d '{
    "phone": "84773543888",
    "call_type": "audio", // audio + video + audio_and_video
    "reason_code": 101
}' 'https://openapi.zalo.me/v2.0/oa/call/requestconsent'

Tham số header​

Tham số

	

Kiểu dữ liệu

	

Tính bắt buộc

	

Mô tả




access_token

	

string

	

yes

	

Token cho phép ứng dụng đại diện OA gọi API. Xem chi tiết cách lấy access token tại đây.

Cấu trúc body của request​

Tham số

	

Kiểu dữ liệu

	

Tính bắt buộc

	

Mô tả




phone

	

string

	

yes

	

Số điện thoại của người nhận.




call_type

	

string

	

yes

	

Loại cuộc gọi muốn thực hiện. Danh sách giá trị:

· audio: Cuộc gọi thoại

· video: Cuộc gọi video

· audio_and_video: Cả gọi thoại và video




reason_code

	

number

	

yes

	

Mã lý do muốn thực hiện cuộc gọi đến người dùng. Danh sách giá trị:

· 101 : Tư vấn sản phẩm / dịch vụ

· 103 : Xác nhận đơn hàng / cuộc hẹn

· 105 : Thông báo giao hàng

· 106 : Thông báo chuyến bay

· 107 : Cập nhật đơn hàng

·        Trường hợp không thuộc các lý do trên: vui lòng liên hệ oa@zalo.me để được hỗ trợ.

Example respond​
{
  "error": 0,
  "message": "Success"
}
