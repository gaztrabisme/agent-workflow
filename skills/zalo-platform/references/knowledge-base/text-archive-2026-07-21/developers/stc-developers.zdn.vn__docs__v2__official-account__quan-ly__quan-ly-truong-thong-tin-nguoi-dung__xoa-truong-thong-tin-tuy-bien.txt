Xóa trường thông tin tùy biến
LƯU Ý
Ứng dụng cần được OA cấp quyền "Quản lý trường thông tin người dùng" để sử dụng API này.
API này chỉ cho phép xóa các trường có field_type là oa_custom.
Không thể xóa các trường có field_type là system.
HTTP request​
URL: https://openapi.zalo.me/v3.0/oa/userfield/delete
Method: POST
Response Type: text/json
Example request​
curl --location --request DELETE 'https://openapi.zalo.me/v3.0/oa/userfield/delete' \
--header 'access_token: <your_access_token>' \
--header 'Content-Type: application/json' \
--data '{
  "key": "ma_don_hang"
}'
