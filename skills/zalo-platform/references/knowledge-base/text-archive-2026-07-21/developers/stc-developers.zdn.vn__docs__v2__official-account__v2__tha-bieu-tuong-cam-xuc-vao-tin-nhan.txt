Thả biểu tượng cảm xúc vào tin nhắn

Quyền cần có: Gửi tin nhắn/Thả biểu tượng cảm xúc vào tin nhắn

HTTP request​
URL: https://openapi.zalo.me/v2.0/oa/message 
Method: POST
Content Type: application/json
Response Type: text/json  
Example request​
curl --request POST "https://openapi.zalo.me/v2.0/oa/message"
--header 'access_token: <your_access_token>'
--header 'Content-Type: application/json'
--data-raw '{
   "recipient": {
       "user_id": "186729651760683225"
   },
   "sender_action": {
       "react_icon": "/-strong",
       "react_message_id": "789f573aecf8a9a4f0eb"
   }
}'

Tham số header​
Tham số	Kiểu dữ liệu	Tính bắt buộc	Mô tả
access_token	string	yes	Token cho phép ứng dụng đại diện OA gọi API. Xem chi tiết cách lấy access token tại đây.
Cấu trúc body của request​
Tham số	Kiểu dữ liệu	Tính bắt buộc	Mô tả
recipient	object	yes	Thông tin người nhận
sender_action	object	yes	Nội dung cần gửi
Cấu trúc thuộc tính recipient​
Tham số	Kiểu dữ liệu	Tính bắt buộc	Mô tả
user_id	string	yes	ID của người nhận (nhận được thông qua API truy xuất chi tiết người dùng, API truy xuất danh sách người dùng)
Cấu trúc thuộc tính sender_action​
Tham số	Loại	Tính bắt buộc	Mô tả
react_icon	string	yes	Biểu tưởng cảm xúc:
:>
--b
:-((
/-strong
/-heart
:-h
:o　
/-remove (sử dụng khi thu hồi biểu tượng cảm xúc)

react_message_id	string	yes	message_id của tin nhắn cần thả cảm xúc
Example respond​
{
    "data": {
        "message_id": "601809c43dd7798b20c4",
        "user_id": "186729651760683225"
    },
    "error": 0,
    "message": "Success"
}

Cấu trúc thuộc tính data​
Thuộc tính	Kiểu dữ liệu	Mô tả
message_id	string	ID của thông báo
user_id	string	ID của người nhận
Lưu ý:​
Một message_id chỉ được thả tối đa 50 biểu tưởng cảm xúc.
API này không bị tính vào quota chủ động hàng tháng.
