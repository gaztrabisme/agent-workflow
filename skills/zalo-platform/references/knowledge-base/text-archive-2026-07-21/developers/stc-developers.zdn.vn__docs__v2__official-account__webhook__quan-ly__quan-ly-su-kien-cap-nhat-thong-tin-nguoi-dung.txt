Sự kiện cập nhật thông tin người dùng

Khi thực hiện cập nhật thông tin cho người dùng hệ thống Zalo gửi đến webhook URL đã đăng ký của ứng dụng.

URL: Webhook Url của ứng dụng
Method: POST
Content Type: application/json
X-ZEvent-Signature: mac = sha256(appId + data + timeStamp + OAsecretKey), với data là chuỗi json trả về dưới đây.
Example request​
{
    "app_id": "360846524840903967",
    "oa_id": "388613280879880645",
    "user_id_by_app":"4840903967328087",
    "user_id":"",
    "event_name": "update_user_info",
    "data": {
        "method":"dynamic_url",
}
    "timestamp": "15503500848",
}

Mô tả thuộc tính​
Thuộc tính	Kiểu dữ liệu	Mô tả
event_name	String	Giá trị là: update_user_info
oa_id	String	Id của Official Account
app_id	String	Id ứng dụng đang nhận sự kiện
user_id_by_app	String	Trường này chỉ có khi app_id và oa_id trên đang liên kết với nhau.
data	json Object	Trong đó
method: là phương thức cập nhật thông tin
dynamic_url: cấp tương tác từ OA URL. Các thông tin về Dynamic url sẽ được lưu lại trong Thông tin người dùng, sử dụng API truy xuất chi tiết người dùng tại đây

timestamp	String	Thời điểm request được gửi, tính bằng millisecond
