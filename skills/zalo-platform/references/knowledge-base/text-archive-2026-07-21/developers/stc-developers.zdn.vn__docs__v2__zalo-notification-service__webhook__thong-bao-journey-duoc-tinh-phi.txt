Sự kiện journey được tính phí
LƯU Ý: NỘI DUNG TẠI TRANG NÀY SẼ KHÔNG CÒN ĐƯỢC CẬP NHẬT.

Từ ngày 01/01/2026, dịch vụ ZNS được hợp nhất vào ZBS Template Message. Vui lòng xem tài liệu mới tại: ZBS Template Message.

Khi có sự kiện tin nhắn ZNS đầu tiên thuộc chuỗi hành trình (journey) được gửi thành công đến thiết bị người dùng và journey bắt đầu được tính phí, hệ thống Zalo sẽ gửi đến Webhook Url của ứng dụng một HTTP request như sau.

LƯU Ý

Quyền cần có: Sử dụng Zalo Notification Service

URL: Webhook Url của ứng dụng
Method: POST
Content Type: application/json
X-ZEvent-Signature:mac = sha256(appId + data + timeStamp + OAsecretKey), với data là chuỗi json trả về dưới đây.
Ví dụ:​
{
     "event_name": "event_journey_acknowledged",
     "journey_id": "928189878372556800",
     "msg_id": "9c7bce8fc761fb3da272",
     "app_id": "4349311699477619340",
     "oa_id": "3886651700907664415",
     "timestamp": "1641368111938"
}

Mô tả thuộc tính:​
Thuộc tính	Mô tả
event_name
String	Tên sự kiện
Giá trị nhận về: event_journey_acknowledged
journey_id
String	ID của journey
msg_id
String	ID của tin nhắn được gửi
app_id
String	ID của ứng dụng
oa_id
String	ID của OA
timestamp
String	Thời gian bắt đầu tính phí journey
Trước
Sự kiện journey hết hạn
