Hàm gọi API Zalo​
client.excuteRequest(String url, String method, Map<String, Object> params, JsonObject body, Map<String, String> headers, Map<String, File> files)


Trong đó:

Tham số	Mô tả
url
String	url tương ứng với api muốn gọi.
method
String	method tương ứng với api muốn gọi.
params
Map<String, Object>	các parameter phụ thuộc vào api muốn gọi
body
Json Object	Chứa dữ liệu của body, tùy vào api mà dữ liệu của body sẽ khác nhau.
headers
Map<String, String>	Luôn có biến "access_token".

các header còn lại phụ thuộc vào api muốn gọi
files
Map<String, File>	Các phần tử phụ thuộc vào api muốn gọi
