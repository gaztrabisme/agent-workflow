Gửi tin nhắn nhóm dạng Text
LƯU Ý

Ứng dụng cần được cấp quyền quản lý thông tin nhóm.

HTTP request​
URL: https://openapi.zalo.me/v3.0/oa/group/message
Method: POST
Content Type: application/json
Response Type: text/json
Example request​
curl --location --request POST 'https://openapi.zalo.me/v3.0/oa/group/message' \
--header 'access_token: <your_access_token>' \
--header 'Content-Type: application/json' \
--data '{
    "recipient": {
        "group_id": "f414c8f76fa586fbdfb4"
    },
    "message": {
        "text": "hello from Zalo"
    }
}'

Tham số header​
Tham số	Kiểu dữ liệu	Tính bắt buộc	Mô tả
access_token	string	yes	Token cho phép ứng dụng đại diện OA gọi API. Xem chi tiết cách lấy access token  tại đây.
Cấu trúc body của request​
Tham số	Kiểu dữ liệu	Tính bắt buộc	Mô tả
recipient	json object	yes	Thông tin người nhận
message	json object	yes	Nội dung tin nhắn
Cấu trúc body của recipient​
Tham số	Kiểu dữ liệu	Tính bắt buộc	Mô tả
group_id	string	yes	ID của nhóm
Cấu trúc body của message​
Tham số	Kiểu dữ liệu	Tính bắt buộc	Mô tả
text	string	yes	Nội dung tin nhắn cần gửi
Example respond​
{
    "data": {
        "message_id": "81d74a9cd71d6f473608",
        "group_id": "f414c8f76fa586fbdfb4"
    },
    "error": 0,
    "message": "Success"
}

Cấu trúc thuộc tính data​
Tham số	Kiểu dữ liệu	Mô tả
message_id	string	ID của tin nhắn mới được gửi
group_id	string	ID của nhóm
