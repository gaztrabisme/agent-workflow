Lấy danh sách admin

API này cho phép bạn lấy danh sách admin của Official Account (OA) với các quyền quản lý khác nhau.

Thông tin Request​
HTTP
cURL
GET https://EXTENSION.zalo.me/v1.0/oa/admin/getlist

Headers​
Tham số	Kiểu dữ liệu	Bắt buộc	Mô tả
access_token	string	Có	Token cho phép ứng dụng đại diện OA gọi API
Query Parameters​
Tham số	Kiểu dữ liệu	Bắt buộc	Mô tả
role_name	string	Không	Quyền quản lý OA, hỗ trợ lọc các giá trị: MANAGER, MODERATOR, INSIGHT_ANALYST, ADVERTISER, CUSTOMER SERVICE, AGENCY
user_id	string	Không	ID của admin cụ thể cần truy xuất thông tin
THÔNG TIN:

Tham khảo danh sách các quyền quản lý OA tại đây.

Response​
Cấu trúc Response​
{
  "data": [
    {
      "admin_id": "186729651760683225",
      "role_name": "MANAGER"
    }
  ],
  "error": 0,
  "message": "Success"
}

Các trường trong Response​
Trường	Kiểu dữ liệu	Mô tả
data	array	Danh sách tất cả admin thỏa điều kiện truyền vào
data.admin_id	string	ID của admin
data.role_name	string	Phân quyền của admin
error	number	Mã lỗi (0 nếu thành công)
message	string	Thông báo kết quả
Ví dụ​
Request
Response
curl --location --globoff 'https://openapi.zalo.me/v1.0/oa/admin/getlist?data={"role_name": "MANAGER"}' \ --header 'access_token: <your_oa_accesstoken>'

MẸO

Sử dụng API này cùng với API Truy xuất danh sách người dùng để lấy thêm thông tin chi tiết của admin.
