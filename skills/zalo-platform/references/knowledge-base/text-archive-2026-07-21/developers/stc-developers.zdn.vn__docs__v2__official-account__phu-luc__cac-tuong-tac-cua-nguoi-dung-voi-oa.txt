Thuật ngữ 

	

Mô tả 




Zalo Official Account (OA) 

	

Zalo OA là tài khoản chính thức của Doanh nghiệp trên Zalo, giúp Doanh nghiệp tương tác với người dùng Zalo cá nhân. 

Xem thêm tại mục Khám phá. 




Zalo App (App) 

	

Ứng dụng của doanh nghiệp khởi tạo trên nền tảng Zalo, dùng để quản lý Zalo OA hoặc các dịch vụ của nền tảng Zalo (ZCA, Mini App,…) 

Xem thêm tại mục Khám phá. 




Zalo Cloud Account (ZCA) 

	

ZCA là công cụ quản lý chi tiêu cho dịch vụ Zalo OA và Zalo Notification Service (ZNS) 

Xem thêm tại mục Khám phá. 




OA ID 

	

ID của OA 




App ID 

	

ID của App 




Authorization code 

	

Mã ủy quyền cho phép ứng dụng gọi API để lấy access token và refresh token.  

Xem thêm tại Xác thực và ủy quyền. 




Access token 

	

Token cho phép ứng dụng đại điện OA sử dụng API 

Xem thêm tại Xác thực và ủy quyền. 




Refresh token 

	

Mã dùng để tạo lại access token khi access token hết hiệu lực 

Xem thêm tại Xác thực và ủy quyền. 




UID 

	

ID của người dùng gắn với OA 




UID by App 

	

ID của người dùng gắn với App 




Admin ID 

	

ID của quản trị viên OA 




Sender ID/ From_ID 

	

ID của đối tượng gửi, tùy API sẽ là UID hoặc OA ID 




Recipient ID / To_ID 

	

ID của đối tượng nhận, tùy API sẽ là UID hoặc OA ID 




Message ID / Msg ID 

	

ID của tin nhắn 




Button 

	

Nút đính kèm (CTA) của Tin nhắn. Xem chi tiết tại đây. 




Element 

	

Thành phần của Tin nhắn. Xem chi tiết tại từng API Tin nhắn. 

Định nghĩa Tương tác ​

OA chỉ có thể gửi Tin nhắn và Gọi tới người dùng sau khi người dùng chủ động tương tác với OA. Tương tác của người dùng với OA có thể gồm một trong các hành động: 

Quan tâm OA 

Gửi tin nhắn đến OA 

Chấp nhận cuộc gọi từ OA 

Nhấn nút Nhắn tin tại trang OA profile 

Nhấn biểu tượng hoặc nút Gọi OA 

Nhấn menu Tương tác nhanh hoặc Menu Dịch vụ chứa giá trị oa.query. Xem thêm các giá trị của button tại đây.
