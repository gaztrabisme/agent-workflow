# Fresh-context review: data dashboard (derived: dogfood 2026-10-02, F8)

Review the whole screen at its intended size, then inspect the data panels. Answer **Yes** only when the whole statement is true; any **No** needs a note describing what to change.

- Can you identify the subject, reporting period, current status and main question from the screen?
- Does one status or data view read first, with supporting views clearly secondary?
- Does every key number show its unit, reporting period and comparison baseline, or clearly say that no baseline is set?
- Does every alert state its level in words, explain its cause or reason, and give a next action?
- Are severity and categories still understandable without colour alone?
- Does each missing-data state name what is missing, why it matters and what will restore the view?
- Do panels intended for direct comparison share the same domain, direction and pixel range?
- Can you read every label and value at the intended size without clipping, collision or zooming?
- Do the displayed values, annotations and source notes agree with the data shown?
- Can you follow the intended reading order without treating a missing target or limit as zero or as evidence that the current state is safe?
