# Measurement: course procedures, independent checks and defaults

Reader: an agent checking a rendered SVG/HTML chart or its source-data mapping. All thresholds below say whether the course supplied them or the skill chose them. The courses often prescribe a comparison or reader test but do not set an acceptance number; no course threshold is invented here.

## T1–T5: brief, data, story and chart choice

|---|---|---|---|
| T1 Reader and question | Answer what the data are, who reads it, what need it serves, where it is used and whether it is print or interactive. ## Markup and status

The render-kit chart root uses `data-rk-chart` and scale attributes; marks use `data-rk-mark` and values; categorical series use `data-rk-series`. Render-kit reports exact checks and review questions for a person who can see the images. Read its `AGENTS.md` contract before changing this markup.

Report each test as **measured**, **vision-judged**, **not judged** or **skipped**. Include values for measures, answer text for vision questions, and reasons for skipped checks. If a threshold is changed, name the project requirement that replaces it and who supplied that requirement.
