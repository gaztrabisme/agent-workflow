# Unit 3 · Creating a Poster

Anchor: 3069 · U3

In this unit, I will start by defining the outlines for the design. Then, I will create sketches and try out colours, shapes, and layouts. What are the methods and techniques you want to apply? In Adobe Illustrator, I'll bring in the building blocks such as graphs and symbols together to create the set\-up of the design.

## Tasks

- ### Sketch Your Ideas 
Practice exercise 3\.1

Looking at the subject and the collected data, see what shapes come to mind and what graphs might be appropriate. Then, grab some paper, pencils, or whatever you're comfortable with and start to practice. You might already have a pretty good idea of how you want to visualize the data but keep some paper nearby for sudden or additional thoughts.


![](https://assets4.domestika.org/course-images/000/028/624/28624-big.jpg)
- ### Create Basic Graphs 
Practice exercise 3\.2

Using RAWGraphs or another tool of your choice, create a bubble graph. You can also experiment with other charts to see what the result would be and if you could use it as a basis. How\-tos can be found online as well as in the additional resources. Save the graph in Adobe Illustrator for later.
- ### Collect Your Resources

In Adobe Illustrator, create several artboards or use the attached template. Then, collect all things, inspirational bits, and ideas you have created so far by copying and pasting them from Excel or RAWGraphs. Save them in different layers so you can later come back.
- ### Create the First Shapes 
Practice exercise 3\.3

When you have successfully created a bubble graph, you can use this as the set\-up for the circles representing the chapters. Copy the layer with the graph and ungroup, release clipping masks and compound paths. Repeat multiple times until every object is an individual one. Throw away elements that you don't need and scale and arrange the circles on your canvas. You will find an example in the additional resources.


![](https://assets6.domestika.org/course-images/000/028/626/28626-big.jpg)
- ### Create Colors and Shapes 
Practice exercise 3\.4

According to your sketches, create the colours and shapes you want the characters from the book to represent. Pick them from the illustrations or other references you have found. Just place them on the artboard you assigned for them and keep this as a backup if you want to change anything later on. Then go ahead.


![](https://assets7.domestika.org/course-images/000/028/627/28627-big.jpg)
- ### Practice Creating Symbols and Using the Type Tool

Symbols are handy when you have to repeat many elements. If you are not familiar with the symbols panel in Adobe Illustrator, I suggest that you take some time to practice how to use it. Then, add your symbols and see how you can edit them. Try to create a type on a path text using the type tool as well. Then, refer back to the video lessons to see how it's done.
- ### Add in Layers

Add the layer for total word count. Next, arrange the chapter bubbles with the characters and add an extra layer for information: the data on the total character count, scaling the character symbols. Feel free to replace this data with any other that you find fascinating.

Then add the layer for locations. Create some rough sketches to illustrate locations from the book. Use the clipping mask and type on a path tool if you want it to resemble my illustrations.
- ### Add the Final Details

Add any extra information that you deem necessary. Introduce your audience to the subject and project, sharing some history and fun facts. Don't forget to add the legend as well. It will lead your audience through your visualization. Add keys like arrows or texts to point out which element shows what.

Last but not least, add a catchy phrase or the subject's name as the title of your project. Try to place it in a way that attracts the eye.

## Additional resources

- ### Useful Materials

**Notebooks**
  
If you are a structured worker or you simply love neat materials, there are some great brands with nice notebooks. However, I don’t want you to feel like you have to purchase these, especially when you don't have the means to buy them. I draw almost everywhere where I find a surface large enough, and I buy the most regular notebooks at the famous Dutch department store Hema. The ones that I use the most are mathematical exercise books. They have a grid, which is very handy when you have to count, draw simple bar graphs, and such. Another thing I do is use the unprinted backs of printouts instead of just throwing them away. That way you save some paper, which is always a good thing, right? 

**Pencils**
  
Just as I mentioned when talking about notebooks, there is no need to have high\-end brand pencils. Just use whatever you have at hand or borrow something out―there's no shame in that and it's even better for the environment!
- ### More Tools

[RAWGraphs](https://rawgraphs.io/)
  
RAWGraphs is an open\-source data visualization tool that you can use online. You can easily paste or upload your data in their environment. I started using RAWGraphs when I participated at Makeover Mondays, trying out several graphs. Not that long ago they increased the variety of graphs you can choose. The documentation on how to create a certain graph is extensive and easy to follow. Try out experimenting with the customization settings to see how you can create something that you like. I mainly use RAWGraphs as a very helpful tool for checking my data and easily creating set\-ups which I then edit in Adobe Illustrator, but you can use the tool for fully designed graphs and export them as SVG or PNG files. You can even embed them in your webpage!

[Adobe Illustrator](https://helpx.adobe.com/support/illustrator.html)
  
If you want to follow the steps as shown in this course, you will need the program Adobe Illustrator. If you don’t have a license, you can get a paid membership instead. What's more, there are several other alternatives, so I hope you find something that you find fitting or are familiar with.
- ### Fonts Used

These are the fonts used in my project. I hope this gives you some ideas, but don't feel like you have to use the exact same ones!

• Back to Black Demo, regular (for the titles)
  
• Forza Book, italic (for the text bubbles)
  
• Forza Medium, italic (for the legend)
  
• Constantia, bold (for the numbers)
