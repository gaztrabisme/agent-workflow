## Choose a tool for the visual idea

Anchor: 3601 · U3 · L10 · 00:09–01:52

In this lesson, we move the ideas and sketches into pixels. As data visualisation has become more popular over recent decades, more tools have appeared. You can carry out the work in whichever tool you prefer; if you are already experienced with one, you can use it. I will show a couple of tools, with more in the resources. The kind of data you have may make one tool a better fit than another.

Two free tools I use often are RAWGraphs and Data Illustrator. Both are free, open-source tools that run in a browser and do not require a login. I recommend Google Chrome, especially for Data Illustrator; it is the most stable version in my experience.

RAWGraphs describes itself as the missing link between spreadsheets such as Excel and Google Sheets and graphic software such as Adobe Illustrator or Sketch. I see it as the link from exploring data in a table, through working on paper, to making the design in Illustrator. I use it for flowcharts, alluvial diagrams, Sankey diagrams, treemaps (captions: “Three maps”), and other forms. It is powerful and intuitive, but it uses templates: you map your data to a particular framework.

## Load and map data in RAWGraphs

Anchor: 3601 · U3 · L10 · 01:52–04:30

When you open RAWGraphs, you can paste data into the white box or upload a file. You can also try one of the sample datasets to explore the tool and perhaps find inspiration for a dataset of your own. I upload the CSV I have already downloaded. CSV stands for comma-separated values (captions: “Common Separated Values file”). RAWGraphs parses 138 rows in a fraction of a second. The first row should contain the labels that describe the data; all the other rows should contain data. The interface indicates whether a field is a string or a number.

Next, choose a chart. Each framework or template has a short explanation and a tutorial. I choose a circular dendrogram because it seems closest to what I want to create. The mapping options change with the selected visualisation. You drag and drop dimensions into the chart’s visual variables. For the hierarchy, I put countries under continents. For size, I use the percentage of the population with access to safely managed water in 2020. I could map income level to colour and use country names as labels.

As I look at the result, I switch from the continent hierarchy to the countries. The circular dendrogram shows the country structure, but I cannot change the circle areas here. I can use the structure and layout, then recreate the visualisation in Adobe Illustrator. That is when I decided to use Data Illustrator for this specific dataset. I still recommend exploring RAWGraphs to see what it can do.

## Move from a template to drawing in Data Illustrator

Anchor: 3601 · U3 · L10 · 04:30–05:52

Data Illustrator is also a browser app without a login. Its site has learning resources and projects where you can see the data, the example, and a demonstration of how each was made. The best way to learn is usually to try it. When I launch the application, its interface is very different from RAWGraphs. The canvas is in the centre, with tools around it. The drawing tools are on the left, alongside a data panel that gives an overview and a Layers panel where drawn objects appear. The imported-data panel previews the table. On the right, you can link what you draw to the data.

The main difference is that Data Illustrator starts with drawing rather than a template. You can make a freehand shape such as a path, then use the panel to link visual variables such as width, height, area, or colour to data points. Before data is imported, those options are not available.

## Prepare the data for the prototype

Anchor: 3601 · U3 · L10 · 05:52–07:27

Before importing the dataset into Data Illustrator, I clean and format it with just one row of labels. I add a Change Pos vs Neg column as a tagging system: it groups each numerical change as positive, no change, or negative. I filter the values and replace the numbers with those category strings. I also reduce the four income levels to a binary format: high income and others. Some countries are undetermined, so I use high income versus the rest of the world.

After highlighting a few rows, I rank the dataset alphabetically by country, then by continent, then by income. To match the sketch, I add a row under each region to create a space between regions. Once the table contains what I need, I download it as a CSV.

Anchor: 3601 · U3 · L10 · 07:27–08:56

I upload my own dataset. The app previews how it parsed the table, including qualitative strings and numerical values, and gives a summary.

I also add 0 and 100 to the past and present values as a shortcut to make the scale complete. Otherwise, Data Illustrator would use only the smallest and largest values in the data. Now we can draw from the sketch. I want two segments to make up a stacked bar chart, and a third line to connect the bar to its label. I draw two lines and add the third connector. For now, I do not worry too much about the connector. I make one line blue to represent the change from 2000 to 2020; the other represents the 2000 position. The connector can be much thinner. I want the lines to have the same width and to align neatly. Where they overlap, I move them by four points. I can also select elements in the Layers panel.

I add two text boxes, one for the value and one for the country name. I align and position them, then change their text. This is not the final typeface, but Helvetica gets me close to the intended look. Even a prototype deserves a little craft.

## Repeat the drawing for each country

Anchor: 3601 · U3 · L10 · 08:56–10:52

These elements are what I want to repeat for every country, so I group them and use the repeat function to duplicate the group by country. I can drag the green handle down to make the next countries appear in the same order as the exported data: Algeria, Central African Republic, Chad, and then the rest. There is a long list, so I can double-click and select one group, then set the count. The count is 146 groups. This is more than the 138 countries because I added blank separator rows between regions. I also reduce the gap between rows.

## Bind the marks and labels to the data

Anchor: 3601 · U3 · L10 · 10:52–14:05

Now I can bind the visual attributes to the data. There is a selector for everything and an individual selector. I use the individual selector to choose an anchor point and bind it to the 2000 data, which is the base of the stacked bar chart. I select the dark-blue line again and bind its left anchor point’s x value to the past, so it coincides with the other point. I bind the right anchor point to the present. I merge its scale with the first scale because all of the data points use the same axis.

Data Illustrator treats a line as both a segment and a set of anchor points. I can manipulate those points and make the 2020 point more visible. I can also colour the segment according to whether the change is positive, negative, or unchanged, using the three category values.

Next I bind the text. I select the first text box and click the link beside it, then bind it to the 2020 value so readers can see the current percentage of the population with access. I bind the second text box to the country name. I select a repeated example and bring it into place; as I move the point up or down, I keep the marks aligned. I should occasionally see an orange line because those are the fake data entries I added to create the region breaks. Finally, I check that the scale runs from 0 to 100. The prototype is done. I can save the project and export an SVG.

With prototyping tools such as RAWGraphs and Data Illustrator, I can build a quick skeleton without writing code, create visual variables, and link them to the data. I may try different frameworks and tools and compare what each can do, even with the same dataset. I am happy with the Data Illustrator prototype; in the next lesson I will refine it in Adobe Illustrator.

### Key points (derived)

- RAWGraphs maps a dataset into a template; Data Illustrator lets you draw a form and bind its visual properties to data.
- Prepare the table to fit the intended design: tag the changes, reduce uncertain income categories, sort the rows, and add separator rows to make regional gaps.
- In Data Illustrator, repeat the grouped marks by country, bind their anchor points and labels to the relevant fields, and keep all values on a shared 0–100 scale.
- Treat the result as a prototype: test it against the data, then refine the chosen form in a full design tool.
