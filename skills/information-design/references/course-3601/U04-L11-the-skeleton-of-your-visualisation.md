## Building the circular graph and placing its content

Anchor: 3601 · U4 · L11 · 01:43–03:56

The artwork already contains a few rough shapes based on the sketch from the previous lesson: two circles, which will become semicircular data displays. The left half will represent high-income countries and the right half the rest of the world. The goal is a circular dendrogram, built by applying a brush to the circles’ strokes. A brush can be applied to any stroke, turning a plain circle into a visualisation. Before getting there, I need to clean up the prototype and prepare it to become a brush.

There are also placeholder boxes for an overview of the world, statistics comparing 2000 with 2020, and a world map showing missing data. A reference panel on the left will establish the visual grammar, which at this point consists of type and colour. We discussed colour in the sketching lesson, so I will not go into detail yet; we will return to it later. The map and statistics are placeholders; the type and colours are the first parts of the system to settle.

## Establishing a consistent type system

Anchor: 3601 · U4 · L11 · 03:56–05:58

I like to make the small design decisions early, then refine them as the work develops. Starting with a system makes it easier to keep the finished piece consistent. Typography is one part of that system. An untypeset paragraph looks like a blur: to understand it, the reader has to work through it line by line, with no shortcut. The same copy becomes easier to read when its structure creates hierarchy and focus. The styling should be consistent with the kind of information shown: a definition should look different from example text, and a title should be treated as a title.

When creating colour and type styles, use global styles. If I later refine or update a text style, or add more country layers, changing the style once can update every matching label. The same principle applies to colour: define global swatches and objects that use them change together. For example, if a hundred blue circles need a different shade or tint, changing the global colour updates them all. This is a tidy way to keep the design consistent in Illustrator.
The course resources also explain how swatches work in Illustrator.

## Organising the prototype into layers

Anchor: 3601 · U4 · L11 · 05:58–07:54

When I select the prototype from Data Illustrator, everything is grouped together. I ungroup it and reorganise its contents into layers. The finished prototype should have one layer for the lines connecting countries to regions, which form the dendrogram; one for all the copy; a separate layer for the 2020 point; separate layers for positive and negative change; a layer for past change; and layers for the guides and the dendrogram. To select items efficiently, choose an object and use Select Same Stroke Color. Illustrator then selects the objects sharing that colour, which can be moved into a layer and renamed. Repeat the process for the other selections.

Once the layers are organised, remove the unnecessary data points that were only placeholders for gaps between regions. Reorder the layers by dragging them so that elements that belong on top are on top. The prototype’s country rows use a legend for positive, negative and unchanged movement.

## Drawing and repeating the connecting curves

Anchor: 3601 · U4 · L11 · 07:54–09:58

The connecting curve that forms the dendrogram can be drawn with the Pen tool. Draw a line, inspect its anchor point and add a stroke; then adjust the point to get a smooth curve. A line can also be drawn with the Line Segment tool (captions: “light segment tool”), but its anchor point then needs to be edited with the appropriate tool. Either method works.

To repeat the line, choose Effect, Distort & Transform, Transform. You can scale the duplicates as well as move them. In the dialog, set how many copies to make—in this example, 146—and move the duplicate segments down. You can estimate their spacing from the y-coordinates of two grey guide lines and subtract one from the other, or set the spacing by eye. After expanding the appearances so each copy is an individual line, align the first and last lines. Select the set, align them, then use Direct Selection on the end anchor point to finish the alignment.

## Simplifying the scale and preparing the brush artwork

Anchor: 3601 · U4 · L11 · 09:58–11:53

With the dendrogram structure in place, I continue through the countries. I also simplify the scale: instead of marking every ten percentage points, I keep only 25%, 50%, 75% and 100%. Those quarter marks make it easier to read one in four people, half the population, three quarters, and so on. This is another way to declutter the information.

Now the prototype is ready to become a brush. I return to the spread template, select all the prototype layers and copy them into the design file. They arrive much larger than the spread, so I scale them down to 70%. This takes some trial and error: imagine the graphic wrapped around the circle and estimate how long it needs to be to fit the circumference.

There are two approaches. Use the full circumference as one brush, or split it into two parts and make one brush for high-income countries and one for the rest of the world. Whichever approach you choose, keep the spacing between countries consistent. The two brush patterns should have equal total height, so add blank spaces to the shorter high-income group until its segment matches the rest-of-world pattern. I’ll demonstrate the full circumference first, then break it apart; you can explore the alternatives.

## Creating the circular dendrogram with Art Brushes

Anchor: 3601 · U4 · L11 · 11:53–13:42

I have kept two versions of the source: one with editable text and one with the text expanded. To expand it, choose Object, Expand; this converts the text into shapes. A brush cannot read text, symbols or gradients, though other artwork is usable. In Outline mode, toggled with Command-Y, I added a couple of invisible points. They let me separate the labels from the graphic and build them as different brushes while keeping both at the same height. A top line aligns with the end point as well.

Select all the text, including the top line and lower point, open the Brushes panel and drag the selection into the panel. In the dialog, choose Art Brush. Because the artwork is a long pattern, Illustrator reads it in one direction; choose the direction that wraps the pattern around the stroke. Do the same for the country graphic and make it an Art Brush. The circles have already been placed where they seem to fit the layout.

## Placing and replacing the country labels

Anchor: 3601 · U4 · L11 · 13:42–14:59

I do not want the brush-generated country text to be the final labels because it is distorted. I copy the country labels separately. Unfortunately, this takes manual work; I would like to know if there is a shortcut. Select a label, use the rotation function and set its centre at the middle of the circle. Option-click the centre to enter a precise angle, preview it and copy the label. Then press Command-D to duplicate it repeatedly around the circumference. After the full circle is labelled, replace the temporary labels with the names from the spreadsheet. Copy and paste rather than typing each name so you avoid spelling errors. It is a tedious step, but it prepares the layout for the next lesson. The circular graphic is taking shape.
