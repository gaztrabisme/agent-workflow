## Return to the visualization with fresh eyes

Anchor: 2495 · U4 · L16 · 00:00–01:55

I return to the text, correct a few typos, and plan to check it again later to make sure none remain. Before doing that, I suggest taking a break or working on another project, then coming back to the visualization with fresh eyes. A pause helps me leave the intense workflow I have been immersed in and return with a new perspective. The point of view I want to explore is always the user's.

After my break, I ask whether there is anything else I can do to improve the visualization and help readers use it. I want to use visual variables to show insights and add information. The first insight is whether each country's per-capita emissions increased or decreased from 2000 to 2019. I decide to use color: I check the countries one by one and select those whose emissions increased. I lock the levels I am not interested in so the countries are easier to select. I use a temporary color for now and will refine the palette later.

This is my first use of color as a variable in the visualization. Color is a strong visual variable, so I use it carefully and avoid using too many colors, which could make the visualization difficult to read. The additional resources include helpful articles about color in data visualization.

## Mark changes in emissions and peak years

Anchor: 2495 · U4 · L16 · 01:55–03:34

After showing the increase insight, I start using another color for countries whose emissions decreased. These colors will be refined later. The second insight I want to show is the year in which each country's per-capita emissions reached their highest value, which can help readers understand trends. To find it, I return to the Illustrator tab and sort each country's per-capita emissions in ascending order (captions: “sending order”). For Australia, the peak is in 2004.

I return to the visualization, make a new layer, and choose a circle as the symbol. I place it by the relevant country and use the same color as the shape. I repeat the operation for every country. Splitting the screen makes it easier to move between the table and the visualization. For Austria, the peak year is 2005 (the captions render this as “1,005”).

## Add and check the peak-year marks

Anchor: 2495 · U4 · L16 · 03:34–05:56

I continue country by country, sorting the per-capita CO2 emissions in ascending order and placing a dot at the year with the highest value. I do the same for Canada and match the dot's color to the shape. These small, additional layers of information let the visualization show insights and more detailed stories from the dataset. For example, a country's highest emissions from twenty years ago tell a different story from a peak two years ago, so I think this is interesting information to show.

I repeat the operation for all the countries and then check the data again. I discover that I had entered the wrong year for Australia. That can happen, which is why it is a good idea to check that the work has been done correctly and look for errors and mistakes.

## Explain the new marks in the legend

Anchor: 2495 · U4 · L16 · 05:56–07:42

I add this information to the legend, in the section for the curved lines. Because the dot is a new rule, I create a short paragraph, use an arrow again, and take one shape as an example. I want a clear, short sentence that explains what the dot does: it highlights the year with the highest data for each country within the indicated time range. I will arrange the space better during the final phase. (The captions read “error” for “arrow.”)

I also explain the colors with simple sentences. Then I return to the comment about Turkmenistan's GDP: we have a value only for 2018, so I add a note beside the country to show that it is an exception to the 2019 GDP rule. The graphic reads “(2018 data)” (the captions say “2019 GDP data”).

## Add 2019 emissions values and complete the guide

Anchor: 2495 · U4 · L16 · 07:42–10:00

I copy the last number I want to add: annual CO2 emissions. I give it a different color so readers can distinguish it from the other values, and place it below the years. I return to the data table, select the countries again, and this time look only at the 2019 data. I sort those values and copy each country's annual emissions number into the visualization. These are complex numbers, so I add a comma after every three digits to make them easier to read. I also keep the spacing between the different text labels consistent so the result looks organized and clean.

Instead of writing all the numbers, another option is to make a legend with two, three, or four sample values and explain what quantity of emissions each one represents. I choose to show the numbers, but readers can use a legend with different sample circle sizes for this part.

## Test the visualization with other readers

Anchor: 2495 · U4 · L16 · 10:00–11:15

Now that I have designed the visual elements to help readers understand the piece, it is important to test them. My parents are my favorite testers because they are not data visualization experts and represent most of my potential readers. I send them work in progress, including the legend and explanatory text, to find out whether an external reader can understand the guides I have made.

Taking a moment away from work while it is still in progress and showing it to someone else helps me avoid getting trapped in my own perspective. When I return to a project after sending it to my parents or friends, I often have new ideas for improving it even before I read their comments. I suggest showing your project to someone else, testing whether it is clear, and listening to their feedback. Their feedback can be extremely valuable. In the next lesson, we will work on final touches that make the project both communicatively and visually effective.
