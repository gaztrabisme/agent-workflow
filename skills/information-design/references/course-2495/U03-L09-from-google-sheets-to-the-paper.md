## Assign visual roles to the contextual and main data

Anchor: 2495 · U3 · L09 · 01:08–02:33

I can now consider a visual representation and the visual variables I might use. GDP and population are contextual information. I want to use them to position each country on the page, so position is the visual variable for these two measures. A scatter plot could do this: population on the horizontal axis, GDP on the vertical axis, and each dot representing one country.

Per-capita emissions over time are the main data, so I need a representation that can show a timeline. This is the central information (captions: “Wind is my central information”). I want to find an interesting shape for it, and I will look for visual inspiration in the next lesson. I also want to include total annual emissions, represented as circles of different sizes.

## Define an initial visual language

Anchor: 2495 · U3 · L09 · 02:33–03:35

I have begun sketching the visual variables and defining an initial visual language for the visualization. These are the rules I have chosen, but you can select your own visual variables and define your own visual alphabet.

I will use GDP and population to contextualize all the countries. For the main information—the per-capita emissions and total emissions—I will use size, along with a new visual variable that I will create after looking for visual inspiration. The central message will be about CO₂ emissions, while additional layers can give context about the countries being explored. Now that we have a first idea of the overall structure, we can move on to the next phase: visual inspiration.
