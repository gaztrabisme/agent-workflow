# Unit 3 · Setting the Project in Motion

Anchor: 2495 · U3

In this unit, we will start working on our main activity. We will tackle the first step: the data! I will show you how to find official and reliable sources and how to explore them to find the data and the stories you are interested in telling. Then I’ll show you how to import and explore the dataset using Google Sheets. Finally, I will guide you through that essential shift from a table to a visual representation.

## Tasks

- ### Explore the Sources and Find a Topic

I’ve shown you the sources I’ll use for this activity and the topic I’m interested in communicating. Now you can select yours! You can decide whether to choose the same topic I’m showing or to explore a subject you are particularly curious or passionate about.
- ### Choose Your Data and Download It

Now that you have selected a topic you can choose the datasets to be used and download them. You will find in the additional resources the links to download the ones that I’m going to use, but feel free whatever data you want.
- ### Create Your Dataset on Google Sheets

Now you can create your own dataset on Google Sheets. If you have decided to use data that are different from mine, make sure that the data structure is not too different from the one I’m using. 

For example, you could use a list of countries, or cities, or books, or movies and then 2 or 3 columns (or more) of data for each one of them.
- ### Explore the Dataset with Google Sheets

If you have never used it, learn how to use Google Sheets. You can use the filter option that I’ve shown in the second lesson to filter and order your data.
- ### Start Sketching 
Practice exercise 3\.1

After having created your dataset, you can start sketching. Start by writing down your variables to recap the information and also to abstract the overall structure. You can also begin sketching out some possible visual representations. In the next unit, we’ll dedicate some time to the phase of visual inspiration. There is still time then to explore potential solutions (and also change your mind!).
