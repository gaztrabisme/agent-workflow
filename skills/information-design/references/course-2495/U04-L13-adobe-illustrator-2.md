## Recreate the country shapes against the reference grid

Anchor: 2495 · U4 · L13 · 00:00–03:01

After repeating the earlier operation for all the countries, I use that base to draw the shape I designed. I recreate it more accurately by following the circular reference, using a lighter, thinner stroke. I repeat the construction with Object > Transform > Transform Again, then refine it so each line aligns precisely with the grid.

Once the shape is grouped, I resize its lines to the grid. Before that, I select the lines for 2005, 2010, and 2015 and give them a thicker 1.2 stroke [captions: “ticker stroke”]. That is the first guide for helping readers recognize the years. I can adjust the details later; the first reference is already useful.

I drag the shape [captions: “ship”] into position so I can reuse it for every country, then resize it curve by curve. Patience is part of making custom visualizations. These are good moments for music, a podcast, or an audiobook; I especially enjoy Agatha Christie audiobooks because they relax me.

I use the squares as a reference: the shapes are organic, but I still want them to be accurate. After finishing the first, I move to the second and keep the original shape nearby so I can reuse it. If a shape is too small and difficult to edit, I can start from the last curve instead. I hold Shift while resizing so the curves stay properly proportioned.

## Adjust the reference and line weights for easier editing

Anchor: 2495 · U4 · L13 · 03:01–05:50

If the graph is too dense to work on, I can ungroup it and change the stroke so the curves are easier to see. The squares may no longer be necessary as a reference; the other guide is more precise. I repeat the process for version two and, for Belgium, prefer to start from the last year.

The zoom shown so far is ordinary, but careful work needs both a very close view—1,000% or more—and a view around 50% to check the overall composition. If detailed elements are difficult to resize, I can remove the squares because they are not needed in this case, ungroup the chart, and edit it as a vector file [captions: “Victoria file”]. Changing line thickness also makes the points easier to see.

I keep a thicker stroke on the element that provides the correct size, and make the grid lighter. This is a quick way to use hierarchy for my own eyes as well as for the readers: varying line thickness makes information easier to inspect. We will use similar refinements later for the readers.

## Build and align a guide grid

Anchor: 2495 · U4 · L13 · 06:55–10:10

I now create a grid. The numbers currently on the graphic were only there to establish the order of the countries; I want visual guides that show how the countries are ordered along both axes. I create a new layer with vertical and horizontal lines, one for each country. The lines will be dashed, and the grid will sit over the bubbles.

Each line should eventually stop at its country rather than run to the edge of the scatterplot, so it does not add unnecessary visual noise. I leave the lines long at first because it is easier to assign one to each country, then resize them. I duplicate the first line with Command+D. The lines do not need to be aligned yet: I align the first and last grid lines to the first and last circles, select the set, and use Horizontal Distribute Center. I repeat this for the horizontal lines with Vertical Distribute Center.

I shorten each line to the centre of its circle, avoiding extra line length that would create visual noise. I do this for all the circles. The finished grid will also give me reference points for placing the country shapes.

## Separate the layers, recolor the shapes, and space the countries

Anchor: 2495 · U4 · L13 · 10:11–13:26

I select the grid lines by their stroke color, then create a separate per-capita-emissions layer. I prefer to keep the different visual representations and stages on their own Illustrator layers. I preserve the shapes in place so I can keep track of which country each belongs to, and duplicate them with Command+F and Command+B. The old working layer is blocking progress, so I no longer need it; I create a new layer containing only the correct shapes.

I begin changing the pink to a darker, reddish color with Recolor Artwork. I select the elements with the colors I want to change, open the advanced option, and drag the pink color to the red swatch. I will refine the color later.

Before moving the shapes onto the scatterplot, I give the countries more room because they are too close together. I redistribute the vertical grid lines with Horizontal Distribute Center, then repeat the operation for the circles by selecting one and choosing Select Same Fill Color. I do the same for the country names.

I can delete the temporary ordering numbers now that I will show the actual population and GDP values. I keep the country labels because they are useful. I also draw a reference line, repeating it with Command+D.

## Place and scale the shapes, then save a new version

Anchor: 2495 · U4 · L13 · 13:27–15:44

Now I am satisfied with the size and drag the shapes onto the scatterplot. I move each shape closer to the artboard so it is easier to work with, beginning with Australia. I centre it on its bubble and repeat the process for every country. I am using 20 countries here, but 10 is already a good number if that is more comfortable; I also often use 30 or 50.

The visualization is taking shape. I select the shapes and use Object > Transform > Transform Each to change the size of each element individually. The horizontal and vertical scales should stay equal. Now that the shapes are plotted on the actual graph, I can see where small adjustments would improve them, then adjust any shape that has moved.

I next want to work on typography and alignment because the text is not yet readable. I am going to download fonts from Google Fonts. Before changing the text, I save the file as a new version. Keeping versions makes it possible to return to an earlier stage and lets me see how the project has evolved.
