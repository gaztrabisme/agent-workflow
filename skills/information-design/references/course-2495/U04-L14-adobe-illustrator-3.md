## Choose a font with enough styles for the visualization

Anchor: 2495 · U4 · L14 · 00:00–01:00

I use Google Fonts often because it has many free, well-designed fonts. I can filter by categories and font properties, then test how the fonts look. I especially like serif fonts, so I browse those options and select one that works for this visualization.

I always check how many styles a font includes. I want at least regular, bold, and italic, because I will use different styles to show hierarchy and help readers find insights in the visualization. A font with enough styles works for me, so I download it and use it in the project.

## Set consistent typography and check label spacing

Anchor: 2495 · U4 · L14 · 01:00–03:01

Back in Illustrator, I put all the text on a new layer and start changing its alignment. I choose Amiri Bold for the country names because they are one of the main pieces of information, and increase their size slightly.

I establish a consistent rule for positioning the names. With Command+K, I open Preferences and set the keyboard increment to 4 pt. I want each country name to sit 4 pt from the centre of its circle. I use the same spacing rules for every element so the visualization stays orderly, even though it combines organic shapes with a carefully organized layout.

I review the overall composition and move the labels up a little so they do not overlap the grid lines. I check the exceptions one by one for overlaps or anything else that needs adjustment.

## Add the GDP and population values from the source data

Anchor: 2495 · U4 · L14 · 03:01–05:47

I now work on the axis labels. The countries are positioned according to their GDP and population, but the graphic does not yet show the actual values. I want to add those numbers, so I return to the dataset and the RAWGraphs tab to get the needed information.

I start with GDP, sort the countries in descending order, and simplify the numbers by changing the decimal places. After copying them into Illustrator, they appear as one block of text. Object > Flatten Transparency turns them into separate text objects, which I can ungroup and use individually. I align the first and last values with the ends of the axis, then distribute the objects vertically by their centres instead of positioning them manually.

I repeat the process for population, this time sorting the countries in ascending order. These values are in thousands, so I will make that unit clear on the graphic. I copy and simplify the data, flatten the text, and ungroup it. I rotate the labels, align them, and distribute them horizontally. With Transform Each, I keep the scale the same while changing the angle so the numbers are readable. I align the first and last labels with the countries, then realign the rest.

## Label the axes and explain their units

Anchor: 2495 · U4 · L14 · 05:47–08:17

I copy the column titles to the axis labels so the organization of the countries is clear. For the vertical axis, I write that the countries are ordered by GDP. I return to the source to check the GDP data and add the unit and year. I do the same for population.

The legend will be developed in more detail later, but I start recording the ordering rules now: countries ordered by GDP, and countries ordered by population. I refine the explanation so it is clear what the displayed numbers mean, including the population unit and the GDP value. I specify that the GDP values are in US$ millions for 2019 [captions: “20 minutes”]. Once those labels explain the axes, I delete the temporary axes to make the composition cleaner.

## Add per-capita emissions values for the first and last years

Anchor: 2495 · U4 · L14 · 08:18–09:37

The remaining numbers to add are the main information: per-capita emissions for the first and last years shown. I select the year, then organize the data by country. I copy the values for all countries and keep one digit after the decimal point.

I leave the values irregular, align them, and keep the same distance between each value and its country name. I repeat the operation for every country. With these labels in place, the main elements are ready. In the next lesson I will work on the legend, explanatory text, and feedback, which connect the visualization to its readers.
