## Choosing and applying a typeface

Anchor: 4217 · U4 · L16 · 00:09–02:17

I begin by changing the typeface, because I am tired of the one currently in the graphic. I use Google Fonts to download free fonts. Its menus let me choose categories and filter the results. I want a serif font, and I check the number of styles because I need several options: at least about four, including bold and italic versions that I may use in the legend. I turn on that filter, look through the choices, and select Amiri. I like its regular, italic, and bold versions, so I download the family and return to Illustrator to change the country labels.

## Refining labels, hierarchy, and spacing

Anchor: 4217 · U4 · L16 · 02:17–08:01

Back in Illustrator, I change the country font and reduce its size. I look for problems, such as Argentina being too far from its mark and the Argentina shape looking odd. I check for overlaps, reduce the text size a little more, adjust the tracking, and move the labels slightly to the left. I customize individual labels where a detail needs attention, and use the same font for the grid.

I like the curves, so I make them black but slightly thinner. Then I resize the whole composition to fit, center it, and select only the grid to adjust it.

## Choosing a palette from the references

Anchor: 4217 · U4 · L16 · 08:01–10:37

I return to my references and choose a green that I like. I generally want a gray background, and I want the leaves to use a green similar to the one in the reference. I first change the color with Fill and Stroke. For more detailed adjustments, I use Recolor Artwork. I select the leaves, hold Shift, and select the population layer as well. Recolor Artwork lets me change the color of all elements that have that specific color. In Advanced Options, I see only the colors belonging to the selected elements. I choose one of them and adjust it, making sure that Recolor Art is checked so the changes appear in the artwork.

Color is enjoyable to refine, but in this piece the information is carried by other visual variables, which is why I have left the palette until this stage. If color were displaying essential information, I would work on it near the beginning. I definitely want to [unclear] [caption: “McDantyner”].

## Adjusting marks and layers, then choosing another data layer

Anchor: 4217 · U4 · L16 · 10:37–15:22

I realize I did not make a group for all the bar charts, but it is not a problem. I select them, lock the population layer so I select only the bars, use the eyedropper to choose a color, then unlock the population layer. I open Object > Transform > Transform Each and scale the bars horizontally so they are wider. I give them a slightly different, darker color and put them on another layer. I make the grid lighter (the caption reads “Nighter”). I correct a few mistakes by moving some leaves down, and move the leaves layer above the bar-chart layer.

I draw an arrow that I will use later in the legend. In Stroke > Arrowheads, I choose the arrowhead I want; if it appears on the wrong end, I swap the ends.

## Finding and filtering fossil-fuel data

Anchor: 4217 · U4 · L16 · 15:22–18:16

I return to Our World in Data and search for fossil fuels. There are several articles and charts. One example is the global consumption chart; the one I want is “Fossil fuel consumption: which countries use the most energy from fossil fuels?” The value is expressed in terawatt-hours. The data can be viewed as a map, a chart, or a table, and I download it as a CSV (the caption reads “CSO5”). I import it into the existing workbook instead of creating a new spreadsheet.

I keep only the year 2020, which is the most recent year in this dataset, then sort the values in descending order to find the top 20. I remove rows that refer to regions or continents rather than countries and use the count tool to see when I reach 20. The list ends at Taiwan. I delete the other rows that I do not need.

## Comparing the lists and marking matches

Anchor: 4217 · U4 · L16 · 18:16–20:57

I split the screen so I can see the table beside my Illustrator file and compare it with the 40 countries already in the visualization. There are matches. I create a layer called “fossil fuels” and keep the mark simple: I add a small mark on each country that also appears in the top-20 table. I start with Canada and Brazil. To check a country such as Ecuador carefully, I use Command-F to search for its name and confirm that it is not in the table. I repeat the comparison for the rest of the countries and mark every one that appears in the top 20. It is a small extra layer of information that I will explain in the legend. I also change the background color. The graphic is nearly finished; in the next lesson I will work on the legend and text.
