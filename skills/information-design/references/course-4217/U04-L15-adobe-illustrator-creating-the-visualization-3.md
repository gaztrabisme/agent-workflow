## Scaling the leaves and reducing overlaps

Anchor: 4217 · U4 · L15 · 00:11–03:08

I visualize all of my countries, and the project is beginning to take shape. I see too many overlaps, so I enlarge the composition while preserving its proportions. I select everything, including the countries below the chart, because I will work on those next. I then make the leaves slightly smaller relative to the rest of the graphic. The overall composition becomes larger while the leaves take up less room, which should reduce the overlaps.

I have placed the leaves on a separate layer. I recommend putting each new element, or new level of information, on its own layer so that it can be selected with one click. I select all the leaves and open Object > Transform > Transform Each. I set the horizontal and vertical scale to 80%, keep the anchor point at the top so that the transformation does not create an unwanted gap, and switch the preview on and off to compare the result. There are fewer overlaps. I am not completely sure about the size, so I return to Transform Each and make the leaves a little larger. This back-and-forth testing and changing very small details is part of my process, even when nobody else will notice them. I may remove some leaves later to close gaps, but I can refine those details in a second pass.

## Aligning and rotating the country labels

Anchor: 4217 · U4 · L15 · 03:08–09:31

Next I work on the labels. I reduce their size and plan to change the font later. First, I align each label with its bar. Using the method I showed earlier, I click Canada, then the first bar, hold Caps Lock, and click the bar again to make it the anchor object. I use Horizontal Align Center so that the label moves into alignment with the bar while the bar stays in place. I repeat this at the other end of the list, move the Philippines label so the countries are in the correct order, then select the labels and distribute them evenly.

I first position the labels below their shapes, then create a layer called “countries” for them. To give every label the same spacing from its shape, I open Illustrator’s preferences with Command-K, or through Illustrator > Preferences > General, and set the keyboard increment. The arrow keys then move an element by a consistent amount. I bring the labels closer to their shapes, then set the keyboard increment [caption: “Bon appetit”]. I then try 3 and later 20. I use Shift while moving to constrain the movement horizontally and repeat the adjustment for all the countries.

I do not always like vertically integrated labels because they can be difficult to read, so I rotate them slightly with Object > Transform > Transform Each. Some overlap is acceptable if it helps readers connect a label to its mark while keeping the composition clean. I will revisit small label details after changing the font, rather than spending time on them now.

## Adding the grid

Anchor: 4217 · U4 · L15 · 09:31–12:04

I add a grid to help readers look at the data. I use the grid as a reference, ungroup it, and resize it. I copy it and paste it in front with Command-C and Command-F, then make a grid layer that can also hold the numbers. With the eyedropper tool, shortcut I, I sample the style of another element. I may need to reduce the whole composition again so it fits the artboard, but for now the proportions are what matter.

I make the grid lines thinner. To create dashed lines, I open Stroke and set the dash length and gap. I will refine the grid later. I am also comfortable starting in black and white and adding color afterward when color is not carrying essential information.

## Adding population circles

Anchor: 4217 · U4 · L15 · 12:04–16:16

The last information layer I add here is population. I return to the table and check that its row order matches the visualization. I copy the population column and use Illustrator’s Pie Graph tool.

I confirm and ungroup it a few more times.

I use the eyedropper to sample a background color, then adjust the population color so it is distinct. I make a separate layer for the population data. As with the country names, I align the first circle to its reference bar, use Caps Lock to set the bar as the key object, repeat at the other end, and distribute the other circles evenly. China is clearly the largest, so the data are correct. The circles are too small, so I enlarge them with Object > Transform > Transform Each. I set their opacity to Multiply so I can also see the overlap, then move the circles into the positions I want. The graphic is now ready for the refinement work in the next lesson.
