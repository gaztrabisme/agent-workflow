## Exporting the desktop visualization

Anchor: 4217 · U4 · L19 · 00:00–02:15

In this lesson I work on the final details, consider what devices readers will use, make a mobile version and export the project. The output determines the format: I use PNG or JPEG, PDF or APS files for different purposes. This piece could be a web visualization placed after an article, so I export it as a PNG. Before exporting, I delete the elements outside the artboard that I do not need. From Export, I choose Export As and select PNG. I check Use Artboards so the artboards constrain the export, choose high resolution and set a white background. The exported file shows the order in which readers will look at it on a webpage. The order in which we tell the story matters.

## Adapting the layout for mobile

Anchor: 4217 · U4 · L19 · 02:15–05:45

The current project is not mobile-first, but I have worked on projects that clients defined as mobile-first; in those cases, I have to think about the mobile version first. Sometimes I work mainly for desktop but rearrange parts so the work can also be accessed on a mobile device. We can make some changes to improve legibility here, so I create another version with a longer layout.

First, I increase the font sizes, including the title, text and legends. For a mobile version I prefer to use the vertical space I have so that the legends are very clear and accessible. I group the elements and use Align to Artboard, centering them. There is still room, so I enlarge the artboard and increase more text. Some text can stay the same, while other text can grow. I adjust the elements so they are readable.

## Replacing small country labels with references

Anchor: 4217 · U4 · L19 · 05:45–08:45

I increase the size a little more to be sure, and change the rules I had predefined so that everything stays clean without overlapping. I adjust the spacing and the source a little more.

Increasing the country names can be extremely tricky here. It would be difficult because we did not design the project mobile-first, but we can look for another solution. I put a number under each country's shape, then add a list of the countries at the bottom of the page. This lets users see the graphic as a whole while reading the text without having to zoom and go back and forth. I show how the country list could sit on the page, add reference numbers under the shapes, and rotate and enlarge the numbers. That makes the information more readable.

## Testing the mobile version

Anchor: 4217 · U4 · L19 · 08:45–10:45

I suggest testing it. After creating the version, export it as a PNG, open it on your mobile and check whether you can read everything. If anything feels too small, return to Illustrator and change it. I will not finish this adaptation, because the final project is the desktop version of the visualization. I wanted to show changes that can be useful. Knowing the context in which a project will be used is essential, and it can be important to provide alternative solutions for different devices. This can also help if you want to work on a mobile version of this project. The graphic is smaller because it was not designed for mobile, but at least the text is readable. I save and export it as a PNG to test it on my smartphone.
