# Unit 6 · Introduction to Lean Information Architecture (AI)

Anchor: 1490 · U6

In this unit you will learn to design the flows and the *sitemap* of a digital product in the most efficient way possible.

## Tasks

- ### Create a sitemap 
Practice exercise 6\.1

Create the *sitemap* of your project to distribute the content in it. You can do it by hand or help yourself with these three tools:

 1\. Text document with *bullets* . (We use Google Docs because it allows editing in collaborative mode).
  
 2\. [MindMeister](https://www.mindmeister.com/)
  
 3\. [Octopus](https://octopus.do/)
- ### Create a user flow 
Practice exercise 6\.2

Define one of the main flows of your digital product based on the Ryan Singer technique that we have seen:
  
 

![](https://assets3.domestika.org/course-images/000/012/173/12173-big.png)
 You can modify it as you want, the important thing in this task is that it helps you identify the steps, the different actions on each screen and the screens that we will have to define later.

 I recommend that you make the flow of actions very concrete, otherwise the flow can be as complicated as the one you have seen in the video of the lesson.
