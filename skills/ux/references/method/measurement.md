## Render-kit conventions

Use `data-rk-stage` to label each rendered screen or flow stage. Run exact code checks before vision review. Fix every failure and render again. Skipped or incomplete checks need an explicit reason; `n/a` applies only when the artifact has nothing for that check. A fresh-context reviewer receives the rendered images and the specific questions in [review-checklist.md](review-checklist.md). Verify the answers; if no reviewer can judge an image-based property, report it as **not judged**.
