# Research Coordination

Delegate only work that can proceed independently. Each assignment names the decision question, evidence standard, relevant sources, output shape, and how findings return to the synthesis. Use the active harness’s supported worker roles.

## Assignment shape

- Question and account scope
- Source requirements and date sensitivity
- Required evidence log and uncertainty labels
- Output fields and hand-back point
- Stop condition when the question is answered or further collection costs more than its decision value
