# Frameworks Vocabulary

Frameworks are prompts for better questions and comparisons, not substitutes for client-specific evidence. Choose the smallest method that helps the current decision.

## Field vocabulary

Use MEDDICC for element-based deal qualification; use SPIN or a pain-funnel structure to plan discovery; use Admiralty grading to describe source reliability; use TCO and expected-value analysis to structure cost and value questions. Select terms only when their method serves the current client decision.

## Use frameworks as aids to judgment

- Analyst sources help survey current solutions; the book does not prescribe Forrester Wave for competitor positioning or specify generic vendor marketing as a trigger. [book:mastering-api-architecture], ## ADR Guideline: Selecting an API Gateway
- Build each stakeholder's buying vision by teaching a fresh insight they can advocate — needs-discovery and pain questioning per stakeholder score far lower than delivering unique perspectives. [book:challenger-sale], The Key to Generating “Widespread Support”
- Build the strategic account plan around expected results and the specific measurements that show progress — the plan should work as a contract between supplier, account manager, and customer. [book:key-account-management], 9.3 Performance measurement and monitoring
- Combine complementary frameworks across discovery, qualification, stakeholder mapping, and insight development. [book:meddicc], Implicate the Pain
- Compare TCO across like-for-like three-to-five-year periods and include direct, indirect, hidden, exit, and status-quo costs. [book:modernnetworkobservability], ## Cost analysis
- Do not cite the framework in the client deliverable.
- Drop framework language that does not fit the client's communication style while keeping the underlying concept. [book:software-architect-elevator], # Chapter 1. The Architect Elevator
- Frame every competitive research effort as a specific Key Intelligence Topic tied to a deal decision. [book:intelligence-driven-incident-response], ### Data Versus Intelligence
- Grade source reliability and information credibility independently when using Admiralty Code. [book:intelligence-driven-incident-response], ### Confidence Levels
- Prevent objections by changing your own opening message and timing instead of relying on prepared responses to recover from objections after they occur. [book:selling-to-big-companies], Deal with the Really Tough Objections and Obstacles
- Score each MEDDPICC element 1–10 for confidence with defined bands and treat a low score as a found qualification gap to work, not just a missing element to research. [book:meddicc], MEDDICC Scoring
- Score enterprise AI use cases with BXT.
- Screen analyst comparisons for vendor sponsorship and age, and corroborate them with experiments or a proof of concept. [book:mastering-api-architecture], ## Radars, Quadrants, and Trend Reports
- The book maps buying roles by budget authority, technical approval, user evaluation, and Champion or Coach status, rather than assigning every role a separate win-result. [book:meddicc], ## What is MEDDICC?
- The book uses stage-specific MEDDICC questions and prioritizes unresolved elements for follow-up; it does not prescribe Strong/Weak/Missing ratings or a two-missing pause. [book:meddicc], ## QUALIFICATION
- Treat pain as qualified only when it has been identified, indicated, and implicated on the customer; the book's Three I's gate parallels the rule's three pain layers but does not name Sandler's. [book:meddicc], Implicate the Pain
- Treat the Situation stage as unfinished work — keep going until the pain is quantified as a Problem and implicated in consequences rather than staying with situation facts. [book:meddicc], Implicate the Pain
- Use Challenger's Teach, Tailor, Take Control posture to develop commercial insight and disrupt status quo when appropriate. [book:challenger-sale], ## FINDING #2: ONE CLEAR WINNER AND ONE CLEAR LOSER
- Use Cost of Inaction when no decision is the real competitor. [book:selling-to-big-companies], Know Your Biggest Competitors
- Use IDC MarketScape queries for industry-specific vendor evaluations when relevant.
- Use named sales frameworks as query anchors, translate findings into BI's outputs, and do not apply the frameworks wholesale.
- Use only one framework anchor per stalled research track.
- Use Porter's five forces as distinct query angles when competitive research lacks broader market dynamics. [book:key-account-management], 7.2 Key account analysis
- Use the B2B Elements of Value framework to look beyond functional value when differentiating.
- Use Value Proposition Canvas to map customer jobs, pains, and gains to pain relievers and gain creators. [book:continuous-api-management], ### Methodology: Value Proposition Interface Canvas
