## What constants and variables mean

Anchor: 5642 · U6 · L87 · 00:21–00:51

Constants and variables are clearly a fundamental part of any visual-identity system. They're what makes some data or composition elements stay the same throughout a system, while other data and elements of that same composition — that same visual language — mutate, swap out or complement each other across the whole system.

## Setting up the exercise

Anchor: 5642 · U6 · L87 · 00:51–01:16

Since the exercise covers three similar products with different flavours or varieties, the system will probably end up a bit more closed. The exercise is done without colour or typographic exploration for now, just to see how some elements can become constants and others variables.

## Third variable: typography by strength

Anchor: 5642 · U6 · L87 · 03:13–04:47

Typography, too, can serve as a variable. A heavier line of type suits a stronger version — for instance, one at 10% alcohol. A lighter version calls for lighter typography. And a slightly stranger version might call for a more technical-looking typeface.

## Further variables

Anchor: 5642 · U6 · L87 · 04:47–05:07

If the exploration were pushed further, other elements could be worked too — the container itself, for instance: one version could have the container flipped upside down, another could have both ends rounded off. This is how constants and variables keep building up within the same graphic system.

### Key points (derived)

- Constants are the elements that stay fixed across a system; variables are the elements that mutate, swap or complement each other across the pieces.
- The exercise on the "Kashmir" label deliberately sets colour and typography aside at first, to isolate which elements can be constants and which can be variables.
- Three variables were tried on the same base composition: the container's base shape (pentagon, rectangle, ellipse), the content of the ear circles and centre emblem, and the typography used for the alcohol-content line (heavier for a stronger drink, lighter for a lighter one, more technical for an odder variant).
- The fundamental, constant element across all three versions is the underlying concept — the traveller in time and space — while secondary zones (container, circle content, type) carry the variation.
- Further variables are possible beyond this exercise (e.g., flipping or rounding the container) — colour and typography come next.
