## Fixing the drop-shadow capitals

Anchor: 5642 · U7 · L97 · 01:43–02:21

Let's analyse what we have on the front, which is the most important part. Following this idea of tradition, the design uses two illuminated capitals — actually the same letter twice, both R's — treated with this drop-shadow effect. For this kind of lettering, if we do use a shadow at all we should always treat it as if the light were coming from above, meaning it should fall preferably below and to the right. But in this case it would probably be better to remove it altogether, because it gives a three-dimensional effect that doesn't really make sense on our label.

## A space problem: the brand crowds the label

Anchor: 5642 · U7 · L97 · 02:21–03:05

Then there's a problem with how space is distributed on this label. The brand, in this stepped arrangement, takes up a very large area of this rotating surface — the bottle — so that it practically gets lost around the sides. This is something we should keep in mind: the more we fill the central space of the label, the better; the fewer empty spaces we leave that we don't quite know how to fill — as happened with other applications we've looked at — the better. We're also repeating this same distribution of elements on the back, so perhaps what we could do is remove these parts here and work with a clean surface instead.

## Fixing the tracked lowercase script

Anchor: 5642 · U7 · L97 · 03:05–04:13

Another thing we need to consider on this label is how we're setting the product name. Apart from these capitals, we're writing it in a calligraphic-style lower-case letter. As a rule, we shouldn't add space between lower-case letters — there's no reason to; it's capitals that we're used to spacing out a little, almost as guides. When we work with capital typography, especially roman capitals, it's sometimes fine to add a bit of tracking; in lower case it's not advisable, because lower-case letters, even typographic ones, are inspired by a more calligraphic style, so the letters have a joined character. In italics it's even less advisable, because of how an italic's shapes are drawn — the letters visibly reach for one another — and in scripts, like the one we're using here, which clearly imitate handwriting, we should never space out these lower-case letters. So simply removing this tracking here will already improve things quite a bit.

## Dropping the historicist background

Anchor: 5642 · U7 · L97 · 04:13–05:28

Another thing we should do with this cover is really work a different background — let's de-historicise this label a little. There's not much sense in imitating this old, parchment-like style; if we simply remove it and work with a white background, and later print this label on quality paper, we won't need to fake that sensation — we'll have a much, much cleaner product. We should also concentrate on a single idea: working with a capital letter as the main idea can work well, but doing this historicist style on top of it can be a mistake. This happens quite a bit in typography — we often try to do things like this fake cover of Don Quijote, giving it a historical feel, as if that same kind of lettering had been used at the time, when in fact, in the case of Don Quijote, roman type was used to print it — nothing to do with this kind of gothic letter. So here what we could do is a non-historicist rethink of this label, however artisanal the drink is, keeping the idea of the capital letter and the drink's name, but starting fresh with an update.

## Working with a lettering artist: the new R

Anchor: 5642 · U7 · L97 · 05:28–06:29

As we've done on other occasions, we're going to work with an outside collaborator here: we spoke with Bianca Dumitrașcu, a calligrapher and type designer who does very good, modern, up-to-date vector lettering. Talking with her, we got interested in a piece of work she'd been developing from vector letterforms built out of evolved curves, using a system of expanding curves. Talking it through with her, she proposed different versions of an R for this drink — since it's called Ratafia Rossell, basing the design on the R seemed like a good way to keep working. Starting from one specific letterform, she went on, let's say, experimenting with the treatment of the strokes, and in the end we decided this was the definitive shape, and made the change. Now we have this very beautiful R as the main theme of our label — a label we're going to remember, because it's original. Even though it's an artisanal drink, there's nothing wrong with giving it this modern treatment — on the contrary, we're bringing it up to date.

## Carrying the redesign to the collar and back label

On the back label, which continues the same surface, we give it the same treatment as the front: we remove the background, getting a more elegant, cleaner label. ## A typeface that doesn't cover the alphabet you need

Anchor: 5642 · U7 · L97 · 08:12–09:58

We've also changed the typeface for the contents text. Let's look at what's going on with this typography: right now it's justified and hyphenating words — something we saw makes sense in a book's body text, but not in a piece with this little text. So the first thing to do is set the text ragged instead of justified, so it's better composed and under much less tension; after that we'll organise it into columns and drop these separating rules, because they don't make much sense. And we're going to change the typeface, because the one we'd used — Gill Sans — is a fine typeface in principle, but in this case it didn't have a Cyrillic alphabet. This is important to keep in mind when starting any project: know which typeface you're going to commit to, because you may need to set text in Russian, Bulgarian or Serbian, or perhaps in Greek, which uses a different alphabet altogether — so we need to work with a typeface that covers that kind of script. Gill Sans didn't have it, so instead we switched to Minion Pro, which works quite well — a roman that holds up well.

## Small sizes, columns and unifying the icons

Anchor: 5642 · U7 · L97 · 09:58–11:10

We could even do a little better and use Minion Pro for the larger sizes and Minion Pro Caption — a cut meant, as its name suggests, for captions and small notes in a text — for the smaller sizes; it will hold up much better there and still tie in with the typeface we used on the front, which is simply Minion. So we get a harmonious typographic set for slightly larger and slightly smaller bodies of text. Setting it in lower case is also mostly a formal choice — it works in both cases, but for a text of any length I think it reads better in lower case: the paragraphs become more legible and invite you to read a little more. We can also organise the text into columns, which is what lets us avoid using these separating bars — it ends up more orderly, easier to scan, and we'll support it with a system of rules that also helps reading a little. If we drop the elements at the top down to the bottom, move the text down a little, and reorganise the volume and centilitres into the new typeface, we can also move the "for over 18s" symbol, which is itself a graphic element, next to the other icons, and perhaps reorder those icons too — dropping the colour that isn't necessary, so we unify the language and unify the colour, and set it together with the barcode. Now the barcode isn't an element that bothers us any more — it doesn't look like something we had to include out of obligation, but something that sits there naturally like all the other elements on the page or the label.

## Recap: composition, shadows and typography

Anchor: 5642 · U7 · L97 · 12:29–15:33

Don't scatter the elements across the surface, and make sure empty spaces don't look accidental — don't let it seem as though those gaps just turned up because we couldn't quite control them. Look for a visually clear composition to give a piece identity — something you can describe quickly, in words; we already mentioned this when we talked about the hairstylist's business card, and it's worth remembering: a design has to be, in some sense, a statement, and composition is part of that — composition has to work like a strong assertion, something memorable, something you're able to describe verbally.

Shows: the composition recap list, with the original parchment label and the finished white "2023 Edition" label shown side by side as the before-and-after.

On more graphic points of detail: avoid these drop shadows in certain graphic styles — it's clear this capital doesn't suit that shadow at all, and if you do use a shadow, it should fall on the lower part of the object, so the light always seems to come from above; that gives it more visual logic, and in some cases, removing this shadow doesn't make much sense. Another thing that will serve you well in this kind of work is to unify the graphic elements stylistically wherever possible — what we did on the back was remove colour, unify stroke widths, put everything inside the same kind of circle, unify sizes; this helps make for clearer, cleaner signage.

(Graphic elements / Avoid drop shadows in certain graphic styles, and if you use them, put them on the lower part of the object. / Unify all graphic elements stylistically wherever possible.)  
Shows: the icon recap showing the pregnancy-warning, recycling and 18+ icons twice — once in their original mixed colours, once unified into a single grey tone — as the before-and-after of the "unify" rule.

On typography, we saw it isn't advisable to add extra space between lower-case letters — what we call tracking — unless there's a clear reason to, and even less so in italics and in script faces, these letters that imitate handwriting; it doesn't make much sense there. Don't use historical styles without a reason — we saw the example of that fake Don Quijote cover, which has nothing to do with the real, old Quijote. And don't justify lines of text when you're not working with a book or a long text; it's better to work with the text set ragged. And if you're working with a typeface family that gives you the option, use the versions made for smaller sizes when you need them — that's worth doing whenever you're setting sizes that need a bit of special care for reading, small type of the kind that turns up on labels and this sort of work. And finally, I'd recommend using typefaces that carry the scripts you're actually going to need — make sure you know which languages your label, catalogue or book will require, and make sure the typeface has Greek, Cyrillic, Latin, or whatever scripts it needs, so you don't have to change typeface partway through just because you've switched language.

Now that we've seen how we made a label for an alcoholic drink, let's look at something quite different: how we build an identity for business courses.

### Key points (derived)

- The label redesign follows the same throughline as the publisher's mark in the previous lesson: strip a generic, borrowed signal (a fake-historic parchment and gothic-adjacent capitals) down to something built specifically for this name, then let a specialist (the lettering artist) resolve the one element that has to carry the whole identity — here, the R.
- The back-label rework treats legibility as a typeface-coverage problem, not just a style problem: the practical failure (no Cyrillic in Gill Sans) forces the typographic choice (Minion Pro plus its Caption cut). The earlier justification and hyphenation problems are fixed separately, by setting the text ragged and organising it into columns.
- "Unify stylistically" is demonstrated very literally here — the same three icons, first in inconsistent colours, then recoloured into one tone — which makes the abstract recap rule easy to check against a real before-and-after.
