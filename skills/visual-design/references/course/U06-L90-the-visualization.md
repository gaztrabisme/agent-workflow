## Three product lines from one system

Anchor: 5642 · U6 · L90 · 00:23–01:47

What I did here was start developing three lines that work as a system. As you can see, the system is fairly closed, and because it's based purely on the formal, the morphological, you can play a lot with the color palette to signal one line or another. If we were working with a system based more on color itself, it would be much more complex to choose different palettes for the different lines. Since here we're relying on structure and the composition of the layout, it's much simpler to keep adjusting the colors and find a system that ties itself together across each of the cans.

That's how each one carries a few small changes in the miscellaneous details — in that complementary landscape we always talk about — plus a color change and a change in some of the structures that hold the content. For instance, this becomes a rectangle, this triangle we saw from the very first sketch, and this version, a bit heavier, maybe with more alcohol, takes on a different color because the solid color takes over the background and the typography ends up contained in other supports.

## Small design tells: alcohol-strength cues

Anchor: 5642 · U6 · L90 · 01:47–02:43

There are a few small details that are nice too. This is the softest one, with the lightest colors — maybe the alcohol percentage is smaller. This one was the standard drink we were working with. And this one, having more alcohol and being stronger, allows for other colors, other contrast, and so on.

At the same time, there are a few nods tied to that, which help finish giving shape to the final design. For example, on the lightest one we have a single diamond; on the intermediate version we have two; and on the more robust version, stronger in alcohol, we have three. They're small nods, small design decisions made inside the design, that let us play with having some encrypted messages or meta-messages within the proposal.

As you'll notice, all the colors come from this landscape — they're in tune with what we'd been planning — and now let's move on to how to visualize what we're generating.

In this case I have a mockup of these four cans, quite interesting, very dynamic, very flexible. And what matters with mockups is working tidily with the layers. Usually the layer where we need to place our design says "put your design here" — pretty clear. So in that layer, which is a smart layer, a Smart Object, we double-click and plant our design there. It always comes with some sample design that we need to delete first. We can also change the background here, and see what happens — let's test turning this can black; it gets pretty interesting, to be honest. And since this is a smart object, when we hit save and go back to the other file, we'll see the impact on our can. We'll do the same with the others.

## A poster system from the same elements

Anchor: 5642 · U6 · L90 · 06:21–07:31

That is, if we're designing cans, it's also worth opening up that landscape and seeing how the visual identity system looks dismembered, or becoming more and more dynamic, on other supports — like a bag, a t-shirt, or a poster system. Here we can clearly see that one poster is simply the can's front design with a few changes. Another poster resizes elements that used to be miscellaneous and now become part of this main view. It's also worth seeing what happens with the typography and a change of scale, with a change in the shapes of the main elements, or with a more distant view that generates some kind of pattern or texture out of all the elements generated so far.

That's how the project gets enriched, simply starting from the design of a can — the more elements we have, and the more dynamic and flexible the visual identity becomes, the more we'll be able to dismember the elements into different pieces and make the whole project richer and more interesting, and have it nearly ready for a presentation.

### Key points (derived)

- One structural system can generate several product lines just by shifting the color palette and a few container shapes, without redesigning the whole layout.
- Small recurring details, like the number of diamonds or the depth of color, can work as quiet meta-messages that signal strength or variant.
- Mockups keep well-labelled smart-object layers ("put your design here"); double-click to edit, delete the sample art, and the change updates automatically back in the main file on save.
- Placing a mockup's back label alongside its front, when the mockup allows it, shows how the two sides read together.
- Beyond the core product, applying the system to other supports — a gift bag, a t-shirt, a poster series — tests how flexible the identity really is and gives the client a fuller sense of the project.
