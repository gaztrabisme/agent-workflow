## Rabatment: rotating the square without losing the proportion

Anchor: 5642 · U4 · L62 · 16:43–17:50

Rabatment (*el rebatimiento*) is a good strategy for holding on to the proportions: if I rotate these squares, it doesn't matter what distance there is between them, it keeps on being proportional, it keeps relating back to the proportion. ### Key points (derived)

- Type-scale calculators (Typographic Scale Calculator, type-scale.com) generate a full set of harmonious sizes from one base size and one ratio (commonly 1.618, 1.25 or 1.2), and web tools can export the result as CSS.
- A rough, intuitive pass at choosing a scale should come before fine adjustment.
- Margins and column widths can be derived mathematically from the same ratio used for the type scale, by testing candidate proportions against a reference square.
- A page's inner and outer margins, its running head, its folios and its column count and gutters can all be tied back to one governing proportion.
- Setting the gutter equal to the leading makes the gutter-and-leading gap form a perfect square — a small, self-consistent check that the grid is proportionally sound.
- A fixed column structure suits a book, which needs less flexibility; a magazine benefits more from a grid system that can flex per spread.
- Rabatment (rotating a square within the format) preserves the same proportion at any distance, which is why it works as a construction method — filling the page with guides instead would not.
