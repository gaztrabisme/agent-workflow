## The brief: a mark for a publishing house

Anchor: 5642 · U7 · L96 · 00:00–00:36

In this lesson we're making a mark that has a very strategic use on one part of the product: a publisher's imprint (*sello editorial*). Because of that, our mark has to meet a very specific function — it has to look good on both the cover and the spine. We'll explore iconography and look at how other publishing houses have solved this, and we'll see how the identity extends across the publisher's other pieces, including communication pieces.

## The weak point: the spine

Anchor: 5642 · U7 · L96 · 01:48–02:32

Then there's what would be the most important application for a publisher, since this is a publisher that makes books: the mark on the spine of the book. This is a key element — a very important one — because however much a book appears on a new-releases table, in shop windows or in promotions, it ultimately lives on a shelf by its spine, and that's what tells us which publisher the book belongs to, appearing there as this small drawing. This is clearly the weakest part of the mark in this case: if it has to be reduced, it doesn't work well. It's slightly tilted and just doesn't quite come off.

## Typography problem: the justified block and mismatched weights

Anchor: 5642 · U7 · L96 · 02:32–04:03

Looking at the mark typographically, something quite common has been done here: trying to close up all the lines into a tidy block. Justifying text on both sides is fairly common in a book's body text, and here that could make sense given it's a publisher — but it's really more a habit inherited from a typographic world where text tends to be justified, and we often end up justifying marks and other elements too, sometimes even titles. This gives marks a slightly old-fashioned look, and it also creates a problem: because the top line is longer than the second, the strokes end up with different thicknesses — an unwanted difference in weight that doesn't work well, whereas the word "Editorial" is deliberately set light. This difference could be patched by using a heavier weight of the same typeface to compensate, but it would probably be better to simply align the two lines, giving them the same size. It's a fairly distinctive piece of wording, so it works well spoken with a single voice, so to speak — writing it at the same size might make more sense, although then we'd find the article "de" left hanging at the end of the first line, which doesn't work very well either. So it might be better to set it as a single line — we'll see later how it gets applied, but working on a single line will read a little better and will likely give us a more visible phrase: not something we have to decode, but something read a little more naturally.

## Typography problem: hanging particles and false small caps

Anchor: 5642 · U7 · L96 · 04:03–05:43

Then there's this element underneath that closes the mark off. The same thing happens as in the previous lesson: this kind of "signature" we sometimes put below — here it reads "Editorial". What's been done here is false small caps. Properly, small caps are capital letters set at the height of the lowercase letters, sometimes paired with true capitals; this has a certain tradition in publishing. But especially since personal computers came into use, false small caps started being generated, as in this Times shown here — notice how the capital letter looks different from the reduced lowercase letter, with a different stroke weight. Small caps also have a certain tradition in publishing, but above all they're used with roman (serif) letters, not with sans-serif ones — sans-serif letters belong more to the industrial era, the letters of modernity, so we shouldn't use small caps with sans-serif letters, because with them they'll always come out as false small caps. So this is an element that not only doesn't work well typographically, but that we could even consider removing altogether, since this logotype will be seen applied in an environment that's already a book environment, an editorial one — so it doesn't add much for us.

## Typography problem: two typefaces too alike

Anchor: 5642 · U7 · L96 · 05:43–06:19

On top of that there's another problem: this lower word is set in Frutiger, a sans-serif that's perfectly fine on its own, but the logotype's letters are set in Helvetica (captions: *albética*) — also a sans-serif. In its final version we'll see this more clearly: they're actually two typefaces that look very similar to one another. That's something we shouldn't do: combine two typefaces that sit too close to each other. It's a change that doesn't make much sense. So removing this signature element altogether would improve the mark quite a bit — it would take away its very categorical, old-fashioned, centred character, and give it something a little more modern instead.

## Rethinking the compass-rose symbol

Anchor: 5642 · U7 · L96 · 06:19–07:26

Now let's talk about the symbol, or imagotype — the image part of the corporate identity rather than the text. In our example this element is a compass rose. It's a bit repetitive, or it fails to give us a new idea: it's tied to the same thing as the publisher's own descriptive name, but above all I think it's an aesthetic problem — it's a symbol that feels dated. It's mostly a cliché, a symbol we can find associated with many other things, and it feels old-fashioned; it has a style that's, let's say, a bit stale, so it's something we could question. And given that we have a very distinctive, very descriptive name — Cuaderno de Bitácora — the new image could rest on the text alone. We already saw that the symbol didn't work well on the spine of the book, and this is a very special element for publishers — you have to get this kind of symbol right, work it very carefully. So it's something we could perfectly well do without.

## Building the new mark from typography alone

Anchor: 5642 · U7 · L96 · 07:26–08:27

Once we're left with just the typography, we should probably find something a little special for the spine — perhaps a kind of summary of what's on the cover, so that seen together the two read as one. If we simply use the C and the B as a symbol, that might feel a bit cold; we should look for something more special. Now that we're working with a Helvetica, this is also the moment to bring it up to date. Helvetica is of course a fine typeface — we've talked about it and we'll talk about it again — but perhaps we should update it with a slightly more modern neo-grotesque. First, it would help to move it to lower case: this gives it a more contemporary feel, more in keeping with how this kind of typeface is used today, and to choose a more modern, more current neo-grotesque, with a few more humanist details, like the round dot on the "i", a slightly larger eye, and a somewhat more regular letterform.

## A new symbol for the spine

Anchor: 5642 · U7 · L96 · 08:27–09:06

So how could this be summarised with the C and the B? We could make a special symbol that in turn looks a little like letters, but isn't exactly letters — a small enigma that's a B, but not quite a B, and a C, but not quite a C, because it's turned around. This element works very well on the spine as a very special symbol: almost a letter, one that combines well with the cover text, but that gives the mark a very distinctive character with something very much of a publisher about it. It's not as pictorial as the previous symbol, but something much more typographic, while still not being exactly a letter.

## The new system in use

Anchor: 5642 · U7 · L96 · 09:55–11:05

On the book cover, or on the card for example, we could place this symbol on a coloured background on the back, at the same size and in the same position, and use the full logotype on the front. In email signatures and that sort of thing, don't use just the symbol on its own — using this "CV"-like mark alone in a signature is odd; there we need it to be clear who's writing. So we have to choose, case by case, which of the two we use, and use the other more decoratively, in promotional pieces or wherever. For example, for the element that identifies the social media accounts, we can clearly use the other symbol, because that's a place where we'd normally use imagery, since it's almost always accompanied by text underneath. With this we get an image that's overall more modern, one that lets us develop new promotional pieces that feel a little more up to date — a type of image that doesn't feel as stale as what we had before, something a bit more dynamic, that feels a little less like a traditional publisher, while still letting us create more dynamic, more cheerful elements.

## Recap: typography, iconography and systems

Anchor: 5642 · U7 · L96 · 11:05–14:39

Let's look, then, at some of the most important points we've covered in this lesson.

On typography: the justified text block is really meant for bodies of text — what would be the typeset page of a book — so we shouldn't overuse it in logotypes and similar typographic settings. You can combine weights within the same typeface to compensate for different sizes; as we saw here, it's something we didn't apply in the end, but it's a trick that can work with some typefaces when a size change produces a difference in weight we don't like. We should also remember that when setting a word, we shouldn't leave particles hanging — it's better to carry them down to the line below. We didn't do this with our own logotype, because in the end we put it on a single line, but it's more elegant not to leave these pieces hanging at the end of a line. We should also remember to avoid false small caps — those letters that come out thinner because we're simply shrinking capitals down. If we are going to use small caps, we'll find genuine ones in some OpenType typefaces as a stylistic feature, and if we use them, we should use them properly. Another of the most common mistakes in typographic design is combining two typefaces that look too much alike. In our case we had Helvetica and Frutiger — both fine typefaces, both able to serve a corporate identity well, but two typefaces that resemble each other too closely, and because they're so alike there's no contrast; there's no point combining these styles together.

On iconography — meaning what kind of images we use when making an imagotype — we should avoid images that are obvious or easy to forget; thinking of things we may have already seen elsewhere, or that could be almost anything, isn't going to make a good image for our company. We should also often design imagotypes with their main application in mind: we can make an imagotype that looks great, but if it doesn't work in its main application, there's no point using it. Sometimes we should start by thinking about where it has to work best, what the key point of our image is, and make sure it works well there — because then the image will surely work well overall and we'll succeed with it. After that, we should build a graphic system that lets us grow indefinitely rather than tailoring it to each different application. We'd need a system unlike the one in the previous mark, which sometimes worked and sometimes didn't; instead we should build one that adapts as flexibly as possible without forcing the image — as with our first mark, which sometimes sat inside a stripe, sometimes didn't, and sometimes appeared as a decoration, this new system works far more flexibly and far more naturally.

### Key points (derived)

- The whole case study is driven by one constraint stated at the start: the mark has to survive on the spine, so every later decision (single-line setting, dropping the small-caps signature, dropping the compass rose, designing the mirrored symbol) is judged against whether it still reads at spine width.
- The mirrored "b/c" symbol solves two problems at once: it replaces a dated, generic pictorial symbol with something that is only meaningful for this name, and it gives the spine a mark that reads at small size where the full wordmark can't.
- The flexible system (symbol alone, wordmark alone, or both together, chosen by application) replaces a rigid rule (always the stripe, never on the envelope) with a decision made case by case.
