# Story and structure

## Build the sequence before slide styling

Write a short spoken version and a one-sentence main point before laying out slides; the first checks that the story can be told without visual scaffolding, and the second makes the intended point explicit. [book:storytelling-with-data], “The 3‐minute story & Big Idea”.

Make a low-cost outline of the planned content, then arrange and remove pieces until each section supports the main point. A storyboard gives the communication a changeable structure before slide production creates attachment to individual pages. [book:storytelling-with-data], “Storyboarding”.

For a live presentation, write speaking notes with the important points for each slide and practice transitions between slides. [book:storytelling-with-data], “Who, what, and how”.

## Set the order for the audience

Decide whether the conclusion should lead or arrive after context; the story source presents both as choices to consider for the audience, not one universal order. [book:storytelling-with-data], “Storyboarding”.

Include more detail in a written, self-serve communication than in a live presentation, where the presenter can answer questions. [book:storytelling-with-data], “Who, what, and how”. Put additional content in an appendix when it should remain available without interrupting the main explanation. [book:storytelling-with-data], “Chapter 5: think like a designer”. For a narrated piece, give motion an established message and sequence. Let the required reading or listening time shape holds, and use movement to direct attention or explain a transition. ## Return when

Return to the brief if reviewers cannot state the main point, a slide has no clear job, or a caveat is detached from the fact it limits. Return to data-slides if the evidence changes the argument. [book:storytelling-with-data], “The 3‐minute story & Big Idea”; [book:storytelling-with-data], “Storyboarding”.
