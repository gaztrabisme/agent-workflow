## Set up the triangle and choose its colors

Anchor: 503 · U4 · L16 · 00:00–01:13

In this lesson I’ll animate the rotation of our shape layer (*capa de forma*) in a basic but stylish way. Let’s get started. I duplicate this composition. That is a bit of a habit of mine: you can start one from scratch or do it however you like, but duplicating is useful because I keep the composition’s size and roughly the same layers, which saves time. I’ll turn these layers off and arrange them so I know which one I’m working in, then delete the layer I no longer need.

Here I’ll create a polygon. I double-click to open it. The same thing has happened again, so I click this button to keep the bounding box visible. If we open the shape-layer controls (captions: *save layer*), we can see an option called Points under Polystar Path. I set it to three to make a triangle. I chose a triangle because, if we look back at my library, there is a range of forms I want to reflect in my animations; when I put them together, that variety gives the result visual interest.

Remember to name your layers. I open the color palette and change the colors. I’ll make the background yellow, a color I haven’t used yet. I like this better. We’ll use color to add visual interest. Then I center the shape here.

## Center the shape and check the anchor point

Anchor: 503 · U4 · L16 · 01:13–02:29

I want to make a rotation animation, so the triangle should sit around here. To check the center more precisely, I create a circle, give it a stroke (*trazo*), remove its fill (*relleno*), and make it a little smaller. I place the triangle here. With the circle selected, I show the rulers with Command or Control + R and place a guide. The guide shows that the triangle is more or less centered.

The surest test is simply to rotate the triangle and see how it behaves. I undo with Command or Control + Z. The shortcut for rotating a shape directly is W. You can see how it rotates; that lets you test your anchor point (*punto de anclaje*). I press V to return to the selection tool, undo again, and the setup is ready.

## Shape the character of the rotation

Anchor: 503 · U4 · L16 · 02:29–03:46

I enter the curve editor and double-click the property to select all the keyframes (captions: *kifres*) I have. Then I click the button that changes linear keyframes into curved keyframes. Now I have the handles I need to begin animating. We have a rough idea of how to do this from the previous exercises. I fit the view so I can work on the curve.

The character, Mr. Clint Eastwood, is lazy about getting started because he is a show-off and takes a long time to begin his work. But then he moves with a lot of decisiveness, so this part needs a steep slope and a lot of speed. I adjust the curves and preview. Perhaps it needs to be even more extreme. I use the old trick: select the pen tool and add a keyframe here, then switch back to the cursor with V. I make the beginning of the animation softer—in other words, slower—and preview again. It needs to feel more forceful, so I bring this part of the curve closer together to make it faster. I’ll also give this keyframe a little more easing at the arrival. Let’s see how it looks. That’s it; I like it.

## Refine the arrival and preview the finished rotation

Anchor: 503 · U4 · L16 · 03:46–05:22

Let’s make one last adjustment. We said that when the triangle arrives, it reaches the end almost without easing. I add another keyframe at this point: when the plus sign appears, I can click to add the keyframe. Then I select the cursor again and lengthen this part a little. I’m careful to keep the handle from moving up or down, so the curve does not go above the value. If it does, the triangle makes a small bounce because it has exceeded the value.

To fix it, I can select these two points and pull the handle down, or adjust it this way. That has not worked, so I use the Bezier handle itself. Now it works. I bring the keyframes closer together so the triangle does not spend so long paused. I make the transition a little steeper and faster. For me, this is Mr. Clint Eastwood playing Dirty Harry, in action, transformed into a triangle.

Make your animation really polished. Adjust the keyframes, and especially the curves, with care and it will look great. Now that we’ve made the rotation animation, we’ll make an interaction between two elements in the next lesson.
