## The five Transform attributes

Anchor: 503 · U2 · L05 · 02:40–03:58

Click the small arrow to open the layer's Transform group. I recommend keeping the interface in English, but in a Spanish interface this group is called Transformar. Here are the five basic attributes of a layer in After Effects. We will go through them one at a time.

The first attribute is the Anchor Point (*punto de anclaje*). When we select the layer, either in the layer area or in the After Effects preview, the anchor point appears as a small symbol like a crosshair. It is the physical center of the layer, or the pivot. There are two values here. The one on the left is X, and the one on the right is Y. X is horizontal, and Y is vertical; the captions render the letter Y as “I.” These values tell us where the point is within the layer. If the layer is 1080 by 1080, its center is at 540 by 540, exactly the physical middle where After Effects places it by default.

## Move and reset the anchor point

Anchor: 503 · U2 · L05 · 03:58–06:21

Here are a few tricks for working with the anchor point more intuitively and quickly. First, learn two simple keyboard shortcuts. Press V to switch to the cursor tool in the toolbar at the upper left. With it, we can move and scale the layer, as we have seen. I will click Reset. The second shortcut is Y, which selects the Anchor Point tool so we can move the anchor point in the preview window. We can grab the anchor point and move it wherever we want.

If I hold Control on a PC, or Command on a Mac, while moving the anchor point, it snaps to important points on the layer: the center, the corners, and the other marked points around the layer. This helps us place it very precisely.

The third trick is useful when the anchor point is somewhere arbitrary. Hover over the Anchor Point tool in the toolbar, hold Control, and double-click. The point immediately returns to the physical center. I will move it away again and repeat the shortcut: Control or Command on a Mac, then double-click. Now it is centered.

Let us recap. V selects the cursor. Y lets us move the anchor point directly in the preview. Holding Control helps us place it accurately at the layer's important points, such as its corners and center. If it is anywhere other than the center and we want it centered again, hover over the Anchor Point tool, hold Control, and double-click.

## Position and Reset

Anchor: 503 · U2 · L05 · 06:21–07:02

The next parameter is Position (*posición*). Again, the left value is X and the right value is Y: horizontal and vertical. We can move the layer by selecting it in the viewer and dragging it; the values change to show exactly where the layer's physical center is. We can also click a value and drag it, or enter an exact value for the layer's position. There is another useful button to the right of Transform, called Reset. Clicking it returns all the layer values to their defaults.

## Scale and its linked dimensions

Anchor: 503 · U2 · L05 · 07:02–08:28

The next parameter is Scale (*escala*). It also has X and Y values, and now there is a small link control that we did not have for the anchor point or position. This is the option to keep the two values linked, an option shared by several Adobe programs. When it is on, changing either value also changes the other, so the square will not be deformed.

If I turn the link off, I can change X and Y independently and deform the layer. I will press Control-Z or Command-Z a couple of times to restore the square. Even with the values linked, I can drag a corner in the viewer to deform the layer. For precision, use the layer attributes; for a freer adjustment, drag a corner directly in the preview window.

## Rotation and the anchor point

Anchor: 503 · U2 · L05 · 08:28–09:59

The next parameter is Rotation (*rotación*). It has one value on the left and another on the right, separated by a plus sign and a comma to show fractions. The value on the right is easiest to understand: a negative value rotates to the left, and a positive value rotates to the right. The value on the left is the number of full turns: 360 degrees, 720 degrees, and so on.

If I set it to 2, the layer's current appearance does not change, but when it is animated it will make two full turns and then nine degrees. We can specify full turns to the left—for example, 4—and use the value on the right to say which way it rotates. A negative value for the full-turn count also rotates it to the left.

Some of you will have noticed that the anchor point is displaced. The layer is rotating around that point, which is one reason to be careful about where the anchor point is placed. I will use the earlier trick—hover over the tool, hold Control, and double-click—to put it back in the physical center for rotation. Then I will click Reset. Another useful shortcut is W, which selects the Rotation tool so I can rotate the layer directly in the preview window. I will reset it again.

## Opacity

Anchor: 503 · U2 · L05 · 09:59–10:33

The last basic layer attribute is Opacity (*opacidad*). It is simple: it is measured as a percentage. One hundred percent means full visibility, or full opacity; zero means complete transparency, or no opacity. We can animate this value to make fades, or use different opacity levels for the layers. It is probably the simplest attribute.

## Create and name a null object

Anchor: 503 · U2 · L05 · 10:33–11:40

We have seen the basic attributes any layer has in After Effects. The next type of layer is a Null Object (*objeto nulo*). Go to Layer > New > Null Object to create one. I know its shortcut because I am a bit of a geek and do this for a living: Control-Alt-Shift-Y (the captions render the final letter as “¡Adiós!”). I use it, but some shortcuts are not essential to know.

By default, the null object has a name. I will rename it: select the layer, press Enter, and give it another name, such as “posición escala” (“position scale”), or another name that identifies what it will do. A null object is a layer that works as a controller and is not rendered. Although it appears in the interface, it will not be visible when the animation is rendered.

Its clearest use is to link other layers to it. For example, we can use the null object to scale or move several layers. Let us see how.

Anchor: 503 · U2 · L05 · 11:40–12:28

## Link layers to the null object

Anchor: 503 · U2 · L05 · 12:28–13:40

Now select the layer you want to link to the null object and drag the spiral without letting go. Release it over the name of the layer that should control it—in this case, the null object controlling Blue Solid 1. If we expand the layer controls, we can see the link. Moving the null object's Position controls will change the Blue Solid 1 layer beneath it. We can affect its Scale, Rotation, and other parameters. We can link several layers to the same null object.

There is one exception: the null object's Opacity never affects the other layers. The null object passes on only the physical attributes—Anchor Point, Position, Scale, and Rotation. To unlink one layer from another, open its dropdown and choose None (the captions render this menu choice as “known”). We can link the layer again. You can see how simple it is to connect a layer to a null object.

We have now seen how to create a null object and a solid, the most basic layer in After Effects. Next, we will see different ways to create shape layers and explain what they are: vector layers.

## Draw a shape layer with the Pen tool

Anchor: 503 · U2 · L05 · 13:40–14:33

One way to make a shape layer is with the Pen tool (*pluma*) in the toolbar. It is important that no layer is selected. If I draw or create points in the preview window and close the path, After Effects automatically creates a new shape layer. We will not open Contents yet; we will look at that later. The Transform group has exactly the same basic attributes as the solid: Anchor Point, Position, Scale, Rotation, and Opacity.

This is one way to create a shape layer. The captions call the new layer “6 player”; the menu and the vector shape show that the term is “shape layer.”
