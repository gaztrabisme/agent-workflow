## Shape layers and the two ways to create them

Anchor: 503 · U2 · L06 · 00:00–01:33

Shape layers (*capas de forma*) are one of the essential tools for the course exercises and final project. In this lesson, I will look at them in more depth after the previous lesson’s introduction to layers. A shape layer can be made from a preset or procedural shape, or drawn directly with the Pen tool. The captions call the shape layers “save layers” at the start, but he means shape layers. The shortcut for the Pen tool is G.

I will start with the preset shapes. Choose the Polygon Tool from the shape tools at the top. If a shape layer is already selected when you draw, After Effects adds the new shape path inside that layer. That is not what I want here, so I delete the shape I just made inside it. To deselect the layer, I click any point outside it, such as in the timeline. Now drawing creates a new shape layer. I change its color so it is easier to see that it is a separate layer.

## The anchor point and procedural shapes

Anchor: 503 · U2 · L06 · 01:33–03:11

The anchor point (*punto de anclaje*) belongs to the layer that contains the shape or path. I delete the polygon, draw another one in a corner, and press V to select the cursor. With the layer selected, I use the anchor-point tool at the top. Holding Control or Command, I double-click it without releasing the modifier; this puts the anchor point in the center.

The shape controls appear under Contents, inside nested dropdowns. There are many controls, which can feel tedious at first, but we only need a small part of the shape-layer system for this course. For example, under Polystar Path, the Points setting changes the polygon. Lowering the number of points can make a triangle, the minimum shape here; changing the number gives other polygons, and raising it a little can make stars. Look through the other procedural shapes and their dropdowns to see what options they offer.

## Freehand shapes, fill, and stroke

Anchor: 503 · U2 · L06 · 03:11–04:30

Next I draw a freeform shape with the Pen tool. By default, After Effects gives it a fill. Name the layers and use colors to distinguish them. I set the background to none. When I select a shape layer, its fill and stroke (*trazo*) controls are available at the top. Clicking the fill control changes its color immediately. The stroke is currently disabled, shown by a red diagonal line through its swatch. Clicking the word “Stroke” opens its options: I can choose a solid outline or a gradient, confirm the choice, adjust the stroke width, and change its color. After showing those options, I delete the rough shape.

## Convert a procedural shape to a path for morphing

Anchor: 503 · U2 · L06 · 04:30–05:54

There is much more to shape layers, but I want to cover only what we need so the subject does not become a wall that gets in the way. In some exercises we will make morphs by animating the shape or path itself. For that, a procedural shape will not work: instead of its Scale, Size, and Position controls, I need it to be a path. I can create any procedural shape and convert it. In the layer’s Ellipse Path menu, right-click and choose Convert To Bezier Path (the captions garble this menu instruction as “tú decir paz”). This gives me a path with a stopwatch, so I can animate the shape later.

## Select and transform individual path points

Anchor: 503 · U2 · L06 · 05:54–07:47

The last topic is how to work with individual points on a path. After Effects does not have Illustrator’s Direct Selection tool, so I recommend using the search field. Select the layer you want to work on, type “path” in its search field, and the path property appears. If the path has keyframes, hold Shift to snap to the keyframe. Select the path property, then click and drag to select individual points. I show the Undo command to reverse the change.

The other way is to keep the cursor selected and double-click in the preview: the first click shows a bounding box, and then I can select points. Use whichever method suits you, though I recommend the search field. With the path selected, click and drag to select points; I can select two and double-click to create a bounding box. I can then adjust its anchor point or axis to suit the morph or shape change. Practice, because this is a little tricky, and ask me if you have questions.

## Keep the shape-layer workflow small

Anchor: 503 · U2 · L06 · 07:47–08:27

That is the minimum set of shape-layer tools we need to animate without getting lost. Shape layers have a lot of potential, but we do not need all of it right now; the goal is to keep enjoying the work and move forward. In the next lesson, we will start moving graphics with keyframes.

### Key points (derived)

- Deselect a shape layer before drawing when you want a separate layer.
- Procedural controls are useful for changing a preset shape; convert it to a path when you need to animate its outline.
- Use the layer search field to find and select path points.
