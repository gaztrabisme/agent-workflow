# Unit 4 · Creating Shapes with Data

Anchor: 3762 · U4

In this unit we will move to Adobe Illustrator and work on the infographic starting from the sketch we have prepared. First of all we will set the dimensions and the grid of the project. Then we will move on to importing the data and creating our objects with the parameters we entered.
