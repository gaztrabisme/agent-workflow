## Set the document dimensions and aspect ratio

Anchor: 3762 · U4 · L10 · 00:00–01:31

We will set up the project in Illustrator by defining its dimensions and grid, which makes working with geometric shapes easier. Start a new file and enter the dimensions. The document uses a four-fifths format, with a width of 1080 pixels and a height of 1350 pixels, in RGB color mode. Click Create.

Working with proportions matters, especially when moving from a digital format to physical print. At 1080 by 1350 pixels, the document's four-to-five proportions convert to millimeters in a way that makes it suitable for printing on paper. The same 1080-by-1350 document is already ready for social media. You can also crop it, for example into a square, to export it in a one-to-one format.

## Set up and display the Illustrator grid

Anchor: 3762 · U4 · L10 · 01:31–02:25

Set up the Illustrator grid in Illustrator > Preferences > Guides and Grid. Choose any grid color you like and select lines as the style. Set the grid to 80 pixels with 8 subdivisions. Make sure to turn off “Grids in Back” and “Show Pixel Grid.” After setting the grid, open the View menu and choose Show Grid. From the same menu, turn on Snap to Grid.

## Edit anchor points and handles on the grid

Anchor: 3762 · U4 · L10 · 02:25–03:37

The grid is useful for drawing different elements precisely, and they need to share a common grid [captions: *una razza comune*] and be extremely precise relative to each other. The grid affects not only the overall shape but also its individual anchor points (*punti di ancoraggio*). When you move a point, it aligns precisely with the grid. You can also work on the handles (*maniglie*) of the anchor points, so the points and their handles remain aligned with the grid and the work stays precise.

### Key points (derived)

- Use a 1080-by-1350-pixel RGB document for the four-to-five layout; a square crop produces a one-to-one export.
- Set the grid to 80 pixels with 8 subdivisions, then turn on Show Grid and Snap to Grid.
- The grid can align shapes, anchor points, and their handles.
