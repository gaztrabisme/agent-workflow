## Draw geometric shapes on the grid

Anchor: 3762 · U4 · L11 · 00:00–01:48

With the Illustrator project set up, we can create the geometric shapes that form the graphic and choose the colors to use. Begin with basic geometric shapes on the grid. The rectangle tool (*strumento rettangolo*) lets you draw accurately on the grid. The same menu also contains the ellipse (*ellisse*); hold Shift while drawing to make a perfect circle. Or you can freely create the shape you want.

The menu also offers polygons (*poligoni*). Click in the center of the document to set the number of sides and the radius. I want to make a hexagon (*esagono*) with six sides and a radius of 50 pixels. This shape fits the same grid. With the grid turned on again, you can see how these shapes follow its structure. You can also edit their nodes (*nodi*) while keeping the grid as your main reference.

## Round corners and combine shapes

Anchor: 3762 · U4 · L11 · 01:48–03:48

Another useful Illustrator tool is Dynamic Corners (*angoli dinamici*). Four white nodes appear next to the anchor points. They let you round a shape's corners easily and improve its overall appearance. You can adjust them by hand, even rounding a square until it becomes a circle, or set an exact measurement such as 100 pixels. You can also change individual corners: for example, set one corner to 200 pixels and another to 200 pixels. This will be useful for distinguishing data in the project.

Another key tool is Pathfinder (*elaborazione tracciati*), available from the Window menu. It lets you make several shapes interact, creating complex forms or dividing one shape into distinct parts. For example, if I have two squares, I can use Unite (*unifica*) to merge them into a more complex geometric figure. Alternatively, Divide (*scomponi*) can split the shapes into separate parts. This tool will be useful for some parts of the final project.

## Set up and edit document swatches

Anchor: 3762 · U4 · L11 · 03:48–06:14

Before starting on the data and the project, set up the document's swatch palette (*campioni*). Illustrator makes it convenient to set colors from the Window menu by opening the Swatches panel. Choose four colors using the Color menu. I will set four base colors, but you can choose whichever colors you want for your project.

After choosing the colors, add them to the Swatches panel from its dropdown menu so they are easy to access. Illustrator adds the selected colors. You can use the same dropdown to find and remove unused swatches, which keeps the file more organized and clean.

The Swatches tool also lets you change a color after you have started the project. For example, to remove blue from my palette, I double-click its swatch and delete it. Here I can change the color options; as I move a slider, the color changes. I will change the blue to yellow. The change appears both in the Swatches panel and in the document. The tool is useful because I can duplicate a particular color easily. If I decide to change it again, I can return to the menu, adjust the color, and click Preview. The change then affects not only the original swatch but every shape that uses that color.

## Use the eight-color palette for the cocktail project

Anchor: 3762 · U4 · L11 · 06:14–07:34

Now that you know how to set up swatches, here is the palette I made for the project. We chose eight colors to color the cocktails. The palette evokes the vivid colors of cocktails, and its shades blend easily into harmonious, dynamic transitions. For example, red blends smoothly into magenta, as lilac does into purple. This will be useful later for creating interactions between the cocktails. You can find the palette with its registered swatches in this lesson's additional resources.

### Key points (derived)

- Rectangles, ellipses, polygons, and edited corners can all be aligned to the same grid.
- Unite joins shapes; Divide breaks them into distinct parts.
- Swatches keep colors editable, and the final cocktail palette uses eight colors.
