## Keep a working copy of the histogram

Anchor: 3762 · U4 · L13 · 00:00–01:11

Once we have entered all the data and clicked Apply, the cocktails are aligned. Keep an open copy of the histogram (*istogramma*) so you can return to the data if you make a mistake, need to change something, or want to add more cocktails. Duplicate the data you want to keep open. Then, through the Object menu, divide the data and unlock it. Remove what is unnecessary: for this infographic we will use only the bars, without the Cartesian plane. Illustrator warns that once a graph's elements are separated, its style can no longer be changed.

## Color the cocktail data and fit it to the artwork

Anchor: 3762 · U4 · L13 · 01:12–02:49

Using the color legend we developed earlier, we now reconstruct the cocktails from the real data. For the Americano, one section will be red, one magenta, and one black. The Boulevardier will have one red section, one magenta, and one green section. Apply this color treatment to every cocktail.

After entering all the cocktail data, adjust each graph to fit the artwork so that you can work creatively with it. Use the Negroni as the example: duplicate it first so you have a backup, then paste it onto the artboard (*tavola da disegno*; captions: *sull'arco*). With the Selection tool (*strumento Selezione*), you can change the shape of the graph without changing the proportions of the data. Do not use the tool that selects the nodes. That could distort the data permanently, forcing you to undo and start again.

## Set the grid and add the cocktail artboards

Anchor: 3762 · U4 · L13 · 02:50–04:34

Use the grid (*griglia*) to set up the data. We chose a margin of two grid modules to avoid distortion. Set the width to 760 pixels. Use the grid to adjust both the width and height of the graph, keeping a similar margin above and below. The data bars then align with the grid, which lets us lay out the remaining cocktails while preserving their proportions.

Add nine artboards for the nine cocktail recipes. Align the artboards to the grid as well, setting a uniform distance between them that matches the grid’s margin.

## Map alcohol content to rounded corners

Anchor: 3762 · U4 · L13 · 05:23–07:10

As in the legend stage, make the final adjustments to the data by rounding the shape’s corners (captions: *stonare l'aroma*). A liquor with a higher alcohol content will have less rounding; one with a lower alcohol content will have more. Set the corner rounding as a range: 200 pixels is the maximum and 50 pixels is the minimum. We choose this range for both aesthetic and calculation purposes.

For the Negroni, Campari Bitter has 25% alcohol, while Red Vermouth has 15%. We can therefore give the 25% ingredient 50 pixels of rounding and the 15% ingredient 150 pixels. Apply the same method to all the cocktails, including the Boulevardier.

## Give the ingredients a consistent order

Anchor: 3762 · U4 · L13 · 07:11–08:07

Another important aesthetic choice is the order in which the data appear in the artwork. The alcoholic base is always the first ingredient in a cocktail, so keep that order in every presentation. Reorganize the data so bases such as bourbon and gin sit in the middle. Apply this arrangement to all the cocktails.

## Turn mixer measurements into outlined squares

Anchor: 3762 · U4 · L13 · 08:08–10:30

The last part of assembling the cocktail data is to represent colorants such as sodas, soft drinks, and tonic water. In the legend, these are colored squares with outlines. Calculate the area of the supplied data rectangle, then turn it into a square and place it in the artwork (captions: *hardware*). To find a rectangle’s area, multiply its base by its height. Use a calculator to do that multiplication. Then take the square root (*radice quadrata*) of the area to find the side length of the square.

This gives us a square that is proportional to the other data. Place it appropriately on the grid. It may not line up exactly because its size comes from a calculation; we can leave it as calculated or round the value slightly so it aligns with the grid. Once it is in place, make it an outline. Set the stroke thickness in proportion to the grid: 20 points matches the grid perfectly. Repeat this for every cocktail. Then the data for the artwork are ready to be modified and animated, making each cocktail distinctive and engaging. In the next lesson we will develop the details further.
