## Arrange the shapes so the ingredients interact

Anchor: 3762 · U4 · L14 · 00:00–02:56

In this lesson we refine the details of the artwork by improving the interaction between the data and adding text. With the data in place, we can enter the creative phase: make the shapes interact to recreate the effects of liquids and cocktails that we imagined in the visual research mood board.

Move the shapes freely, but do not distort them, or you will alter the data. Start by imagining how they might interact. For example, the bourbon rectangle (captions: *barbon*) fits fairly well into Campari’s magenta rectangle, but the interaction between the magenta and the vermouth rectangle (captions: *Bermud*) is limited. Move the vermouth rectangle down a little so the shapes meet more. The more they interact, the stronger the effect will be in the video. You can move the shapes by hand, as shown here, or use the Rotation tool (*strumento Rotazione*) to give them similar movements. Rotate the bourbon by 30 degrees, Campari by minus 15 degrees, and vermouth by minus 20 degrees. When these rotation values are applied to the other shapes, they will move in similar ways.

There is no fixed logic for moving the shapes at this stage. Create different degrees of interaction and move the shapes around within the artwork (captions: *hardware*) to get the ending you have imagined.

## Add a gradient to the liqueur shapes

Anchor: 3762 · U4 · L14 · 02:57–04:01

Before making the shapes interact, add a gradient (*sfumatura*). This visual element evokes the cocktail, though it is not necessarily linked to the data. Use Illustrator’s Gradient tool (*strumento Sfumatura*) and the swatches we created earlier to add more detailed color transitions. Adjust the gradient with the toolbar controls, including its percentage, proportions, and angle. Since we defined Campari as magenta, make its gradient predominantly magenta. We chose to apply gradients only to the liqueurs, leaving out the alcoholic bases and spirits, so their strength and consistency remain visible.

## Divide the shapes and blend their intersections

Anchor: 3762 · U4 · L14 · 04:02–06:50

Once the gradient and positions are set, make the shapes interact harmoniously. Use the Pathfinder tool (*elaborazione tracciati*). Select two shapes and choose Divide (*Scomponi*) to cut the paths into separate pieces. In this example the tool cuts the three shapes. For an efficient workflow, duplicate the shapes you already made, divide the duplicates, remove the pieces you do not need, and place the resulting shape above the original path.

Use the anchor points (*punti di ancoraggio*) to position the new shape; they snap together and make precise alignment easier. Then use the Eyedropper (*contagocce*) to copy the same gradient onto it and blend the two elements. This part is mainly aesthetic, so choose how much to blend and where the gradient should sit within each shape. The aim is to make the relationship between the shapes visible through their movement. In this example, the rounded edge of Campari appears through the vermouth edge, creating a visual connection between them.

Repeat the process for the other two ingredients: duplicate them, click Divide, remove the unnecessary piece, and align the two shapes with their anchor points. Apply a gradient here too. For the green and magenta interaction, replace red with green and adjust the gradient until it looks right. Keep the goal in mind: show the intersection between the shapes clearly and precisely.

## Add a background color

Anchor: 3762 · U4 · L14 · 06:51–08:01

Once the cocktail is defined, add a few details to finish it. First add a colored background. This keeps the colors from looking too white and gives them greater intensity and visual impact. Choose a reference color from the Swatches panel, draw a rectangle for the background, and select the desired color from the swatches. The neutral color lets the other colors stand out without interfering with them. Move the background to a lower layer and lock the layer. Rename it “bg” for background; you can name the file whatever you like.

## Define a visual pattern for each garnish

Anchor: 3762 · U4 · L14 · 08:02–10:37

The remaining elements are the decorations above the cocktails. We chose patterns to identify fruit, salt, and other ingredients used as garnishes. These ingredients often have no specified quantity and serve an aesthetic purpose, so we treat their value as equivalent, as agreed earlier.

Use the legend to define a set of basic garnish patterns. The orange wedge, for example, is represented by a pattern of dots. You can choose any graphic element for this part of the visual language. The Boulevardier and Negroni both use orange, but one uses an orange wedge and the other an orange slice. Distinguish them with different shapes: we chose a rhombus for the slice. The grid helps keep the shapes in proportion and gives the pattern a consistent composition.

After defining these first examples, define the others too. We used ovals for olives and small circles for the salt rim on the Margarita glass. Recreate the garnish patterns on the grid to keep their scale and spacing consistent.

## Place, size, and color the decorations

Anchor: 3762 · U4 · L14 · 10:38–12:40

Recreate the patterns on the artwork’s grid, keeping the legend’s rules for consistency. Put them on a new layer named “decorazioni.” Use the grid as needed to position the patterns in relation to the artwork. Once a pattern is made, the Shape tool (*strumento Forma*) can change the size of its elements. Decorations should not overpower the cocktail, so make them smaller than you first planned.

The decorations should also relate to the drink’s ingredients. Here we color the orange decoration red because it suits the orange. Apply Difference transparency (*differenza*) so the decoration remains visible over the artwork: where the colors contrast, their colors stay distinct; where they are similar, a different color appears. This will also make the artwork more interesting during animation.

## Add restrained text to guide the reader

Anchor: 3762 · U4 · L14 · 12:41–14:28

Text is the final part of the artwork. Even in a visual infographic, it helps people read the data and understand the subject, making the work clearer and more accessible. Create a new layer called “testo.” Keep the text within the page so it does not overpower the artwork or feel intrusive.

We place text in the four corners of the artwork, choose a moderate size, and select a suitable typeface. We chose Apfel Grotezk (captions: *AppFolgrotesk*), a free font downloaded from Collletttivo (captions: *Collettivo*), an Italian open-source type foundry listed in the additional resources. Its rounded details echo the carefully made artwork. Choose the font size to suit the mood you want the artwork to evoke; this choice has a major effect on the final appearance. Use the grid to set an even distance from the edges. It makes these details quick to place.

## Label the ingredients and their quantities

Anchor: 3762 · U4 · L14 · 14:29–16:23

After placing the text, add the ingredients you want to show. The Boulevardier contains bourbon (captions: *barbon*); label it with a quantity of 45 ml. To show the reader that green represents bourbon, add a colored marker within the text. Use the Type tool and open Glyphs (*Glifi*). The typeface includes a circular character that we can color and use as a legend marker.

Copy the marker into the Campari label and color it with Campari’s color; write “Campari 30 ml.” Do the same for Sweet Red Vermouth: add the label and “30 ml,” then color its marker with the vermouth’s red. The artwork is now complete, with the data, decoration, and explanatory text for readers who want to explore it further.

## Repeat the design across the cocktail set and save

Anchor: 3762 · U4 · L14 · 16:24–18:22

Repeat the same steps for each cocktail to make nine distinct artworks. Rotate and arrange the forms freely to create the compositions you want. Keep the alcohol base at the bottom; if the main ingredient is not a distilled spirit, put the ingredient with the highest alcohol content there. The forms can intersect in different harmonious ways, or interact as a mix of filled shapes and outlines.

Customize the decorations as well. For the Margarita, we chose a concentric pattern to match its classic presentation in a glass with a salt-covered rim. The Americano pattern is more complex because it includes both orange and lemon. We designed two distinct patterns that weave together along a set grid to make a cohesive composition.

Save the file one last time using File > Save As. Name it “Infografica.Co.Tl,” version 0.3, so it is ready for animation. In the next lesson, Valerio will show how to animate the data in Adobe After Effects.
