## Why move the artwork from Illustrator to Photoshop

Anchor: 561 · U3 · L08 · 00:02–01:03

Before starting with Photoshop, let us watch a short video about how to bring designs over from Illustrator. In this lesson, we will look at an example of bringing designs into Photoshop. First, we design in Illustrator because it works with vectors (*vectores*). You can scale vectors as much as you want and they do not lose quality. Photoshop mainly works with pixels (*píxeles*), which lose quality and become pixelated when you scale them. We bring vectors into Photoshop so we can apply texture on top. You do not need to bring every item in your design into Photoshop, only the ones you want to highlight. That is why I do it manually.

## Create a Photoshop guide and import the title

Anchor: 561 · U3 · L08 · 01:04–01:48

First, create a Photoshop file the same size as the design in Illustrator. If you want, you can use the same background color as the design. The first thing we do is select everything with Control + C and paste it as a Smart Object (*objeto inteligente*). If you get an error, try deselecting this option and click OK. That will serve as a guide for the other things we bring in later. Lower its opacity and leave it there.

For example, I am not going to apply texture to each of these items. I want to highlight the title. So I copy the title with Control + C, use Control + V to paste it, and, since everything is copied in the middle, it stays in place. We name the layers so everything stays organized.

## Bring over the planet and position the elements

Anchor: 561 · U3 · L08 · 01:48–02:10

Later I will apply texture to the planet. We bring it over and paste it in the middle. We hide the guide, press Control + T to select the object, move it into position using the guide, and name it. That is how we bring all our designs from Illustrator into Photoshop.

## Arrange and transfer the remaining elements

Anchor: 561 · U3 · L08 · 02:11–03:28

For example, with this title, we copy and paste it. We can assemble it with the arrow keys: holding Shift moves it in larger increments, and without Shift it moves a little at a time. We position it, and that is it.

If we are not going to scale anything, it is best to bring everything into Photoshop. That way, we can import the Photoshop file directly into After Effects. Otherwise, we will have to import both a Photoshop file and an Illustrator file. We will see later how to organize everything.

With Control + 2, we can lock some layers. For example, if we want to bring all of this together, we select it while holding Shift, select each item, use Control + C and Control + V, and paste it. We position it, and that is it. This is the way to move designs manually from Illustrator to Photoshop so we can apply textures to them later.
