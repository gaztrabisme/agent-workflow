## Importing and setting up the first scene

Anchor: 561 · U4 · L10 · 00:02–02:13

Before we start animating, we are going to separate everything into layers (*capas*) so we can bring it into After Effects. I’ll show you how I export from Photoshop and Illustrator and bring the work into After Effects. You can start with either one. It is better to bring everything in from Photoshop; if we see that we need something else, we can bring it in from Illustrator.

Take the file—our first scene, the first thing you designed—and drag it into After Effects. Drop it in this window, make sure it is imported as a composition (*composición*), retaining the layer sizes, and click OK. Create a new document the same size as the work and set it to 40 seconds. This creates the main precomposition (*precomposición*). Press Enter to change its name. Drag our first scene in here, and we can name everything as we go to keep it organized.

If the scene is too short, open Pre-composition Options, add a few seconds, select everything with Control + A, and extend it. Come back here. Enlarge the size. From here you can Zoom In or Zoom Out. Stretch this, close it, go back, stretch this, and here you will be able to stretch the precomposition.

In After Effects you can see the same things you had in Photoshop: the noise, the noise layers, white over black. You can lock these. We are not going to use or animate them; they will remain as texture. The miscellaneous elements are here, and the glow is behind them. In this case, we are going to animate some of these planets and things going around. Since they are all on a single layer here, we are going to take them into Illustrator separately so we can animate them.

## Separating the artwork into Illustrator layers

Anchor: 561 · U4 · L10 · 02:13–03:25

Select our composition. Select everything with Control + C, then use Control + N to create a new document of the same size, and Control + Shift + V to paste it. We are going to separate everything into layers. We will not use the title because we already have it, and we will not use the background either. Select everything, go to the Layers panel, and choose the option in this corner that separates everything into layers. Select all the layers, drag them here so everything is separated, and save the file.

## Importing the separated scene and organizing its layers

Anchor: 561 · U4 · L10 · 03:25–04:59

In After Effects, find the folder in the file browser, bring it into After Effects, and drop it here. Make sure the import settings say Composition and Layer Size, then click OK. Rename it “Escena 01 - AI” to indicate Adobe Illustrator. We are not going to drag it in here; we will open it and see all our layers.

It is a long job, but it is always worth separating and naming everything so animating it later will be much easier. Copy all these layers with Control + C and close this composition. These will be all our miscellaneous elements. Press Control + V and After Effects places them in the same position. Later, depending on each person’s design and how many elements there are, it is useful to organize and rename everything for the animation. As you can see, this is a little out of alignment, so we arrange it. We can turn off or hide things we will not use. Now we have all the layers. This way we can animate each one separately later: move it, rotate it, and so on. That is how we bring everything from Photoshop and Illustrator into After Effects. Now, in the next lesson, we will start animating.
