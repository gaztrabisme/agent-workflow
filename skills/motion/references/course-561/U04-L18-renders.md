## Rendering a high-quality file from After Effects

Anchor: 561 · U4 · L18 · 00:00–01:24

561 · U04 · L18 · 00:00–01:24

We will render (*renderizar*) the final videos using After Effects. First I will show how to compress the videos, then I will teach you how to convert them to GIFs for social media. One way to get the file out in the best quality is to go to the main precomposition (*precomposición*) and, under Composition, select Add to Render Queue (*Añadir a la cola de procesamiento*). Leave the settings as they are. We can change the video resolution to make the file smaller, for example, to half size. There are not many options here; we choose the format. I will select QuickTime, the largest file at the best quality, in MOV format, and click Accept. Select the folder where you want to save it, give it a name, and click Render.

This creates the file. I have all the rendered files here. This one comes straight from After Effects; it is 5 GB, the highest quality and the heaviest file. I will not render it now because it takes half an hour or an hour, depending on the animation and the amount of material you have made.

## Compressing with Media Encoder and HandBrake

Anchor: 561 · U4 · L18 · 01:24–03:15

561 · U04 · L18 · 01:24–03:15

Another way is to send the video to Media Encoder, which usually comes with the Adobe package. I send it to Media Encoder and the program opens. The video does not appear here, so we choose the rendering options. Media Encoder gives us many more options than After Effects. We can choose AVI or GIF, although I do not recommend making an animated GIF here because a one-minute GIF is very heavy, especially in HD. We can also choose MPEG4, a sequence, TIFF, or QuickTime. I usually leave these settings as they are. We select the folder the same way as in After Effects, set the name, and press Play. This usually renders faster.

The difference is that a 5 GB file becomes a 50 MB file, which is much more reasonable for uploading to social media or anywhere else. Another option is a file I have here that is 7 MB: use HandBrake. This program resizes the file and lowers the quality a little. Sometimes you can hardly notice it, and the result is much better for sharing anywhere, even over WhatsApp. HandBrake is free; you can download it.

Search for the HandBrake site. Usually I take the video, drag it in, select the folder where the file is saved, put it here, enter the name, click Save, then click Start Encode. Usually we do not change many options. If you want to reduce the file size further, change this setting, then click Play. It resizes the video, leaving a file of 7 MB.

## Creating and resizing a GIF in Photoshop

Anchor: 561 · U4 · L18 · 03:15–05:46

561 · U04 · L18 · 03:15–05:46

Finally, I will show you how to make a GIF with Photoshop. Choose Import, Video Frames to Layers, and select the video. The part of the video inside these handles is what will open in Photoshop for making the GIF.

![561 · U4 · L18 · 03:36](frames/U04L18-F0336.00.jpg)

On screen: "Import Video To Layers" / "Range To Import" / "From Beginning To End" / "Selected Range Only" / "Use the trim controls below the video to specify the range" [rest omitted]  
Shows: The import dialog with Selected Range Only selected and trim handles bracketing the video preview.

I recommend making short GIFs, not one that is a minute long, because it will be very large. GIFs are more for sharing on social media such as Dribbble or Behance. What is inside these handles is what will be created in Photoshop. We could make a GIF of just the intro.

Click OK, then go to Window. If your interface is in Spanish, it says *Línea de tiempo*; in English it says Timeline. These are the frames (*cuadros*). A GIF is a sequence of images. Go to Export and choose this option; the shortcut is shown here.

![561 · U4 · L18 · 04:12](frames/U04L18-F0412.00.jpg)

On screen: "Export" / "Save for Web (Legacy)" / "Alt+Shift+Ctrl+S" [rest omitted]  
Shows: The Export submenu with Save for Web (Legacy) highlighted and its keyboard shortcut visible.

We can reduce the file size because GIFs are very heavy and take a long time to load. This GIF has 75 frames and weighs almost 9 MB, which is huge. Here we can reduce it to about 600 pixels wide. It renders again and now weighs less than 1 MB. Select GIF 128 Colors. We can choose more colors for better quality. We can preview the GIF. Depending on what you designed, some colors may break if you use too many colors. It is best to try these settings, including transparency, to get the best quality.

The GIF often comes out better here than from After Effects. We also have more control over its size and quality. When I click Save, it creates a GIF like this one. It is useful for social media, Behance, or Instagram. It is a short loop (*bucle*), but it gives our posts more meaning.
