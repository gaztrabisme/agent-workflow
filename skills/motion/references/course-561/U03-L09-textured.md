## Separate the layers and prepare the texture

Anchor: 561 · U3 · L09 · 00:02–00:40

Now we will create the backgrounds and add texture to our designs. We have reached the texturing (*texturización*) stage. It is one of the stars of the course: adding that extra detail that makes our designs different. I like applying textures in Photoshop because the tools are more versatile and you can find hundreds of free brushes all over the place. As we saw in the previous scene, I separated the layers. I now have the title, planet, ring, and all the miscellaneous items in a single layer.

We will create a new layer while holding Alt between these two layers. It creates a kind of mask (*máscara*) inside the title layer. With the Brush tool (*Pincel*), we lower the opacity (*opacidad*) and paint. You can see how the text takes shape and gains texture and depth. I invite you to try brushes, download them, and try adding something different to your designs.

For the planet, we create a new layer. We can copy the same color as the text with the Eyedropper tool (*Cuentagotas*) or by holding Alt. On a new layer, we just raise the opacity, use roughly the same size, make one brushstroke, and play with the layer modes (*modos de capa*). I invite you to try them. If we set the opacity to 100, it gives an extra glow. Always name the layers to keep everything organized.

## Add noise to the design

Anchor: 561 · U3 · L09 · 01:55–02:48

Another thing I like to do is add noise (*ruido*). We create a new layer, choose a dark color, paint, and go to Filter (*Filtro*) > Noise (*Ruido*) > Add Noise (*Agregar ruido*). We look at the options and experiment with them, making sure Monochromatic (*Monocromático*) is selected. The settings depend on each person’s taste.

Once that is done, we try the layer modes. You can see how this adds texture to the whole design. In this layer mode, it adds texture to the dark colors. We use Control + J to duplicate the layer, Control + I to invert it, and try another layer mode. This way, we now have texture on all the whites as well.

## Finish with highlights and extra detail

Anchor: 561 · U3 · L09 · 02:49–04:01

We can add highlights to the miscellaneous items in the same way as we did with the planet. We copy the color, make a brushstroke, find the mode I used earlier, and add color and highlights to the designs.

How much you add to each design depends on your taste. More layers mean more work and more animation to do, but often that extra detail is worth it.
