## Continuing the location and line animations

Anchor: 561 · U4 · L12 · 00:02–02:23

All right, we will continue animating. We will speed up the video so it does not get too long and tedious, but we will apply the same principles we have been working with so far: position (*posición*), scale (*escala*), and opacity (*opacidad*). We will use the same transition between scenes, add a little movement, and apply Easy Ease to the keyframes (*fotogramas clave*).

On this screen we will select all the location icons. Move the anchor point (*punto de anclaje*) down so they scale from the bottom. Find the time when the animation should begin, simply scale them, and apply Easy Ease.

Now find the lines, convert them to vectors, and find Offset (*desplazamiento*) to animate them. Within the layer options we will find Offset. Move it a little. If you have lines, try to have them all go toward the same place, and animate them one by one.

In this box I moved the anchor point to the left, so when it scales it scales in this direction. For the text, use the same format we have been applying: position, opacity, everything subtle. The circles also use Scale. For the line, instead of using Trim Paths, simply move the anchor point up and scale it. We keep checking that everything is on time and consecutive, and that everything does not animate all at once.

We look for the same text effect for all the text and check that it appears one item at a time, with time to read. Use the same principle with this square. If you have a square or a similar shape, do the same thing. Try different animations for the text. Here, instead of Position and Opacity, I used Scale and Opacity. I also used Position and Opacity for these titles. Always add more detail when you can, but at the beginning there is no need to spend so much time.

To see a preview of how the whole video will look, you can review and adjust things later. This is about adding detail. Sometimes letting the animation rest helps us see new things. We spend so long animating that sometimes we stop noticing some details.

## Creating a dotted line and refining the scene changes

Anchor: 561 · U4 · L12 · 04:59–07:10

This line here is a vector. I created it in After Effects: use the Pen tool (*Pluma*) to draw a line. Go to the options under Dashes. My interface is in English, but yours will probably say *Punto* or *Punteado* [Dot or Dotted]. Check the options until it looks similar to what you have in your design. We do the same thing as before and move Offset. Everything follows the same principles: move the anchor point, use Scale, and make the transition from one panel to another, always applying Easy Ease to the keyframes.

## Sequencing animations and previewing the project

Anchor: 561 · U4 · L12 · 07:10–10:17

Here we continue applying the same thing: Position and Opacity, making the animations sequentially so one appears after another. This creates a system that makes the whole video feel more integrated. Many of these animations in infographics are simply decorations. They do not all have to mean something. Sometimes they move randomly or scale up and down. You keep trying things out and seeing what looks good.
