# Workshop Agenda & Structure

| Time | Item |
|------|------|
| 10 min | Introduction & Workshop Guide |
| 15 min | **Define with BXT** |
| 15 min | **Develop with AI Discovery Cards** |
| 20 min | Exercise — Business Envisioning |
| 30 min | Exercise — Solution Envisioning |
| 10 min | Next Steps |

## Full Engagement Structure (per)

The 90 min above is the core session inside a larger 2-session engagement.

### Pre-Workshop
- Identify multiple business units involved
- Align on the 4 AI Transformation pillars each BU cares about
- **Run the `business-intelligence` skill** on the client. You need: executive profiles with political-layer analysis (reports to / measured on / loses if we win), Capability Map (client need vs. our fit vs. gap), "What Competitor CANNOT Do" for each named competitor likely in the room, and a Claims Verification pass on any collateral you're bringing in. This is the intel foundation — the workshop structures it into BXT-scored use cases, it doesn't generate it.

### Day 1 — AI Discovery (2–6 hrs)

**Prework:**
- Create persona(s) for each BU
- Shortlist candidate use cases
- Prefill BXT template + Journey Map with known info

**Audience:** End Users, BU Stakeholders, Business & Tech AI SMEs

**Output:** 2–3 agentic workflow / use case candidates

**In-session flow:**
1. Intro + workshop objectives
2. Discover — personas, pain points (prompts: Five Whys, Rose/Thorn/Bud, Move off the Solution)
3. Define — BXT Use Case Template filled for each candidate, using the **Five Golden Questions** per pillar (see `facilitator_scripts.md`)
4. Develop — Journey Map with 3 swim lanes (User / AI Discovery / Agentic Workflow)
5. Score candidates on BXT (1–5 each pillar)
6. Plot on Prioritization Matrix → surface top 2–3

### Day 8 — Prioritization (2–6 hrs)

**Prework:**
- Refine BXT for shortlisted use cases
- Fill out AI Pattern Scorecard for the client's industry (Banking/Insurance/Retail/Energy templates in appendix)

**Audience:** BDM (Business Decision Maker), TDM (Technical Decision Maker), Stakeholders

**Output:** 1 approved use case for Proof of Value (PoV)

**In-session flow:**
1. Review shortlisted use cases with refined BXT scores
2. GenAI Approach Selection (4 dimensions: Data, Customization, Dev Complexity, End User)
3. Complexity-vs-Potential-Value matrix → Adopt / extend an off-the-shelf assistant vs. build custom vs. build on a unified data platform
4. ROI Analysis with concrete baselines
5. Architecture Design Session — co-design
6. Solutioning Considerations: Secondary Personas, RACI, HITL, Workflow Grounding
7. Commit 1 use case for rapid prototyping with an AI coding assistant

## Prep Checklist (before Day 1)

- [ ] Five Golden Questions reviewed per BXT pillar (see `facilitator_scripts.md`); client-specific variants drafted
- [ ] Persona drafts for top 2–3 BUs (an off-the-shelf AI assistant generates usable first drafts)
- [ ] Candidate use case shortlist (6–10 at most — narrowed to 3–5 in session)
- [ ] Industry Scorecard prefilled (Banking / Insurance / Retail / Energy — see PDF pp 73–76)
- [ ] BXT templates prefilled with known info for each candidate
- [ ] Confirm BDM and TDM attendance for Day 8
- [ ] AI Discovery Cards printed (79 cards) if in-person; digital versions otherwise
- [ ] Room setup: flipchart / whiteboard / sticky notes / pens

## Materials

**In-person:**
- 79 physical AI Discovery Cards (colored by AI capability category)
- Flipchart / whiteboard
- Sticky notes
- Pens, markers

**Remote:**
- Mural / Miro board with digital card set
- BXT template in PowerPoint or Word
- Journey Map template
- Prioritization Matrix (2×2)
