# ai-discovery-workshop

Use [SKILL.md](SKILL.md) and the files in [references/](references/) to facilitate a client discovery session that produces a client-validated AI use-case brief for presale decisions.

The package includes a compact, generic set of Discovery and Agentic workflow prompts and a client-evidence pattern note. Use an authorized current deck when one is available; a fixed number of agentic candidates is not a workshop target. Keep BXT scores evidence-linked and provisional where needed.

The final brief is client-validated. Before client contact, label the artifact `prework draft` and mark scores provisional. Architecture and proposal work hand off to solution-architect; general product decisions belong to product-management.

The skill inherits shared integrity, grounding, and output-contract guidance from the current `../core/SKILL.md` and its references. When a substantive unrouted task needs coordination, use the `project` skill for coordination and its approach declaration.

## Install

Install this directory as `ai-discovery-workshop` in your skills directory. Keep the sibling `core` skill available for shared guidance.

```bash
git clone https://github.com/gaztrabisme/ai-discovery-workshop.git ~/.claude/skills/ai-discovery-workshop
```
