# Functional colour: choose the job before the family

Reader: a designer planning or reviewing color for graphic identity, posters, packaging, editorial work or other communication. Sources: [L23](../course-5642/U03-L23-color-and-communication.md), [L26–L40](../course-5642/U03-L26-a-functional-classification-of-color.md), [L43](../course-5642/U03-L43-how-to-evaluate-a-color-proposal.md).

## Start with the function

The course classifies color by what it does in a design: represent an object, evoke associations, or work as a functional sign and code. These are communicative roles, not color-space or pigment categories. (5642 · U3 · L23 · 00:23–01:33, 5642 · U3 · L26 · 00:55–01:40)

| Function | Ask first | Variables |
|---|---|---|
| Denotative — representation | Should the color describe the represented thing? | Naturalistic, exalted, expressionist, fanciful |
| Connotative — evocation | Which psychological or culturally learned associations should the color invite? | Psychological, symbolic |
| Sign — functionality and coding | Does color need to work as an autonomous graphic element, a visible code, or a socially recognized emblem? | Schematic, signal, emblematic |

(5642 · U3 · L26 · 00:55–01:40, 5642 · U3 · L26 · 01:40–04:06, 5642 · U3 · L26 · 04:06–05:14)

The course presents these as working categories rather than sealed boxes: one design can use more than one function, and its parts can move between representation and sign. (5642 · U3 · L26 · 09:10–10:58)

## Color families as hypotheses, not fixed meanings

The family examples below summarize associations taught in unit 3. Use them to generate options, then test them in the audience and context. Course 5642 itself says psychological meanings are not proven universal rules, and that symbolic meanings vary by culture and history; course 1140 makes the same caution. (5642 · U3 · L31 · 07:34–08:45, 5642 · U3 · L32 · 09:05–10:00, 5642 · U3 · L32 · 10:00–10:52, 1140 · U2 · L04 · 04:17–05:30)

|---|---|
| Red | Fire, food, energy, love and attraction, but also danger, blood and revolution. Which reading wins depends on the project and its references. (5642 · U3 · L33 · 00:00–06:41) |

## Evaluate a color proposal with viewers

When the meaning of a graphic proposal matters, use a semantic differential: choose relevant bipolar adjective pairs, rate the proposal on seven positions between each pair, and read the result as a profile. The course groups its candidate pairs under aesthetic, indicative-instrumental and symbolic-social dimensions; its worked example overlays audience profiles for two gin variants. (5642 · U3 · L43 · 02:41–03:16, 5642 · U3 · L43 · 03:44–04:34, 5642 · U3 · L43 · 10:21–11:57)

Use [T10–T12 in the review checklist](mistakes-checklist.md) to set the target profile before collecting ratings, check audience agreement, and compare alternatives. The rating profile is evidence about this audience in this context, not a universal verdict about the color. (derived from 5642 · U3 · L43 · 00:26–01:52, 5642 · U3 · L43 · 11:57–12:55 and 1140 · U2 · L04 · 04:17–05:30)
