# Value plan: the structure under the color

Reader: an agent planning or critiquing an image before any color is chosen. Sources: [L07](../course/U02-L07-step-by-step-of-creating-a-color-concept.md), [L08](../course/U03-L08-success-and-failure-of-an-image.md).

**Value** means how light or dark a color is: how close it is to white or to black. A **value plan** is the image reduced to lights and darks.

## Why value comes first

- The eye reads an organization of light and dark before it reads color. There is no color without this structure. (1140 · U2 · L07 · 00:50–01:50)
- **Composition** is defined as "the organization of the values created by light and by color". (1140 · U2 · L07 · 01:50–02:46)
- An image is built in four layers, bottom to top: **1 idea, 2 design (shape), 3 values, 4 colors**. Color is the last layer and only improves an image whose lower layers already work. (1140 · U3 · L08 · 00:31–01:51)
- The teacher's failed sketches shared the successful image's idea and design. They failed at values:
  - flows led away from the focal point;
  - contrasts sat in the periphery;
  - the silhouette could not be read, so there was no protagonist.

  (1140 · U3 · L08 · 01:51–03:34, 1140 · U3 · L08 · 03:34–05:03)

## Focal points and the hierarchy of attention

- **Focal points** rank information: one main, then secondary ones, then decoration. It works like newspaper headline sizes. (1140 · U2 · L07 · 02:46–03:53)
- The hierarchy is made by **contrast**, the difference between one thing and another. (1140 · U2 · L05 · 00:28–01:03)
- The focal points must already exist in the value layout. Color reinforces them, and can create them, but should not be what first makes them.

## The three black-and-white contrasts

| Contrast | How it pulls the eye | Source |
|---|---|---|
| Value | A very light value against a very dark one | 1140 · U2 · L07 · 03:53–04:21 |
| Detail | Detail at the periphery and at the center, with an empty ring between them: a "bullseye" | 1140 · U2 · L07 · 04:21–04:54 |
| Silhouette | The hardest, clearest edges concentrated at the focal point | 1140 · U2 · L07 · 04:54–05:48 |

Once color comes in, more contrasts are added: hue, saturation and temperature. See [palettes.md](palettes.md) and [temperature-saturation.md](temperature-saturation.md).

## Contrast is distance on a scale

Shape, value and color are the three means of contrast. (1140 · U3 · L08 · 12:59–14:13)

On each scale, the farther apart two things are, the stronger the contrast:
- shape: small to large, and circle to square;
- value: black to white;
- color: across the spectrum, where purple and yellow are very far apart.

(1140 · U3 · L08 · 14:13–15:39)

This single idea runs through the whole method. Contrast means moving things apart on a scale. Harmony means bringing them together. See [harmony-bridges.md](harmony-bridges.md).

## Checks

1. **Remove the color.** Look at the image in grayscale. (1140 · U3 · L08 · 03:34–05:03)
2. **Remove more detail.** Reduce the grayscale to a few flat levels. The protagonists and the main contrasts should still sit where they belong. (1140 · U3 · L08 · 05:03–06:31)
3. **Blur low-contrast edges** with Photoshop's Filter > Noise > Dust & Scratches. The edges that survive should be at the focal point. (1140 · U2 · L07 · 04:54–05:48)
4. **Mood check on values.** Mostly light values read as happy, and mostly dark as sad or terrifying. (1140 · U2 · L04 · 01:41–02:57) For the value side of each mood recipe, see [intent-and-meaning.md](intent-and-meaning.md).

## Handing the plan to color

- Keep the intention of the value plan: which element is the protagonist, and where the contrasts are. The color plan must follow the same rules. (1140 · U3 · L08 · 06:31–09:58)
- The most frequent serious error is "a value plan that does not follow the same rules as the color plan". Where the value plan has contrast, the color plan must have contrast too. (1140 · U3 · L08 · 06:31–09:58)

### Set the painting's exposure range

Before painting light, decide how the observed scene range maps into the painting's available lights and darks, and which information must survive. This is the exposure decision in course 1560; it supports the value hierarchy rather than replacing it. (1560 · U2 · L06 · 00:08–01:48, 1560 · U2 · L06 · 01:49–04:41)

Practice the teacher sets for this stage: copy 25 images using only 3 values (dark, medium, light). See [U02-unit.md](../course/U02-unit.md).
