## Setting up the canvas

Anchor: 1560 · U2 · L04 · 00:00–01:06

Now that you know a bit more about me, my influences and how I came to learn all of this, I'd like to introduce the workspace I use and how I organize it to be efficient, and show you the tools and brushes I paint with.

Let's go over creating a new document. I make it 1200 by 1200 pixels. Using a smaller canvas really helps when you're learning to paint, because it stops you getting caught up in small details — I actually paint most of my work at small resolutions even now. Before drawing, instead of pure white, I like to pick a bit of an off-color, beige background. It's more neutral; a pure white background can be quite distracting. That's just personal preference.

## Custom keyboard shortcuts

Anchor: 1560 · U2 · L04 · 01:07–01:59

Next I want to show you the keyboard shortcuts I use in Photoshop. I've modified them because the default ones are very inefficient in my opinion. This setup lets you leave your hand in one spot instead of moving all over the keyboard for basic functions: the brush tool and eraser tool switch with two fingers, the zoom tool sits in the middle to let you reposition your view, and along the bottom are brush-size increase and decrease, so you can change brush size quickly while painting instead of right-clicking and adjusting it through a menu — which really takes you out of the moment. In the middle is also the smudge tool, which is very useful for blending; I'll talk more about that later.

## Color panel, navigator and swatches

Anchor: 1560 · U2 · L04 · 02:00–03:06

I use three main panels. The color panel, in HSB sliders mode: hue is the tint of the color, saturation is how much color is in it (how gray or saturated it looks), and value is how dark or light it looks. Separating color into these three components really helps you understand how it works. Then the navigator, which I keep at the bottom — a small view of what you're painting, useful for keeping a general sense of the whole image. Finally the swatches: I don't use the main color grid at all, only the top row. That way, every time you change color while painting, Photoshop keeps a history of the last colors you used in that row, which is very useful for going back quickly to a color you used a moment ago.

## The five basic brushes

Anchor: 1560 · U2 · L04 · 03:07–05:17

I want to show you the basic brushes I made. There are a lot of brushes online, with crazy textures and effects, but if you want to learn to paint properly you need to start with the most basic set. This is what these are meant to be.

The main one is a rectangle brush, which you can use for everything: press lightly and it's very light, press hard and it becomes completely opaque, so you can also use it for line drawing. You can use it for blending too — paint lightly, then hold Alt to use the Eyedropper and pick up a color from the middle of the stroke, which helps create a smooth transition.

The next is a big airbrush, useful for very soft transitions or, mostly, for atmosphere effects — with white selected it creates a feeling of fogginess, so it's very useful for atmospheric effects.

Then there's a stripe brush, useful for simple textures or to give a bit more direction to your brushstrokes — handy for painting grass, but mainly just to add variety to your strokes.

The big square brush is a color-dynamics brush: using it creates small variations in value, tint and saturation as you paint, which gives a more organic look to your colors.

Finally there's a smudge brush — pressing S on the keyboard switches to it. It's very useful for blending: if you paint a shadow, you can blend it in easily afterwards. You need to be careful not to overdo it, because blending everywhere makes a painting look undefined and confusing, but it's very useful when you need soft transitions, and it's a quick way of rendering.

## Clipping a layer to painted shapes

Anchor: 1560 · U2 · L04 · 05:42–06:30

Next, something a little specific that might seem confusing at first. Say you have shapes painted on one layer. If you make another layer on top and hold Alt in between the two layers in the Layers panel, a small arrow appears; click it and the new layer clips to the one underneath. That means if you take any color and start painting, it will only paint within the boundaries of what's already been painted. This is very useful because it saves a lot of time — especially for painting different lighting on a character, since you keep the silhouette and shapes intact. You'll see later how we use this for painting. If you unclip it, you'll see all that information was there all along; it was just hidden while clipped.

## Two key layer modes: multiply and linear dodge

Anchor: 1560 · U2 · L04 · 06:31–07:39

At the top of the Layers panel is the layer-mode menu. There are a lot of modes and it can be confusing at first, but I only want you to remember two. Multiply mixes the color on the top layer with the color on the layer beneath, keeping some of that underlying color but darkening everything — very useful for painting shadow; you can still see the color underneath, but tinted toward the color you've selected. The second is linear dodge: with this layer you want to use dark colors — picked from the dark area of the color picker. It's very useful for creating very bright lights — it brightens the colors underneath strongly, and we'll use it later to create believable lighting. Again, the two important modes to remember are multiply and linear dodge.

## Sampling color from one layer only

Anchor: 1560 · U2 · L04 · 07:46–09:11

Now something a bit specific, and it might not be obvious why we're doing this. Clear out the layers, take a layer clipped to your painted shapes, and set it to Multiply. Pick an orange color and apply it on top. Now pick another color and apply that too — but if you then want to go back to the first color, you can't just pick it up again with the eyedropper, because on a multiply layer the color you sample back is much darker than the one you actually painted with.

To avoid this, open the Eyedropper tool's options and set Sample to "Current Layer" instead of all layers. Now, when you pick a color while on a given layer, you get the actual color painted on that layer, even though it isn't showing its true value on screen because of the blend mode above it. This lets you paint and blend directly in these colors and see the true end result without having to switch the layer back to Normal mode to check it. The trade-off is that to pick a specific color, you now have to go back to whichever layer actually contains that color — if you're on the wrong layer, the eyedropper only shows you the colors present on that layer, not the ones underneath.

## Checking values in black and white

Anchor: 1560 · U2 · L04 · 09:19–10:39

Finally, a very useful shortcut. Go to View > Proof Setup > Custom, and in that dialog pick "Working Gray, Gray Gamma 2.2." From then on, pressing Command-Y or Control-Y (Proof Colors) turns the image black and white in display only — the colors are still there and you can still pick them, you're just seeing everything as black and white. This is very useful for checking the values in your painting, because colors can be distracting, and you need a clear read on how the darks and lights in a piece are working together.

My workspace is pretty specific, as are my shortcuts and brushes, but I think it can really help you be more efficient and faster, so you can concentrate on what matters: painting. Now that you know how to organize your workspace, in the next lesson we'll start talking about the theory of light.

### Key points (derived)

- Small canvas (here 1200×1200 px) and an off-white background reduce distraction while learning.
- Custom one-hand keyboard shortcuts (brush/eraser, zoom, brush size ±, smudge) keep focus on painting instead of the interface.
- HSB color mode separates hue, saturation and value so each can be reasoned about independently.
- Five basic brushes cover the whole method: rectangle (line/fill/blend), airbrush (atmosphere), stripe (texture), color dynamics (organic variation), smudge (blending — use sparingly).
- Clipping a layer to painted shapes constrains new paint to the existing silhouette, which is the basis for painting lighting variations without redrawing shapes.
- Multiply (darken, for shadow) and Linear Dodge (brighten, for light) are the two layer modes used throughout the course.
- Setting the eyedropper to "Sample: Current Layer" is necessary once you're picking colors across multiply/linear-dodge layers, since sampling "All Layers" returns the blended, not the painted, color.
- Proof Setup → Working Gray, Gray Gamma 2.2, toggled with Cmd/Ctrl-Y, is used throughout the course to check value structure independently of color.
