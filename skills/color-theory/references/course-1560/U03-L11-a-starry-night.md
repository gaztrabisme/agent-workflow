## Setting up the night scene

Anchor: 1560 · U3 · L11 · 00:00–00:33

In this lesson we paint a scene under a night sky lit by moonlight and a lantern. It's worth noting that the process is exactly the same as for a sunny day: we are only changing the value of light, so everything is going to be much darker, but the principles stay identical.

## Painting the night sky and the ambient light

Anchor: 1560 · U3 · L11 · 00:34–01:43

First, make the sky a very dark blue, then add a slight gradient, which looks better, and a few stars.

![1560 · U3 · L11 · 00:53](frames/U03L11-F0053.jpg)

On screen: [none]  
Shows: The character standing among rocks and bushes against a plain dark-blue night sky with scattered stars; the lantern beside him is not yet lit, and his colors are still the flat daytime local colors.

Next comes the ambient light: bring a blue multiply layer over to the right side, using the color of the background, and copy the same treatment onto the same area again. This is something of a cheat, because in real life you can barely see anything at night — it's really, really dark — but in illustration we can stylize what happens at night. It's a common trope in cinema: filmmakers put blue light into night scenes because they want the audience to see what's going on. A small lantern is added early on too, because it will supply a warm light source later.

## Warm shadows and volume

Anchor: 1560 · U3 · L11 · 01:44–02:55

Now paint the volume. Because the shadows should read as warmer, the approach is to go darker and then remove saturation — less blue means less cold, so the color turns warm. This is exactly the same process used for daylight scenes, just with darker colors; the principles don't change. The same warm, desaturated shadow goes under the nose and onto the background. Working quickly now that the method is familiar, add a touch more light on the top surfaces and a shadow for the cut of the lantern's stand, added because the lantern isn't a very strong light source.

## The lantern's warm light

Anchor: 1560 · U3 · L11 · 02:56–03:38

Staying on the same layer, switch to orange for the lantern's own light. The first attempt is a bit too strong, but toned down it looks right. The red of the character's cap reacts strongly to this warm light source, because there is a lot of red in the light's own color; the same warm treatment is applied to the background.

## Moonlight and the rim light

Anchor: 1560 · U3 · L11 · 03:39–04:58

Finally, add a strong light from the moon — again a stylization, since in reality the moon doesn't cast that much light, but here, why not. Pick a dark blue color and use a Linear Dodge layer for this strong light; a touch brighter looks nicer. The effect is really a rim light, used to outline the character a little better; it's kept from reaching as far as the floor, so it reads purely as a way to highlight him. The same rim treatment goes into the background, except directly above the lantern, since a light source is already affecting that area quite strongly — in this case, the lantern overpowers the blue moonlight. A little more volume is added here and there to finish the night scene.

## Key takeaway: painting is interpretation, not reality

Anchor: 1560 · U3 · L11 · 04:58–05:43

Remember that in painting, we're not showing reality as it is — we're only describing it. That is why certain aspects can be exaggerated when the goal is to emphasize a feeling. Here, the only goal is to read as a night scene, so as long as the scene stays dark and bluish, it will feel like night. That leaves plenty of room to play around and explore different lighting ideas, as long as you stay within that range. The next lesson looks at what happens when painting a room lit only by artificial colored lights.

### Key points (derived)

- Night lighting uses the same process as daytime lighting; only the value (darkness) of the colors changes.
- Ambient "night" light is a stylization: real night is nearly black, but illustrations commonly add blue ambient light so the scene stays readable — a trope borrowed from cinema.
- Warm shadows come from going darker and desaturating (less blue = less cold = warmer), not from adding a different hue.
- A strong, saturated light color (like the lantern's orange) makes similarly colored surfaces (the red cap) react strongly.
- Rim light from a secondary source (the moon) should be dialed back wherever a stronger nearby light source (the lantern) already dominates.
- Painting is description, not documentation: exaggerating color and value is fine as long as the scene still reads as intended.
