# Owner brand profile

This folder holds a draft of the owner's personal visual direction: an evidence-led profile, reusable design tokens, and two sample slides. It is for work where no company or client identity governs the design.

## For producers

Read PROFILE.md first for what is observed, what is only a working hypothesis, the optional Art Deco direction, and open owner questions. Use tokens.json as the annotated source of token decisions and tokens.css as the CSS custom-property implementation. The HTML samples embed a copy of those properties so each file renders on its own with render-kit; keep that copy aligned when changing tokens.css. The samples show one possible application of the 2024 game-world deck palette; they are examples, not a requirement to use that world in every artifact.

Presentation, frontend and motion producers can select one coherent visual world per piece and adapt it to the medium. Follow a company or client system wherever it applies. Treat all token values marked chosen as reviewable defaults.
